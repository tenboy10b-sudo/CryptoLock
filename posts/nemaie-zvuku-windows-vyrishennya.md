Звук зник після оновлення Windows або просто так? Ось покрокове виправлення від простого до складного.

---

## Крок 1 — Перевірити базові речі

```powershell
# Переглянути пристрої відтворення
Get-AudioDevice -Playback

# Або через PowerShell без модуля
Get-WmiObject Win32_SoundDevice | Select-Object Name, Status
```

**Вручну:**
```
ПКМ на іконці звуку в треї → "Відкрити параметри звуку" →
перевір що обраний правильний пристрій відтворення
```

**Часті причини:**
- Гучність знижена до 0 або вимкнена
- Обраний неправильний пристрій (HDMI замість колонок)
- Кабель не підключений або підключений не в той роз'єм

---

## Крок 2 — Перевірити пристрої відтворення

```
ПКМ на іконці звуку → "Звуки" → вкладка "Відтворення"
```

Переконайся що:
- Потрібний пристрій є в списку (якщо не видно — ПКМ → "Показати вимкнені пристрої")
- Він встановлений як **"Пристрій за замовчуванням"**
- Зелена галочка на правильному пристрої

---

## Крок 3 — Перезапустити аудіо служби

```powershell
# Перезапустити Windows Audio
Restart-Service AudioSrv -Force
Restart-Service AudioEndpointBuilder -Force

# Перевірити статус
Get-Service AudioSrv, AudioEndpointBuilder |
    Select-Object Name, Status, StartType
```

Якщо служба вимкнена:
```powershell
Set-Service AudioSrv -StartupType Automatic
Set-Service AudioEndpointBuilder -StartupType Automatic
Start-Service AudioSrv
Start-Service AudioEndpointBuilder
```

---

## Крок 4 — Оновити драйвер звукової карти

```powershell
# Знайти звукові пристрої
Get-WmiObject Win32_SoundDevice | Select-Object Name, Status, DeviceID
```

**Оновити:**
1. Диспетчер пристроїв → Звукові, відеота ігрові пристрої
2. ПКМ на звуковому пристрої → Оновити драйвер
3. Або завантаж з сайту виробника материнської плати

**Для Realtek (найпоширеніший):**
Завантаж з [realtek.com](https://www.realtek.com/en/component/zoo/category/pc-audio-codecs-high-definition-audio-codecs-software)

---

## Крок 5 — Перевстановити драйвер

```powershell
# Видалити поточний драйвер через PowerShell
$sound = Get-WmiObject Win32_SoundDevice | Select-Object -First 1
# Далі через Диспетчер пристроїв
```

1. Диспетчер пристроїв → Звукові пристрої
2. ПКМ → Видалити пристрій → постав галочку "Видалити драйвер"
3. Дія → Оновити конфігурацію обладнання
4. Windows встановить базовий драйвер автоматично

## Крок 6 — Перевірити системні файли

```powershell
# Перевірка системних файлів
sfc /scannow

# DISM відновлення
DISM /Online /Cleanup-Image /RestoreHealth
```

## Типові ситуації

### Немає звуку після оновлення Windows

Оновлення могло замінити або пошкодити аудіодрайвер:
```powershell
# Відкотити оновлення драйвера
# Диспетчер пристроїв → звуковий пристрій → Властивості → Драйвер → Відкотити
```

### Немає звуку через HDMI (монітор або ТВ)

```
Параметри звуку → Пристрої відтворення →
знайди "HDMI Output" або назву монітора →
встанови як пристрій за замовчуванням
```

### Звук є в одному додатку але не в іншому

```
ПКМ на іконці звуку → Відкрити мікшер гучності →
перевір чи не вимкнений звук для конкретного додатку
```

### Звук хрипить або з артефактами

```powershell
# Вимкнути покращення звуку
# Параметри звуку → пристрій відтворення → Властивості →
# Покращення → "Вимкнути всі покращення"
```

## Засіб усунення неполадок

```powershell
# Запустити troubleshooter звуку
msdt.exe /id AudioPlaybackDiagnostic
```

## Резюме

| Проблема | Рішення |
|---------|---------|
| Гучність 0 | Підняти в треї або мікшері |
| Неправильний пристрій | Параметри звуку → встанови за замовчуванням |
| Служба не працює | Restart-Service AudioSrv |
| Після оновлення | Відкотити або перевстановити драйвер |
| HDMI немає звуку | Вибрати HDMI пристрій у відтворенні |
