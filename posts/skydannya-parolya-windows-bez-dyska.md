Забув пароль від Windows і не можеш увійти? Є кілька способів залежно від типу акаунту — Microsoft чи локальний.

---

## Спочатку визнач тип акаунту

На екрані входу подивись — є електронна адреса (Microsoft акаунт) або просто ім'я (локальний)?

- **Microsoft акаунт** (email@outlook.com) → скидання через сайт
- **Локальний акаунт** → скидання через WinRE або командний рядок

---

## Спосіб 1 — Microsoft акаунт (найпростіший)

1. Відкрий з іншого пристрою: **https://account.live.com/password/reset**
2. Введи email від Microsoft акаунту
3. Вибери спосіб підтвердження (email або SMS)
4. Скинь пароль
5. Увійди в Windows з новим паролем

---

## Спосіб 2 — Контрольні питання (локальний акаунт)

Windows 10/11 з локальним акаунтом може мати контрольні питання:

1. На екрані входу натисни **"Забули PIN або пароль?"**
2. Відповідай на контрольні питання
3. Встанови новий пароль

---

## Спосіб 3 — Через WinRE і командний рядок

Якщо немає контрольних питань і немає Microsoft акаунту:

### Крок 1 — Зайти в WinRE

- Натисни **Shift + Restart** на екрані входу
- Або: 3 рази увімкни/вимкни ПК під час завантаження
- Або: завантажся з флешки Windows → Відновлення

### Крок 2 — Відкрити командний рядок

```
Усунення неполадок → Додаткові параметри → Командний рядок
```

### Крок 3 — Замінити Utilman на CMD (тимчасово)

```cmd
:: Знайти диск з Windows (зазвичай C: або D: в WinRE)
dir C:\Windows\System32\utilman.exe

:: Зробити резервну копію
copy C:\Windows\System32\utilman.exe C:\Windows\System32\utilman.exe.bak

:: Замінити на cmd
copy C:\Windows\System32\cmd.exe C:\Windows\System32\utilman.exe /Y
```

### Крок 4 — Скинути пароль

1. Перезавантаж ПК нормально
2. На екрані входу натисни іконку спеціальних можливостей (нижній правий кут)
3. Відкриється командний рядок з правами SYSTEM
4. Скинь пароль:

```cmd
:: Переглянути всіх користувачів
net user

:: Скинути пароль (замінити USERNAME і NewPassword)
net user USERNAME NewPassword

:: Або видалити пароль (порожній)
net user USERNAME ""

:: Або створити нового адміна
net user TempAdmin Password123 /add
net localgroup Administrators TempAdmin /add
```

5. Увійди з новим паролем

### Крок 5 — Відновити Utilman (обов'язково!)

Після входу в систему відновити оригінальний файл:

```powershell
# Від адміністратора
Copy-Item "C:\Windows\System32\utilman.exe.bak" "C:\Windows\System32\utilman.exe" -Force
```

---

## Спосіб 4 — Через іншого адміна на ПК

Якщо є другий адміністраторський акаунт на цьому ПК:

```powershell
# Список усіх локальних користувачів
Get-LocalUser | Select-Object Name, Enabled, PasswordRequired

# Скинути пароль через PowerShell
$pass = ConvertTo-SecureString "НовийПароль123!" -AsPlainText -Force
Set-LocalUser -Name "USERNAME" -Password $pass

# Або через CMD
net user USERNAME NewPassword
```

---

## Спосіб 5 — Offline NT Password Editor

Безкоштовний інструмент для скидання паролів без входу в систему:

1. Завантаж **chntpw** або **Offline NT Password & Registry Editor**
2. Запиши на флешку
3. Завантажся з флешки
4. Вибери диск з Windows → SAM файл → скинь пароль

---

## PIN замість пароля

Якщо забув PIN але пам'ятаєш пароль від Microsoft акаунту:

```
Екран входу → "Параметри входу" → вибери "Пароль" замість PIN
```

Або скинь PIN:
```
Win + I → Облікові записи → Параметри входу → PIN → Я забув свій PIN
```

## Часті питання

### Чи видаляться файли при скиданні пароля?

Ні, скидання пароля ніколи не видаляє файли чи програми. Виняток — зашифровані файли (BitLocker, EFS), які можуть стати недоступні без ключа відновлення.

### Microsoft акаунт, але немає інтернету — що робити?

Для скидання Microsoft акаунту потрібен інтернет. Спробуй підключитись через кабель або мобільний роутер. Якщо неможливо — метод з флешкою працює тільки для локальних акаунтів.
