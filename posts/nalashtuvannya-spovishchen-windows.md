Сповіщення Windows заважають якщо погано налаштовані. Ось як взяти повний контроль.

---

## Налаштування сповіщень застосунків

`Win + I` → **Система** → **Сповіщення** → список застосунків

Для кожного: вимкнути повністю, відключити банери або звуки.

---

## Focus Assist (не турбувати)

**Windows 11:** `Win + I` → **Система** → **Фокус**
**Windows 10:** `Win + I` → **Система** → **Фокус-асистент**

Режими:
- **Тільки пріоритетні** — обрані застосунки
- **Тільки будильники** — мінімум переривань

---

## Автоматичні правила

`Win + I` → **Фокус-асистент** → **Автоматичні правила**

- За розкладом (наприклад 9:00-17:00)
- При дублюванні екрана (презентації)
- При повноекранному застосунку

---

## Відключити всі банери через реєстр

```powershell
# Вимкнути банери сповіщень
Set-ItemProperty "HKCU:\SOFTWARE\Microsoft\Windows\CurrentVersion\PushNotifications" `
  -Name "ToastEnabled" -Value 0 -Type DWord

# Увімкнути назад
Set-ItemProperty "HKCU:\SOFTWARE\Microsoft\Windows\CurrentVersion\PushNotifications" `
  -Name "ToastEnabled" -Value 1 -Type DWord
```

---

## Часті питання

### Вимкнув сповіщення застосунку але вони все одно з'являються?

Системні сповіщення обходять налаштування застосунків. Перевір Windows Security Center і налаштування Центру дій окремо.

### Як прибрати новини і погоду з панелі задач?

ПКМ на панелі → **Новини та інтереси** → **Вимкнути**. Або: `Win + I` → Персоналізація → Панель задач → Вимкнути Віджети.

---

## Резюме

Налаштуй окремо для кожного застосунку. Focus Assist для роботи без відволікань. Автоматичні правила для презентацій і ігор. `ToastEnabled = 0` через реєстр щоб вимкнути всі банери.
