Правильно налаштована миша зменшує навантаження на руку і підвищує точність. Ось всі ключові налаштування.

---

## Відкрити налаштування миші

`Win + I` → **Bluetooth і пристрої** → **Миша**

Або через старий інтерфейс: `Win + R` → `main.cpl`

---

## Швидкість курсора

`Win + I` → **Миша** → **Швидкість покажчика миші** → повзунок.

Для звичайного використання: середнє положення.
Для великих моніторів: вище.
Для графіки і дизайну: нижче для точності.

---

## Вимкнути прискорення миші (для геймерів і дизайнерів)

Прискорення миші (Enhance Pointer Precision) змінює чутливість залежно від швидкості руху — непередбачувано при точній роботі.

`Win + R` → `main.cpl` → **Параметри покажчика** → зніми **Підвищення точності покажчика**.

```powershell
# Вимкнути прискорення через реєстр
Set-ItemProperty -Path "HKCU:\Control Panel\Mouse" -Name "MouseSpeed" -Value "0"
Set-ItemProperty -Path "HKCU:\Control Panel\Mouse" -Name "MouseThreshold1" -Value "0"
Set-ItemProperty -Path "HKCU:\Control Panel\Mouse" -Name "MouseThreshold2" -Value "0"
```

---

## Налаштування прокручування

`Win + I` → **Миша** → **Кількість рядків для прокручування за один раз** (3-5 рядків за замовчуванням).

Увімкни **Прокручувати неактивні вікна при наведенні** — корисно при роботі з кількома вікнами.

---

## Поміняти кнопки (для лівшів)

`Win + I` → **Миша** → **Основна кнопка миші** → вибери **Права**.

---

## Швидкість подвійного клацання

`Win + R` → `main.cpl` → **Кнопки** → повзунок **Швидкість подвійного клацання**.

---

## Налаштування для геймерів

Якщо миша має власний ПЗ (Logitech G Hub, Razer Synapse, SteelSeries GG):
- DPI налаштовується в ньому, не в Windows
- Встанови DPI через ПЗ миші
- В Windows залиш швидкість на рівні 6/11 (середина) — не збільшуй в Windows якщо використовуєш власний DPI миші

```powershell
# Перевірити поточну швидкість миші (значення 1-20, 10 = середина)
(Get-ItemProperty "HKCU:\Control Panel\Mouse").MouseSensitivity
```

---

## Розмір і вигляд курсора

`Win + I` → **Спеціальні можливості** → **Покажчик миші і дотик** → змінити розмір і колір.

Великий білий курсор з чорним контуром значно легше бачити на будь-якому фоні.

---

## Резюме

Для повсякденного використання: середня швидкість, 3-5 рядків прокрутки. Для ігор і дизайну: вимкни Підвищення точності покажчика. Для лівшів: поміняй кнопки. Якщо є геймерська миша — керуй DPI через її власне ПЗ.
