Відновлення системи повертає Windows до попереднього стану без видалення особистих файлів. Найшвидший спосіб скасувати невдалий драйвер або оновлення.

---

## Увімкнути захист системи

`Win + R` → `sysdm.cpl` → **Захист системи** → вибери диск C: → **Налаштувати** → **Увімкнути захист системи** → виділи 5-10 ГБ → OK

---

## Створити точку відновлення

```powershell
# Перед ризикованими змінами
Checkpoint-Computer -Description "Перед оновленням драйвера" -RestorePointType MODIFY_SETTINGS
```

Або через GUI: `sysdm.cpl` → Захист системи → Створити.

---

## Запустити відновлення

**Якщо Windows запускається:**
```
Win + R → rstrui.exe
```
Вибери точку відновлення → Далі → Готово → ПК перезавантажується.

**Якщо Windows не запускається:**
WinRE → Усунення несправностей → Додаткові параметри → **Відновлення системи**

---

## Переглянути точки відновлення

```powershell
Get-ComputerRestorePoint | Select-Object Description, CreationTime |
  Sort-Object CreationTime -Descending
```

---

## Видалити старі точки (звільнити місце)

```powershell
# Видалити всі крім останньої
vssadmin delete shadows /for=C: /oldest

# Видалити всі
vssadmin delete shadows /for=C: /all /quiet
```

---

## Часті питання

### Відновлення системи видаляє мої файли?

Ні. Зачіпає тільки системні файли Windows, встановлені програми і реєстр. Документи, фото та інші особисті файли не змінюються.

### Відновлення не вдалось — що робити?

Спробуй старішу точку. Якщо всі не спрацьовують — видали всі точки і спробуй знову після увімкнення захисту.

---

## Резюме

Увімкни захист системи до того як знадобиться. Створюй точку перед: встановленням драйверів, оновленнями, великими програмами. `rstrui.exe` для відновлення. WinRE якщо Windows не запускається. Особисті файли не торкаються.
