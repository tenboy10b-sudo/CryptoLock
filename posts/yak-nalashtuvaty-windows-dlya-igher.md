Windows за замовчуванням не налаштований для ігор — він балансує між продуктивністю і економією ресурсів. Ось як змінити це за 15 хвилин.

---

## 1. Увімкнути Game Mode

`Win + I` → **Ігри** → **Режим гри** → увімкни.

Game Mode:
- Пріоритизує CPU і GPU ресурси для гри
- Вимикає фонові оновлення Windows під час гри
- Зменшує втручання системи

---

## 2. План живлення: Висока продуктивність

`Win + R` → `powercfg.cpl` → **Створити схему живлення** → вибери **Висока продуктивність** → задай назву → **Далі** → **Готово** → вибери нову схему.

Або через PowerShell:
```powershell
# Увімкнути план "Висока продуктивність"
powercfg /setactive 8c5e7fda-e8bf-4a96-9a85-a6e23a8c635c

# Або "Максимальна продуктивність" (якщо доступний)
powercfg /setactive e9a42b02-d5df-448d-aa00-03f14749eb61
```

---

## 3. Вимкнути Xbox Game Bar (якщо не потрібен)

Game Bar споживає ресурси у фоні.

`Win + I` → **Ігри** → **Xbox Game Bar** → вимкни.

Або якщо потрібні деякі функції (FPS лічильник) — залиш увімкненим, він легкий.

---

## 4. Hardware-Accelerated GPU Scheduling (HAGS)

Зменшує затримку між CPU і GPU.

`Win + I` → **Система** → **Дисплей** → **Графіка** → **Змінити параметри графіки за замовчуванням** → увімкни **Планування GPU з апаратним прискоренням**.

Потребує GPU з підтримкою WDDM 2.7+ (NVIDIA RTX/GTX 10xx+, AMD RX 5000+) і Windows 10 2004+.

---

## 5. Вимкнути фонові програми

`Win + I` → **Програми** → **Запущені програми** → вимкни все що не потрібно.

Перед запуском гри вручну закрий: браузер, Discord (або переведи в трей), Spotify, OneDrive sync.

```powershell
# Переглянути що жере RAM прямо зараз
Get-Process | Sort-Object WorkingSet -Descending |
  Select-Object -First 15 Name, @{n='RAM(MB)';e={[math]::Round($_.WorkingSet/1MB,0)}}
```

---

## 6. Налаштування відеокарти

**NVIDIA:**
Панель керування NVIDIA → **Управління параметрами 3D** → **Глобальні параметри**:
- **Режим управління живленням**: Максимальна продуктивність
- **Вертикальна синхронізація**: Вимкнено (або Fast Sync)
- **Режим очікування шейдерів**: Увімкнено

**AMD:**
AMD Software → **Gaming** → **Graphics** → увімкни **Radeon Anti-Lag**, вимкни V-Sync якщо використовуєш FreeSync.

---

## 7. XMP/EXPO для RAM

Більшість RAM за замовчуванням працює на 2133 МГц замість заявлених 3200-6000 МГц.

Увійди в BIOS → знайди **XMP** (Intel) або **EXPO/DOCP** (AMD) → увімкни → збережи.

Різниця в іграх: +5-15% FPS залежно від гри.

---

## 8. Вимкнути Superfetch (SysMain)

На ПК з SSD Superfetch непотрібний і іноді заважає.

```powershell
Stop-Service SysMain
Set-Service SysMain -StartupType Disabled
```

На HDD — **не вимикай**, він прискорює завантаження програм.

---

## 9. Налаштувати файл підкачки

Якщо менше 16 ГБ RAM:

`Win + R` → `sysdm.cpl` → **Додатково** → **Параметри** (Продуктивність) → **Додатково** → **Змінити** → вимкни автоматичне керування → вибери диск → **Особливий розмір**:
- Початковий розмір: 1.5x від RAM в МБ
- Максимальний розмір: 3x від RAM в МБ

---

## 10. Перевірити температури під навантаженням

Перегрів = троттлінг = падіння FPS.

Запусти HWiNFO64 → грай 30 хвилин → перевір **Maximum** температури:
- CPU: має бути нижче 90°C
- GPU: має бути нижче 85°C

Якщо вище — почисти від пилу і замінь термопасту.

---

## Резюме

Найважливіше: план живлення **Висока продуктивність** + увімкнути **XMP/EXPO** в BIOS + вимкнути фонові програми перед грою. Ці три речі дадуть найбільший приріст FPS без ризику нестабільності.
