Підмережа (subnet) — розділення великої мережі на менші сегменти для організації і безпеки. Розуміння підмереж потрібне кожному хто налаштовує мережу, сервер або маршрутизатор.

---

## Основні поняття

### IP адреса
IPv4 адреса — 4 числа від 0 до 255 розділені крапками:
```
192.168.1.100
```
Кожне число — 8 біт. Разом 32 біти.

### Маска підмережі
Маска визначає яка частина IP — мережа, яка — хост:
```
255.255.255.0  →  мережа: перші 3 октети, хости: останній
255.255.0.0    →  мережа: перші 2 октети, хости: останні 2
255.0.0.0      →  мережа: перший октет, хости: останні 3
```

### CIDR нотація
Компактний запис маски через косу риску:
```
192.168.1.0/24   =  192.168.1.0, маска 255.255.255.0
192.168.0.0/16   =  192.168.0.0, маска 255.255.0.0
10.0.0.0/8       =  10.0.0.0, маска 255.0.0.0
```

Число після `/` — кількість одиничних біт в масці.

## Розрахунок підмережі вручну

Для мережі `192.168.1.0/24`:

```
Адреса мережі:    192.168.1.0
Маска:            255.255.255.0
Перший хост:      192.168.1.1
Останній хост:    192.168.1.254
Broadcast:        192.168.1.255
Кількість хостів: 254
```

**Формула:**
- Кількість хостів = 2^(32 - CIDR) - 2
- Для /24: 2^8 - 2 = 254

## Розрахунок через PowerShell

```powershell
# Інформація про мережеві адаптери і підмережі
Get-NetIPAddress | Where-Object {$_.AddressFamily -eq 'IPv4'} |
    Select-Object InterfaceAlias, IPAddress, PrefixLength |
    Format-Table

# Конвертувати CIDR в маску підмережі
function Convert-CIDRToMask {
    param([int]$CIDR)
    $mask = ([Math]::Pow(2, $CIDR) - 1) * [Math]::Pow(2, 32 - $CIDR)
    $bytes = [BitConverter]::GetBytes([uint32]$mask)
    [Array]::Reverse($bytes)
    ($bytes | ForEach-Object { $_ }) -join '.'
}

Convert-CIDRToMask 24   # 255.255.255.0
Convert-CIDRToMask 16   # 255.255.0.0

# Знайти адресу мережі
function Get-NetworkAddress {
    param([string]$IP, [string]$Mask)
    $ipBytes = ([System.Net.IPAddress]$IP).GetAddressBytes()
    $maskBytes = ([System.Net.IPAddress]$Mask).GetAddressBytes()
    $networkBytes = 0..3 | ForEach-Object { $ipBytes[$_] -band $maskBytes[$_] }
    $networkBytes -join '.'
}

Get-NetworkAddress "192.168.1.100" "255.255.255.0"
# Результат: 192.168.1.0
```

## Приватні діапазони IP

За стандартом RFC 1918 — ці діапазони зарезервовані для приватних мереж:

| Діапазон | CIDR | Використання |
|---------|------|-------------|
| 10.0.0.0 – 10.255.255.255 | /8 | Великі корпоративні мережі |
| 172.16.0.0 – 172.31.255.255 | /12 | Середні мережі |
| 192.168.0.0 – 192.168.255.255 | /16 | Домашні роутери |

## Налаштування статичного IP в Windows

```powershell
# Встановити статичну IP адресу
$adapter = Get-NetAdapter | Where-Object {$_.Status -eq "Up"} | Select-Object -First 1

New-NetIPAddress `
    -InterfaceIndex $adapter.InterfaceIndex `
    -IPAddress "192.168.1.50" `
    -PrefixLength 24 `
    -DefaultGateway "192.168.1.1"

Set-DnsClientServerAddress `
    -InterfaceIndex $adapter.InterfaceIndex `
    -ServerAddresses ("8.8.8.8", "1.1.1.1")
```

## Часті питання

### Яка різниця між /24 і 255.255.255.0?
Це одне і те саме — просто різні форми запису однієї маски.

### Скільки пристроїв можна підключити до /24 мережі?
254 пристрої (від .1 до .254). Адреси .0 (мережа) і .255 (broadcast) зарезервовані.

### Чому домашні роутери використовують 192.168.x.x?
Це приватний діапазон RFC 1918 — ці адреси не маршрутизуються в інтернеті.
