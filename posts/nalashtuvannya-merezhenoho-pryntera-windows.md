Підключення мережевого принтера зазвичай просте. Ось як вирішити і складніші ситуації.

---

## Додати принтер через Параметри

`Win + I` → **Bluetooth та пристрої** → **Принтери та сканери** → **Додати пристрій**

Windows сканує мережу автоматично. Якщо принтер з'явився — натисни **Додати**.

---

## Додати за IP-адресою

```powershell
# Додати мережевий принтер за IP
Add-PrinterPort -Name "IP_192.168.1.100" -PrinterHostAddress "192.168.1.100"
Add-Printer -Name "Офісний принтер" -DriverName "HP LaserJet" -PortName "IP_192.168.1.100"
```

---

## Поділитись принтером через мережу

```powershell
Set-Printer -Name "EPSON" -Shared $true -ShareName "EpsonOffice"

# Підключитись до спільного принтера з іншого ПК
Add-Printer -ConnectionName "\\НазваПК\EpsonOffice"
```

---

## Виправити "Принтер офлайн"

```powershell
# Встановити онлайн
Set-Printer -Name "Офісний принтер" -WorkOffline $false

# Перезапустити службу друку
Restart-Service Spooler -Force
```

Або: ПКМ на принтері → **Переглянути чергу** → **Принтер** → зняти **Використовувати принтер офлайн**

---

## Очистити зависаючу чергу друку

```powershell
Stop-Service Spooler -Force
Remove-Item "C:\Windows\System32\spool\PRINTERS\*" -Force -EA 0
Start-Service Spooler
```

---

## Часті питання

### Принтер показує офлайн хоча увімкнений — чому?

Зазвичай потрібно перезапустити Spooler. Також перевір що IP принтера не змінився (DHCP може переприсвоїти). Встанови статичний IP на принтері.

### Принтер працював і зупинився після оновлення?

Оновлення могло змінити драйвер. Диспетчер пристроїв → Принтери → ПКМ → Відкотити драйвер.

---

## Резюме

Додати через Параметри для автовизначення. Вручну — по IP. Офлайн: перезапусти Spooler + зніми "Офлайн". Зависла черга: зупини Spooler → видали файли → запусти. Перевстанови драйвер при постійних помилках.
