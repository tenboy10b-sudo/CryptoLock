Багато функцій Windows потребують інтернету, але чимало важливих інструментів працюють повністю офлайн.

---

## Диктовка (офлайн в Windows 11)

`Win + H` — голосовий ввід тексту.

Windows 11 підтримує офлайн диктовку — спочатку потрібно завантажити мовний пакет:

`Win + I` → **Час і мова** → **Голосові функції** → вибери мову → **Завантажити**.

Після завантаження пакету диктовка працює без інтернету.

---

## Перекладач (вбудований в Edge)

Браузер Microsoft Edge має вбудований перекладач що частково кешує мовні пакети. Для офлайн роботи завантаж пакети заздалегідь у Settings → Languages.

Альтернатива: **DeepL для Windows** — завантажує пакети для офлайн роботи.

---

## Офісні програми

- **LibreOffice** — безкоштовний, повністю офлайн, відкриває .docx, .xlsx, .pptx
- **Notepad** — завжди офлайн
- **WordPad** (Windows 10) — базове форматування офлайн

---

## Відновлення системи офлайн

Всі інструменти відновлення Windows працюють без інтернету:

```cmd
rem Перевірка системних файлів
sfc /scannow

rem Дефрагментація
defrag C: /U /V

rem Перевірка диску
chkdsk C: /f
```

DISM з опцією `/RestoreHealth` потребує інтернету. Без інтернету використовуй `/Source`:

```cmd
DISM /Online /Cleanup-Image /RestoreHealth /Source:WIM:D:\sources\install.wim:1 /LimitAccess
```

---

## Пошук файлів офлайн

Вбудований пошук Windows працює офлайн (шукає в локальному індексі).

**Everything** від voidtools — миттєвий пошук файлів, повністю офлайн.

---

## Діагностика без інтернету

```powershell
# Інформація про систему
msinfo32

# Стан дисків
Get-PhysicalDisk | Select-Object FriendlyName, HealthStatus

# Завантаженість
Get-Counter '\Processor(_Total)\% Processor Time'

# Журнал подій
Get-WinEvent -LogName System -EntryType Error -Newest 10
```

---

## Backup і відновлення офлайн

File History, System Restore і Windows Backup — всі працюють без інтернету якщо є підключений зовнішній диск.

---

## Що потребує інтернету

- Windows Update (окрім офлайн WSUS)
- DISM /RestoreHealth без локального джерела
- Microsoft Store
- OneDrive синхронізація
- Cortana і хмарний пошук
- Активація Windows (але вже активована — працює офлайн)

---

## Резюме

Більшість інструментів діагностики, відновлення і роботи з файлами в Windows повністю офлайн. Для офлайн диктовки завантаж мовний пакет заздалегідь. LibreOffice замінює Office без інтернету.
