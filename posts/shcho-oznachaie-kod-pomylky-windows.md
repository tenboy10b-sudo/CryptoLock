Windows показує коди помилок у форматі `0x80070005` або `0xC000021A`. На перший погляд вони виглядають як безглузда комбінація символів — але насправді кожен код несе конкретний зміст.

---

## Як влаштований код помилки

Код `0x80070005` розбивається так:

```
0x    8007    0005
│     │       │
│     │       └── Win32 код помилки (десяткове: 5 = ACCESS_DENIED)
│     └────────── 8007 = HRESULT з Win32 кодом всередині
└──────────────── 0x = шістнадцятковий формат
```

- **0x8007xxxx** — помилки Windows (Win32 API)
- **0xC000xxxx** — помилки ядра NT (NTSTATUS)
- **0x8000xxxx** — COM/OLE помилки

---

## Найпоширеніші коди і що вони означають

| Код | Назва | Типова причина |
|-----|-------|---------------|
| `0x80070005` | ACCESS_DENIED | Недостатньо прав, заблокований антивірусом |
| `0x80070002` | FILE_NOT_FOUND | Файл видалено або оновлення пошкоджено |
| `0x80070070` | DISK_FULL | Диск переповнений |
| `0x80004005` | E_FAIL | Загальна помилка доступу |
| `0xC000021A` | SYSTEM_PROCESS_TERMINATED | BSOD — критичний процес впав |
| `0x80248007` | WU_E_DS_NODATA | Пошкоджена база Windows Update |

---

## Як виправити помилку 0x80070005 (ACCESS_DENIED)

Найпоширеніша помилка Windows:

```powershell
# Варіант 1: запустити як адміністратор
Start-Process powershell -Verb RunAs

# Варіант 2: відновити права на папку
icacls "C:\ProblemFolder" /reset /T

# Варіант 3: перевірити системні файли
sfc /scannow
```

---

## Як виправити помилки Windows Update (0x80248007, 0x80070002)

```powershell
# Очистити кеш оновлень
Stop-Service wuauserv, bits -Force
Remove-Item "C:\Windows\SoftwareDistribution\*" -Recurse -Force -EA 0
Start-Service wuauserv, bits

# Відновити компоненти
DISM /Online /Cleanup-Image /RestoreHealth
sfc /scannow
```

## Де шукати код помилки

```powershell
# PowerShell може розшифрувати деякі Win32 коди
[System.ComponentModel.Win32Exception]::new(5).Message
# Виведе: "Access is denied"

# Перетворити hex в decimal
[int]"0x80070005"  # або
0x5  # частина після 0x8007
```
