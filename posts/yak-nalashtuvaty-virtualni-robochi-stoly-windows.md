Віртуальні робочі столи дозволяють розділити роботу на незалежні простори — наприклад робота на одному столі, навчання на іншому, особисте на третьому. Без захаращення єдиного екрана.

---

## Створити і перемикати столи

**Відкрити Task View:**
`Win + Tab` — показує всі відкриті вікна і столи внизу

**Гарячі клавіші:**

| Клавіші | Дія |
|---------|-----|
| `Win + Ctrl + D` | Створити новий стіл |
| `Win + Ctrl + →` | Перейти на наступний стіл |
| `Win + Ctrl + ←` | Перейти на попередній стіл |
| `Win + Ctrl + F4` | Закрити поточний стіл |
| `Win + Tab` | Огляд всіх столів |

---

## Перемістити вікно на інший стіл

**Через Task View:**
`Win + Tab` → наведи на вікно → правий клік → **Перемістити на** → вибери стіл

**Через гарячі клавіші:**
`Win + Shift + →/←` — переміщує активне вікно на сусідній стіл

---

## Різні шпалери на кожному столі (Windows 11)

`Win + Tab` → правий клік на столі → **Вибрати фон** → вибери зображення

Кожен стіл може мати власні шпалери — зручно щоб одразу розуміти де ти знаходишся.

---

## Перейменувати стіл

`Win + Tab` → клікни на назву столу зверху → введи нову назву

Наприклад: "Робота", "Навчання", "Особисте"

---

## Показати вікна з усіх столів на панелі завдань

`Win + I` → **Персоналізація** → **Панель завдань** → **Поведінка панелі завдань** → **Показувати мої відкриті вікна на всіх робочих столах**

Або тільки з поточного — залежно від уподобань.

---

## Корисні сценарії

**Для роботи:**
- Стіл 1: браузер + пошта
- Стіл 2: редактор коду або документи
- Стіл 3: Slack, Teams, месенджери

**Для навчання:**
- Стіл 1: відеолекція
- Стіл 2: нотатки

**Для розробки:**
- Стіл 1: код
- Стіл 2: термінал і логи
- Стіл 3: браузер для тестування

## Відмінність від Windows 10

У Windows 11 додано:
- Різні шпалери на кожному столі
- Перейменування столів
- Швидший перехід через Task View

В Windows 10 базові функції ті самі але без кастомізації вигляду.

---

## Резюме

`Win + Ctrl + D` — новий стіл. `Win + Ctrl + →/←` — перемикання. `Win + Tab` — огляд і управління. Для максимальної продуктивності: назви столи відповідно до задач і поклади різні шпалери — мозок швидше переключається між контекстами.
