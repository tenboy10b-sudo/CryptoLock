TeamViewer і AnyDesk — найпопулярніші програми для віддаленого доступу до комп'ютера. Підключитись до ПК вдома з роботи, допомогти батькам з налаштуванням або керувати сервером — все через інтернет.

---

## TeamViewer vs AnyDesk — що вибрати

| | TeamViewer | AnyDesk |
|-|-----------|---------|
| Безкоштовно для особистого використання | ✅ | ✅ |
| Швидкість з'єднання | Висока | Дуже висока |
| Якість зображення | Відмінна | Відмінна |
| Розмір програми | ~50 МБ | ~4 МБ |
| Без встановлення | ✅ (portable) | ✅ (portable) |
| Мобільний додаток | ✅ | ✅ |
| Передача файлів | ✅ | ✅ |
| Вбудований чат | ✅ | ✅ |

**TeamViewer** — більш відомий, краща сумісність з корпоративними мережами.
**AnyDesk** — швидший, менший розмір, зручніший інтерфейс.

## TeamViewer

### Встановлення

1. Завантаж з [teamviewer.com/download](https://www.teamviewer.com/en/download/windows/)
2. Запусти інсталятор
3. Вибери варіант:
   - **"Встановити"** — повна установка, запускається автоматично
   - **"Запустити одноразово"** — без встановлення, тільки для поточного сеансу

### Підключення до іншого ПК

1. Запусти TeamViewer
2. Попроси людину на іншому ПК відкрити TeamViewer і повідомити:
   - **ID** (9 цифр)
   - **Пароль** (4-6 символів)
3. Введи ID в поле "ID партнера" → **"Підключитись"**
4. Введи пароль → ти бачиш і керуєш чужим ПК

### Доступ без нагляду (unattended access)

Для підключення до свого ПК без того щоб хтось сидів за ним:

1. TeamViewer → **"Налаштування"** → **"Безпека"**
2. Встанови постійний пароль в розділі "Персональний пароль"
3. Увімкни **"Запускати TeamViewer разом з Windows"**

Або через акаунт TeamViewer:
1. Створи акаунт на teamviewer.com
2. Увійди в TeamViewer на обох пристроях
3. Всі твої пристрої будуть в списку — підключайся без пароля

### Налаштування безпеки TeamViewer

```
Налаштування → Безпека
```

Рекомендовані налаштування:
- **Двофакторна автентифікація** — увімкни
- **Список дозволених** — додай тільки свої пристрої
- **Вимагати підтвердження** — увімкни для вхідних з'єднань
- **Чорний список** — блокуй підозрілі ID

## AnyDesk

### Встановлення

1. Завантаж з [anydesk.com/en/download](https://anydesk.com/en/download)
2. Можна запустити без встановлення (portable .exe ~4 МБ)
3. Або встановити для постійного використання

### Підключення

1. Запусти AnyDesk
2. Адреса твого пристрою — 9 цифр вгорі (AnyDesk Address)
3. Введи адресу іншого ПК → **"Підключитись"**
4. На іншому ПК натиснуть **"Прийняти"**

### Доступ без нагляду в AnyDesk

1. AnyDesk → **"Налаштування"** → **"Безпека"**
2. Увімкни **"Увімкнути неконтрольований доступ"**
3. Встанови пароль
4. Налаштування → **"Запускати AnyDesk при запуску Windows"**

### Передача файлів

В обох програмах є вбудований файловий менеджер:

**TeamViewer:** Під час сеансу → **"Передача файлів"** у верхньому меню

**AnyDesk:** Під час сеансу → іконка папки в бічній панелі

## Безпека віддаленого доступу

### Основні правила

- **Ніколи не давай доступ незнайомцям** — шахраї часто телефонують "від Microsoft" і просять встановити TeamViewer
- Після сеансу — закрий програму або вийди з акаунту
- Використовуй складні паролі для unattended access
- Увімкни двофакторну автентифікацію

### Альтернатива — вбудований Windows RDP

Якщо обидва ПК в одній мережі або через VPN — використовуй вбудований Remote Desktop:

```powershell
# Увімкнути RDP
Set-ItemProperty -Path 'HKLM:\System\CurrentControlSet\Control\Terminal Server' `
  -Name "fDenyTSConnections" -Value 0

# Відкрити порт в брандмауері
Enable-NetFirewallRule -DisplayGroup "Remote Desktop"
```

Підключення: `Win + R` → `mstsc` → введи IP або ім'я ПК

## Вирішення проблем

### TeamViewer каже "комерційне використання"
TeamViewer автоматично визначає комерційне використання за частотою сеансів. Рішення:
- Зменш частоту сеансів
- Використовуй AnyDesk як альтернативу
- Купи ліцензію якщо використовуєш для роботи

### Повільне з'єднання
- В TeamViewer: налаштування якості → **"Оптимізувати швидкість"**
- В AnyDesk: Налаштування → Дисплей → знизь якість

### Не можу підключитись через корпоративний файрвол
TeamViewer і AnyDesk використовують порти 80 і 443 (HTTPS) — зазвичай відкриті.
Якщо ні — попроси адміністратора мережі відкрити:
- TeamViewer: TCP/UDP 5938
- AnyDesk: TCP 7070, UDP 50001-50003
