Активація Windows підтверджує що ваша копія ліцензійна і не використовується на інших пристроях. Без активації деякі функції недоступні — наприклад персоналізація робочого столу.

---

## Як перевірити статус активації

```powershell
# Швидка перевірка
slmgr /xpr

# Детальна інформація
slmgr /dlv
```

Або: **Параметри → Система → Активація**

Можливі статуси:
- **"Windows активовано"** — все добре
- **"Windows активовано цифровою ліцензією"** — прив'язано до акаунту Microsoft
- **"Windows не активовано"** — потрібна активація

---

## Спосіб 1 — Ключ продукту (25 символів)

Якщо у вас є ключ виду `XXXXX-XXXXX-XXXXX-XXXXX-XXXXX`:

**Через Параметри:**
1. `Win + I` → **Система → Активація**
2. **"Змінити ключ продукту"**
3. Введи ключ → **"Далі"** → **"Активувати"**

**Через командний рядок (від адміністратора):**
```powershell
slmgr /ipk XXXXX-XXXXX-XXXXX-XXXXX-XXXXX
slmgr /ato
```

> Де взяти ключ? На наклейці під ноутбуком, у коробці від Windows, або у листі при онлайн-покупці.

---

## Спосіб 2 — Цифрова ліцензія (автоматично)

Якщо ви раніше мали активовану Windows на цьому комп'ютері — після перевстановлення вона активується автоматично. Цифрова ліцензія прив'язана до апаратного забезпечення.

**Якщо не активувалась автоматично:**
1. `Win + I` → **Система → Активація**
2. **"Усунення неполадок з активацією"**
3. **"Я нещодавно змінив апаратне забезпечення"**
4. Увійди в акаунт Microsoft до якого прив'язана ліцензія

---

## Спосіб 3 — Активація по телефону

Для корпоративних ліцензій або коли інтернет-активація не працює:

```cmd
# Відкрити майстер телефонної активації
slui 4
```

1. Вибери країну → **"Далі"**
2. Зателефонуй на безкоштовний номер Microsoft
3. Продиктуй **Ідентифікаційний номер встановлення** (54 цифри)
4. Отримай **Ідентифікаційний номер підтвердження**
5. Введи його в майстер

---

## Спосіб 4 — Прив'язка до акаунту Microsoft

Прив'яжи ліцензію до акаунту — тоді при заміні комп'ютера зможеш активувати знову:

1. `Win + I` → **Система → Активація**
2. **"Додати акаунт Microsoft"**
3. Увійди або створи акаунт
4. Ліцензія прив'яжеться до профілю

## Вирішення помилок активації

### Помилка 0xC004F213 — ключ не підходить для цієї редакції
Ключ від Windows Home не підійде для Windows Pro. Переконайся що редакція співпадає.
```powershell
# Перевірити редакцію
winver
# або
Get-WindowsEdition -Online
```

### Помилка 0x803F7001 — Windows не активовано, немає ключа
```powershell
# Перевірити вбудований ключ BIOS
wmic path SoftwareLicensingService get OA3xOriginalProductKey
```
Якщо ключ є — введи його через `slmgr /ipk`.

### Помилка 0xC004C003 — заблокований ключ
Ключ використовується на занадто багатьох пристроях. Зверніться до Microsoft Support.

### Помилка 0x8007007B — невірний формат ключа
Перевір що ввів ключ правильно — 25 символів, без пробілів зайвих.

## Часті питання

### Чи можна перенести ліцензію на інший комп'ютер?
- **Retail ліцензія** (куплена окремо) — так, можна перенести
- **OEM ліцензія** (йшла з комп'ютером) — ні, прив'язана до материнської плати
- **Цифрова ліцензія через Microsoft акаунт** — так, через усунення неполадок

### Що буде якщо не активувати Windows?
- Водяний знак "Активуйте Windows" на робочому столі
- Персоналізація заблокована (шпалери, кольори, теми)
- Деякі параметри недоступні
- Функціональність не обмежується — Windows повністю працює

### Скільки пристроїв можна активувати одним ключем?
- **Retail** — 1 пристрій одночасно (можна перенести)
- **OEM** — 1 пристрій назавжди
- **Корпоративні ліцензії** — залежить від угоди
