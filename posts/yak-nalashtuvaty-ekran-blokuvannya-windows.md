Екран блокування — перше що бачиш після пробудження ПК. Ось як його налаштувати під себе і підвищити безпеку.

---

## Змінити фон екрану блокування

`Win + I` → **Персоналізація** → **Екран блокування**

Варіанти фону:
- **Windows Spotlight** — автоматично змінює зображення від Microsoft (включає рекламу)
- **Зображення** — одне фото на вибір
- **Слайдшоу** — чергування фото з вибраної папки

Для слайдшоу: вибери **Слайдшоу** → **Додати папку** → вкажи папку з фото.

---

## Вимкнути Windows Spotlight (прибрати рекламу)

Spotlight показує "цікаві факти" і рекламні пропозиції. Щоб прибрати:

`Win + I` → **Персоналізація** → **Екран блокування** → змінити **Windows Spotlight** на **Зображення**.

---

## Додати інформацію на екран блокування

`Win + I` → **Персоналізація** → **Екран блокування** → **Стан екрана блокування** → вибери програму що показуватиме детальну інформацію (наприклад Погода або Календар).

Нижче можна додати до 7 програм що показують значки зі сповіщеннями.

---

## Налаштувати автоблокування

**Через Параметри:**
`Win + I` → **Система** → **Живлення і сон** → **Екран** → вибери час до вимкнення екрана.

**Через заставку (з паролем):**
`Win + R` → `scrnsave.scr` або знайди **Параметри заставки** в пошуку → встанови час → увімкни **Під час відновлення показувати екран входу**.

**Через GPO:**
```
User Configuration → Administrative Templates →
Control Panel → Personalization
→ Screen saver timeout → 300 секунд
→ Password protect the screen saver → Enabled
```

**Через реєстр:**
```powershell
# Автоблокування через 5 хвилин
Set-ItemProperty -Path "HKCU:\Control Panel\Desktop" `
  -Name "ScreenSaveTimeOut" -Value "300"
Set-ItemProperty -Path "HKCU:\Control Panel\Desktop" `
  -Name "ScreenSaveActive" -Value "1"
Set-ItemProperty -Path "HKCU:\Control Panel\Desktop" `
  -Name "ScreenSaverIsSecure" -Value "1"
```

## Приховати ім'я користувача на екрані блокування

За замовчуванням Windows показує ім'я останнього користувача.

```powershell
Set-ItemProperty `
  -Path "HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System" `
  -Name "DontDisplayLastUserName" -Value 1 -Type DWord
```

Або: `secpol.msc` → **Локальні політики** → **Параметри безпеки** → **Інтерактивний вхід: не відображати ім'я останнього користувача** → **Увімкнено**.

---

## Швидкі клавіші на екрані блокування

- `Win + L` — заблокувати екран негайно
- Будь-яка клавіша — показати час і дату
- Клік на екрані — перейти до поля введення пароля

---

## Резюме

Зміни фон на власне фото або слайдшоу щоб прибрати рекламу Spotlight. Налаштуй автоблокування через Живлення і сон. Для безпеки: увімкни пароль після заставки і приховай ім'я користувача на екрані блокування.
