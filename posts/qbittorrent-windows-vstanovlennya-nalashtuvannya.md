qBittorrent — найкращий безкоштовний торрент-клієнт для Windows. Без реклами, без вбудованого майнера (як uTorrent), відкритий код. Ось як налаштувати його правильно.

---

## qBittorrent vs uTorrent — чому варто перейти

| | qBittorrent | uTorrent |
|-|------------|---------|
| Безкоштовно | ✅ (завжди) | ✅ (з рекламою) |
| Реклама | ❌ | ✅ (багато) |
| Вбудований майнер | ❌ | ⚠️ (був у 2015) |
| Відкритий код | ✅ | ❌ |
| Розмір | ~30 МБ | ~3 МБ |
| Web UI | ✅ | ✅ (Pro) |

## Встановлення

1. Завантаж з [qbittorrent.org](https://www.qbittorrent.org/download) → **"Windows"**
2. Запусти інсталятор — все залиш за замовчуванням
3. При першому запуску дозволь доступ через брандмауер

**Або через winget:**
```powershell
winget install qBittorrent.qBittorrent
```

---

## Основні налаштування

### Швидкість завантаження і роздачі

```
Інструменти → Параметри → Швидкість
```

- **Глобальний ліміт завантаження:** залиш 0 (без ліміту) або встанови 80% від швидкості каналу
- **Глобальний ліміт роздачі:** 50–100 КБ/с якщо хочеш обмежити

**Швидко змінити ліміти:** ПКМ на іконці в треї → Обмежити швидкість

### Порт з'єднання

```
Інструменти → Параметри → З'єднання → Порт для вхідних з'єднань
```

Зміни стандартний порт на будь-який від 10000 до 65535 (наприклад 52413). Це покращує швидкість і анонімність.

**Переадресація порту на роутері:**
Для максимальної швидкості відкрий цей порт в налаштуваннях роутера (Port Forwarding).

### Кількість з'єднань

```
Інструменти → Параметри → З'єднання
```

| Налаштування | Рекомендоване значення |
|-------------|----------------------|
| Макс. з'єднань | 500 |
| Макс. з'єднань на торрент | 100 |
| Макс. завантажень одночасно | 3–5 |
| Макс. активних роздач | 5–10 |

## Шифрування трафіку

```
Інструменти → Параметри → BitTorrent → Шифрування
```

Встанови **"Увімкнути"** — шифрує торрент трафік і ускладнює блокування провайдером.

---

## VPN з qBittorrent — прив'язка до інтерфейсу

Якщо використовуєш VPN — прив'яжи qBittorrent до VPN інтерфейсу. Якщо VPN відключиться — торрент зупиниться автоматично (kill switch).

```
Інструменти → Параметри → Додатково → Мережевий інтерфейс
```

Вибери інтерфейс VPN (зазвичай "tun0" або назва VPN адаптера).

---

## RSS і автоматичне завантаження

qBittorrent вміє автоматично завантажувати нові серії або релізи через RSS:

```
Вигляд → RSS Reader
```

1. Додай RSS посилання → **"+"**
2. Налаштуй правило: **"RSS" → "Download Rules"**
3. Вкажи фільтр (назва серіалу, якість)
4. qBittorrent буде автоматично завантажувати нові епізоди

---

## Web UI — керування через браузер

Корисно для керування завантаженнями з іншого пристрою або сервера:

```
Інструменти → Параметри → Web UI
```

1. Увімкни Web UI
2. Встанови порт (за замовчуванням 8080)
3. Задай логін і пароль
4. Відкрий в браузері: `http://localhost:8080`

## Вирішення проблем

### Повільна швидкість завантаження
- Перевір чи відкритий порт: жовтий/зелений трикутник внизу → натисни щоб перевірити
- Увімкни DHT, PEX, Local Peer Discovery в Налаштування → BitTorrent
- Перевір ліміти швидкості

### qBittorrent блокує весь інтернет
- Зменш кількість з'єднань
- Обмеж швидкість завантаження до 80% від максимуму каналу

### Торрент завантажується але не сідується
Нормально для непопулярних торрентів. Чекай або знайди торрент з більшою кількістю сідерів.
