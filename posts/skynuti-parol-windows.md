Метод скидання залежить від того який тип акаунту — Microsoft або локальний.

---

## Спосіб 1: Акаунт Microsoft — скидання онлайн (найпростіше)

Якщо входиш через email Microsoft:

1. На екрані входу → введи неправильний пароль → **Забули пароль?**
2. Відкрий на іншому пристрої: `account.live.com/password/reset`
3. Введи email → підтверди через SMS або резервний email
4. Встанови новий пароль

---

## Спосіб 2: Локальний акаунт — контрольні питання

1. На екрані входу введи неправильний пароль
2. Натисни **Скинути пароль**
3. Відповідай на контрольні питання
4. Встанови новий пароль

---

## Спосіб 3: Скидання з іншого адмін акаунту

```powershell
# Скинути пароль
$pass = ConvertTo-SecureString "НовийПароль123!" -AsPlainText -Force
Set-LocalUser -Name "Ім'яКористувача" -Password $pass

# Або через CMD
net user ІмяКористувача НовийПароль123!
```

---

## Спосіб 4: Завантажувальна флешка + CMD

Для локальних акаунтів коли інші методи не підходять:

1. Завантажся з USB-флешки Windows
2. На екрані вибору мови: `Shift + F10` → відкриється CMD
3. Замінюємо кнопку спеціальних можливостей на CMD:

```cmd
move C:\Windows\System32\utilman.exe C:\Windows\System32\utilman.exe.bak
copy C:\Windows\System32\cmd.exe C:\Windows\System32\utilman.exe
```

4. Перезавантажся звично → на екрані входу натисни кнопку спеціальних можливостей
5. Відкриється CMD → скидаємо пароль:

```cmd
net user ТвоєІм'я НовийПароль123!
```

6. Після входу відновлюємо файл:

```cmd
move C:\Windows\System32\utilman.exe.bak C:\Windows\System32\utilman.exe
```

## Часті питання

### Чи видаляться файли при скиданні пароля?

Ні. Скидання пароля ніколи не видаляє файли або програми.

### Microsoft акаунт але немає інтернету — що робити?

Потрібен інтернет для скидання Microsoft акаунту. Підключись через кабель або мобільний роутер. Якщо неможливо — метод флешки працює тільки для локальних акаунтів.

---

## Резюме

Microsoft акаунт: скидання на account.live.com. Локальний з питаннями: кнопка "Скинути пароль". Є інший адмін: `net user`. Без нічого: флешка + метод utilman.exe.
