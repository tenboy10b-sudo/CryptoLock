Windows має кілька режимів економії енергії — і вони суттєво відрізняються. Ось коли що використовувати і як налаштувати.

---

## Різниця між режимами

| Режим | Що відбувається | Споживання | Час виходу |
|-------|----------------|------------|------------|
| **Сон** | RAM тримає стан, диск вимкнений | Мале | 2–5 секунд |
| **Гібернація** | Стан збережено на диск, ПК вимкнений | Нуль | 10–30 секунд |
| **Гібридний сон** | Як сон + копія на диску | Мале | 2–5 секунд |

**Сон** — для коротких перерв (відійшов від ПК на годину).
**Гібернація** — для тривалого вимкнення з збереженням стану (ноутбук в сумці).
**Гібридний сон** — для десктопів: якщо світло вимкнеться під час сну — дані не втратяться.

---

## Налаштування кнопки живлення і кришки

`Win + I` → **Система** → **Живлення і сон** → **Додаткові параметри живлення** → **Вибрати дії кнопок живлення**

Або: `Win + R` → `control powercfg.cpl,,3`

Налаштуй окремо для **від мережі** і **від батареї**:
- **При натисканні кнопки живлення**: сон / гібернація / вимкнення
- **При закритті кришки** (ноутбук): сон / гібернація / нічого
- **При натисканні кнопки сну**: сон / гібернація

---

## Увімкнути гібернацію

На деяких ПК гібернація вимкнена за замовчуванням:

```cmd
powercfg /hibernate on
```

Вимкнути (звільняє місце на диску рівне обсягу RAM):
```cmd
powercfg /hibernate off
```

---

## Налаштувати таймаут через PowerShell

```powershell
# Сон через 30 хвилин від батареї, 1 годину від мережі
powercfg /change standby-timeout-dc 30
powercfg /change standby-timeout-ac 60

# Гібернація через 2 години від батареї
powercfg /change hibernate-timeout-dc 120

# Ніколи не переходити в сон від мережі
powercfg /change standby-timeout-ac 0
```

---

## Запобігти переходу в сон при активній задачі

Якщо виконується довга операція (завантаження, рендеринг) і ПК не повинен засинати:

```powershell
# Тимчасово заборонити сон (до наступного завантаження)
powercfg /requestsoverride process powershell.exe system
```

Або використай **Caffeine** — безкоштовна утиліта що імітує натискання клавіші щоб не давати ПК заснути.

---

## Якщо ПК не виходить з режиму сну

```powershell
# Переглянути що дозволено будити ПК
powercfg /devicequery wake_armed

# Заборонити мережевому адаптеру будити ПК
powercfg /devicedisablewake "Intel(R) Ethernet Connection"
```

Або в Device Manager → мережевий адаптер → **Властивості** → **Керування живленням** → зніми **Дозволити цьому пристрою виводити комп'ютер із режиму сну**.

---

## Резюме

Для ноутбука: сон при закритті кришки вдома, гібернація при виході з дому. Для десктопу: гібридний сон — найкращий баланс. `powercfg /hibernate on` якщо гібернація недоступна в меню.
