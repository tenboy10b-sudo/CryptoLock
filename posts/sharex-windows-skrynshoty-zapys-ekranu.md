ShareX — найфункціональніший безкоштовний інструмент для скріншотів і запису екрану на Windows. Відкритий код, без реклами, з підтримкою 80+ хмарних сервісів для завантаження.

---

## Встановлення

```powershell
winget install ShareX.ShareX
```
Або завантаж з [getsharex.com](https://getsharex.com) — є портативна версія без встановлення.

---

## Скріншоти

### Типи захоплення

| Тип | Клавіша за замовчуванням | Опис |
|-----|------------------------|------|
| Повний екран | `Print Screen` | Весь екран |
| Активне вікно | `Alt+Print Screen` | Поточне вікно |
| Область | `Ctrl+Print Screen` | Вибрати мишею |
| Прокрутка | — | Довга сторінка з прокруткою |
| Вікно з меню | — | Захопити відкрите меню |

### Налаштувати гарячі клавіші
```
Hotkey settings → додай або змінюй будь-яку комбінацію
```

## Запис екрану

```
Capture → Screen recording
```

1. Вибери область або повний екран
2. Натисни **Start**
3. Стоп — через системний трей або гарячу клавішу

### Налаштування запису
```
Task settings → Screen recording
```
- **FFmpeg** — встановлюється автоматично при першому записі
- Формат: MP4 (H.264) або GIF
- FPS: 30 або 60

### Запис GIF
```
Capture → Screen recording (GIF)
```
GIF автоматично оптимізується за розміром.

## OCR — розпізнавання тексту

ShareX вміє розпізнавати текст із скріншотів:

```
Capture → Capture text (OCR)
```

1. Вибери область з текстом
2. ShareX розпізнає і скопіює в буфер обміну

Підтримує: англійську, українську та інші мови (потрібен відповідний мовний пакет Windows).

## Автоматичне завантаження

ShareX може автоматично завантажувати скріншоти на 80+ сервісів:

```
Destinations → Image uploader
```

Популярні варіанти:
- **Imgur** — найпростіший, без реєстрації
- **Google Drive** — якщо є акаунт
- **Dropbox** — автосинхронізація
- **FTP/SFTP** — власний сервер
- **LocalHost** — локальний сервер

Після завантаження ShareX копіює посилання в буфер обміну автоматично.

---

## Workflow автоматизація

Головна особливість ShareX — **Workflows**. Кожна дія може автоматично:
1. Зробити скріншот
2. Відредагувати (водяний знак, рамка)
3. Зберегти локально
4. Завантажити на хмару
5. Скопіювати посилання

```
Task settings → Actions → додай команди після захоплення
```
