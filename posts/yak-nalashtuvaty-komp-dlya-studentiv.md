Правильно налаштований ПК заощаджує час і допомагає концентруватись. Ось що варто встановити і налаштувати для навчання.

---

## Організація файлів

Створи зрозумілу структуру папок:

```
📁 Навчання
├── 📁 2025-2026
│   ├── 📁 Математика
│   ├── 📁 Програмування
│   └── 📁 Англійська
└── 📁 Ресурси
    ├── 📁 Книги
    └── 📁 Шаблони
```

Назви файлів: `2026-05-15_Лекція_Алгоритми.pdf` — дата на початку дозволяє сортувати хронологічно.

---

## Резервне копіювання (критично важливо)

Курсові, дипломні і реферати зникають разом з дисками.

Мінімум: увімкни OneDrive і синхронізуй папку Документи:

Правий клік на іконці OneDrive → **Налаштування** → **Резервне копіювання** → увімкни **Документи**.

Безкоштовно 5 ГБ — цього достатньо для більшості навчальних матеріалів.

---

## Режим фокусування

`Win + I` → **Система** → **Фокус** → налаштуй сеанси по 25-45 хвилин.

Або встанови **Focus To-Do** з Microsoft Store — поєднує таймер Pomodoro і список завдань.

---

## Вимкнути відволікаючі сповіщення

```powershell
# Режим "Не турбувати" під час занять
Set-ItemProperty -Path "HKCU:\Software\Microsoft\Windows\CurrentVersion\Notifications\Settings" `
  -Name "NOC_GLOBAL_SETTING_TOASTS_ENABLED" -Value 0 -Type DWord
```

Або: `Win + I` → **Система** → **Сповіщення** → вимкни для соцмереж і месенджерів під час роботи.

## Корисні безкоштовні програми

**Нотатки:**
- **Obsidian** — нотатки у Markdown, локальні файли, безкоштовний
- **Notion** (веб) — бази знань, розклад, завдання

**PDF і документи:**
- **Sumatra PDF** — легкий переглядач PDF
- **LibreOffice** — безкоштовна альтернатива Microsoft Office

**Концентрація:**
- **Cold Turkey** — блокує сайти за розкладом
- **Focus To-Do** — Pomodoro таймер

**Словники і переклад:**
- **DeepL** для Windows — кращий переклад ніж Google для технічних текстів
- **GoldenDict** — офлайн словники

## Організація вікон

Для роботи з кількома вікнами одночасно (наприклад конспект і джерело):

`Win + Z` → вибери макет розділення екрану.

Або `Win + ←/→` — швидке розміщення вікна ліворуч/праворуч.

---

## Швидкий доступ до навчальних папок

Закріпи папку з навчальними матеріалами в Швидкому доступі Провідника:

Правий клік на папці → **Закріпити в Швидкому доступі**.

---

## Голосовий введення для нотаток

`Win + H` — диктовка в будь-якому текстовому полі. Корисно для швидкого запису думок або транскрибування лекцій.

---

## Нічний режим для вечірніх занять

`Win + I` → **Система** → **Дисплей** → **Night Light** → встанови включення о 20:00.

Зменшує синє світло і знижує навантаження на очі при вечірньому навчанні.

---

## Резюме

Мінімальний набір: OneDrive для бекапу + Obsidian або Notion для нотаток + Focus режим + організована структура папок. Це займає 30 хвилин на налаштування і заощаджує годинни протягом семестру.
