Windows показує помилку активації після перевстановлення, заміни материнської плати або просто так? Ось повний гайд по кодах помилок і способах активації.

---

## Перевірити поточний статус активації

```powershell
# Статус активації
slmgr /xpr

# Детальна інформація
slmgr /dlv

# Через WMI
Get-WmiObject SoftwareLicensingProduct |
    Where-Object {$_.PartialProductKey -and $_.Name -like '*Windows*'} |
    Select-Object Name, LicenseStatus, Description
```

**LicenseStatus:**
- `1` — Licensed (активований)
- `0` — Unlicensed (не активований)
- `5` — Notification (ліцензія закінчується)

## Коди помилок і рішення

### 0xC004F213 — Апаратні зміни

**Причина:** Змінив материнську плату або зробив суттєвий апгрейд — Windows вважає це новим ПК.

**Рішення 1 — Активація через телефон:**
```
Win + R → slui 4
Вибери країну → зателефонуй → введи ID підтвердження
```

**Рішення 2 — Через Troubleshooter:**
```
Параметри → Оновлення → Активація →
"Усунення неполадок активації"
```

**Рішення 3 — Зв'язати ліцензію з Microsoft акаунтом** (до апгрейду):
```
Параметри → Активація → Додати обліковий запис Microsoft
```
Після цього при зміні заліза можна реактивувати через акаунт.

---

### 0x803F7001 — Ліцензія не знайдена

**Причина:** OEM ліцензія прив'язана до старої материнської плати або ключ невалідний.

```powershell
# Перевірити ключ вбудований в BIOS/UEFI
(Get-WmiObject -query 'select * from SoftwareLicensingService').OA3xOriginalProductKey
```

Якщо ключ є — активуй ним:
```powershell
slmgr /ipk XXXXX-XXXXX-XXXXX-XXXXX-XXXXX
slmgr /ato
```

---

### 0xC004C003 — Ключ заблокований

**Причина:** Ключ вже використовується на іншому ПК або продавець надав неліцензійний ключ.

**Рішення:** Активація через телефон або новий ліцензійний ключ.

---

### 0x8007007B — Неправильний формат ключа

```powershell
# Перевірити і ввести ключ заново
slmgr /ipk XXXXX-XXXXX-XXXXX-XXXXX-XXXXX
slmgr /ato
```

---

### 0xC004F074 — Сервер активації недоступний

**Причина:** Проблеми з інтернетом або заблоковані сервери активації.

```powershell
# Перевірити підключення до серверів активації
Test-NetConnection -ComputerName activation.sls.microsoft.com -Port 443
Test-NetConnection -ComputerName go.microsoft.com -Port 80

# Активувати примусово
slmgr /ato

# Або через інший сервер
slmgr /skms kms8.msguides.com
slmgr /ato
```

---

### 0x803FA067 — Потрібен вхід до Microsoft акаунту

```
Параметри → Активація → Увійдіть за допомогою облікового запису Microsoft
```

## Активація через телефон (безкоштовно, офіційно)

Для складних випадків коли онлайн не працює:

```
Win + R → slui 4
```

1. Вибери "Україна" або іншу країну
2. Зателефонуй на номер що показує Windows
3. Введи 9-значний Installation ID (покаже на екрані)
4. Отримай Confirmation ID від оператора
5. Введи Confirmation ID → Активувати

---

## Активація після перевстановлення Windows

Якщо ліцензія була ліцензійна і ти перевстановив на той самий ПК:

```powershell
# Windows автоматично знайде Digital License
# Просто підключись до інтернету і чекай

# Або примусово:
slmgr /ato
```

**Digital License** прив'язана до заліза — не до ключа. Якщо залізо не змінилось — активується автоматично.

---

## Корпоративна активація (KMS)

Для Windows Pro/Enterprise в домені:

```powershell
# Перевірити KMS сервер
slmgr /skms kms-server.company.local
slmgr /ato

# Статус KMS активації
slmgr /dlv | Select-String "KMS"
```

## Перевірити яка редакція Windows активована

```powershell
# Редакція і статус
Get-WindowsEdition -Online
winver

# Доступні редакції для апгрейду
Get-WindowsEdition -Online -Available
```
