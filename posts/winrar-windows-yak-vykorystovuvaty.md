WinRAR — найстаріший і найвідоміший архіватор для Windows. Технічно він "умовно-безкоштовний" з 40-денним тріалом який ніколи насправді не закінчується. Але є нюанси.

---

## WinRAR безкоштовно — як це працює

WinRAR після 40 днів показує вікно з пропозицією купити ліцензію. Якщо натиснути **"Continue"** — він продовжує працювати повністю. Вічно.

Це відоме "вічне тріал" — WinRAR навмисно не блокує функції після тріалу. Розробники розраховують що корпоративні клієнти куплять ліцензію (~$36).

**Але є краща альтернатива:** 7-Zip безкоштовний без будь-яких вікон, відкритий код і стискає краще.

---

## Встановлення WinRAR

1. Завантаж з [rarlab.com](https://www.rarlab.com/download.htm)
2. Вибери 64-bit для Windows
3. При встановленні вибери асоціації форматів

## Основні операції

### Розпакувати архів
Правою кнопкою на архів:
- **"Розпакувати файли..."** — вибрати папку
- **"Розпакувати тут"** — в поточну папку
- **"Розпакувати в [назва папки]\"** — створить підпапку

### Створити RAR архів
1. Вибери файли → ПКМ → **"Додати до архіву..."**
2. Налаштуй:

| Параметр | Рекомендація |
|---------|-------------|
| Формат | RAR5 (кращий) або ZIP (сумісніший) |
| Метод стиснення | Нормальний або Найкращий |
| Розмір словника | 128 МБ для великих файлів |

### Шифрування паролем
При створенні → **"Встановити пароль"**:
- Введи пароль двічі
- Увімкни **"Шифрувати імена файлів"**
- Метод шифрування: AES-256 (автоматично в RAR5)

### Розбивка на частини
Поле **"Розбити на томи розміром"**:
- `700 МБ` — для CD
- `4092 МБ` — для FAT32 USB
- `25000 МБ` — для хмари

## Відновлення пошкоджених архівів

Унікальна перевага RAR над ZIP:

**При створенні — додати інформацію для відновлення:**
```
Створити архів → Додатково → Розмір запису відновлення → 5%
```

**При розпакуванні пошкодженого архіву:**
```
Команди → Відновити архів
```
або через командний рядок:
```cmd
rar r архів.rar
```

## Команди WinRAR

```cmd
:: Розпакувати
"C:\Program Files\WinRAR\WinRAR.exe" x архів.rar C:\Destination\

:: Створити архів
"C:\Program Files\WinRAR\WinRAR.exe" a -m5 архів.rar C:\Folder\

:: З паролем
"C:\Program Files\WinRAR\WinRAR.exe" a -hp"Пароль" архів.rar файли

:: Перевірити цілісність
"C:\Program Files\WinRAR\WinRAR.exe" t архів.rar
```

## WinRAR vs 7-Zip — що вибрати

| | WinRAR | 7-Zip |
|-|--------|-------|
| Ціна | "Безкоштовно" (тріал назавжди) | Повністю безкоштовно |
| Відкритий код | ❌ | ✅ |
| Власний формат | RAR (кращий для відновлення) | 7z (краще стиснення) |
| Відновлення архівів | ✅ (унікальна функція) | ❌ |
| Стиснення | Хороше | Краще |
| Реклама | Спливаюче вікно | ❌ |

**Висновок:** якщо важлива функція відновлення пошкоджених архівів — WinRAR. В усіх інших випадках — 7-Zip.
