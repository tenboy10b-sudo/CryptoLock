HWiNFO — найповніший безкоштовний інструмент для моніторингу заліза на Windows. Показує температури, напруги, частоти і навантаження в реальному часі — для CPU, GPU, материнської плати і дисків.

---

## Встановлення

```powershell
winget install REALiX.HWiNFO
```
Або з [hwinfo.com](https://www.hwinfo.com/download/) — є портативна версія без встановлення.

---

## Перший запуск

При старті HWiNFO пропонує два режими:

| Режим | Опис |
|-------|------|
| **Summary only** | Короткий огляд системи |
| **Sensors only** | Тільки датчики в реальному часі (найкорисніший) |
| Без галочок | Повний огляд + датчики |

Для моніторингу температур — вибери **"Sensors only"** і натисни **"Start"**.

---

## Розуміння датчиків

### CPU датчики
- **CPU Package** — загальна температура процесора
- **CPU Core #N** — температура окремого ядра
- **CPU Core Voltage** — напруга на процесорі
- **CPU Power** — споживання енергії в ватах

### GPU датчики
- **GPU Temperature** — температура відеокарти
- **GPU Core Load** — навантаження GPU у %
- **GPU Memory Used** — використання VRAM
- **GPU Fan Speed** — швидкість вентилятора у RPM

### Диски
- **Drive Temperature** — температура HDD/SSD
- **SSD Wear Level** — знос SSD у %
- **Drive Read/Write Rate** — швидкість читання/запису

---

## Безпечні температури

| Компонент | Норма | Небезпечно |
|----------|-------|-----------|
| CPU (idle) | 30–50°C | >80°C |
| CPU (навантаження) | 60–85°C | >95°C |
| GPU (idle) | 30–45°C | >85°C |
| GPU (навантаження) | 65–85°C | >90°C |
| HDD | 30–45°C | >55°C |
| SSD SATA | 30–50°C | >70°C |
| NVMe SSD | 40–65°C | >85°C |

## Налаштування відображення датчиків

### Сховати непотрібні датчики
ПКМ на датчик → **"Disable"** — прибирає з списку.

### Переставити датчики
Перетягни рядки мишею для зручного групування.

### Виділити кольором
ПКМ на датчик → **"Change Row Color"** — виділи важливі червоним або зеленим.

---

## Логування даних

Запис показників в CSV файл для аналізу:

```
File → Log Sensors → Start Logging to CSV
```

Потім відкрий в Excel або Google Sheets для аналізу температур під навантаженням.

---

## Інтеграція з RTSS (Rivatuner Statistics Server)

Показ датчиків поверх ігор (OSD overlay):

1. Встанови [RTSS](https://www.guru3d.com/files-details/rtss-rivatuner-statistics-server-download.html)
2. В HWiNFO: датчик → ПКМ → **"Show in OSD"** → вибери RTSS
3. Під час гри — показники відображаються поверх зображення

## Часті питання

### Чому CPU температура стрибає?
Нормально — процесор підвищує частоту при навантаженні (Boost) і температура зростає. Якщо тримається >90°C під навантаженням — перевір термопасту і кулер.

### SSD Wear Level 50% — це критично?
Ні. Wear Level показує залишковий ресурс. 50% = ще половина ресурсу залишилась.
