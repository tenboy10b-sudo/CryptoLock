Бекап — це єдиний захист від втрати даних. Жорсткий диск може зламатись, вірус може зашифрувати файли, Windows може перестати завантажуватись. Ось як налаштувати резервне копіювання без сторонніх програм.

---

## Стратегія 3-2-1

Надійний бекап — це:
- **3** копії даних
- На **2** різних носіях
- **1** з яких зберігається поза домом (хмара або інше місце)

Мінімум для домашнього ПК: оригінал + зовнішній диск + хмара.

---

## Спосіб 1: File History (для файлів)

File History автоматично копіює файли з папок Документи, Зображення, Робочий стіл, Відео тощо.

**Налаштування:**
`Win + I` → **Система** → **Сховище** → **Розширені параметри сховища** → **Параметри резервного копіювання** → **Додати диск** → вибери зовнішній диск.

Або: `Win + R` → `control /name Microsoft.FileHistory`

**Налаштування частоти:**
**Додаткові параметри** → **Зберігати копії файлів**: щогодини (за замовчуванням) або частіше.

**Відновлення файлу:**
Правий клік на файлі або папці → **Відновити попередні версії** → вибери версію.

---

## Спосіб 2: Windows Backup (повний образ)

Створює образ всього диска — відновлює всю систему з нуля.

`Win + R` → `sdclt` → **Створити образ системи** → вибери зовнішній диск → **Почати резервне копіювання**.

Займає 30–120 хвилин залежно від обсягу. Для відновлення потрібен диск відновлення або USB з Windows.

---

## Спосіб 3: robocopy (автоматизований)

Robocopy — вбудований в Windows інструмент для копіювання з підтримкою синхронізації.

```powershell
# Синхронізувати папку Документи на зовнішній диск
robocopy "C:\Users\$env:USERNAME\Documents" "D:\Backup\Documents" `
  /MIR /R:3 /W:5 /LOG:"D:\Backup\robocopy.log"
```

Параметри:
- `/MIR` — дзеркальна копія (видаляє файли яких немає в джерелі)
- `/R:3` — 3 спроби при помилці
- `/W:5` — чекати 5 секунд між спробами
- `/LOG` — зберігати лог

**Автоматизація через Task Scheduler:**
```powershell
$action = New-ScheduledTaskAction -Execute "robocopy.exe" `
  -Argument "C:\Users\$env:USERNAME\Documents D:\Backup\Documents /MIR /R:3 /W:5"
$trigger = New-ScheduledTaskTrigger -Daily -At "02:00"
Register-ScheduledTask -TaskName "Daily Backup" `
  -Action $action -Trigger $trigger -RunLevel Highest -Force
```

## Спосіб 4: OneDrive (хмарний бекап)

Для критичних папок — увімкни синхронізацію з OneDrive:

Права кнопка на іконці OneDrive в треї → **Параметри** → **Резервне копіювання** → увімкни для Робочого столу, Документів, Зображень.

5 ГБ безкоштовно. Microsoft 365 дає 1 ТБ.

---

## Перевірити що бекап працює

```powershell
# Перевірити статус File History
$fh = Get-WmiObject -Namespace "root\cimv2" -Class "Win32_Volume" -EA SilentlyContinue
if ($fh) { "File History volumes found" } else { "Check File History settings" }

# Перевірити останній бекап robocopy в лозі
Get-Content "D:\Backup\robocopy.log" | Select-Object -Last 10
```

## Що точно треба бекапити

**Обов'язково:**
- Документи, фото, відео
- Паролі (KeePass база або експорт з браузера)
- Ключі продуктів (Windows, Office)
- Проекти і робочі файли

**Не обов'язково:**
- Папка Windows — відновлюється перевстановленням
- Встановлені програми — перевстановлюються
- Тимчасові файли

---

## Резюме

Мінімальний бекап: File History на зовнішній диск + OneDrive для критичних файлів. Для повного захисту: додай щомісячний образ системи через Windows Backup. Robocopy + Task Scheduler для гнучкої автоматизації будь-яких папок.
