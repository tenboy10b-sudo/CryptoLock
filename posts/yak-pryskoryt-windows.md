Windows гальмує з різних причин — і рішення залежить від того, яка саме. Перш ніж щось вимикати чи купувати новий SSD, варто 2 хвилини витратити на діагностику: інакше можна довго боротись не з тією проблемою. Цей гайд веде по порядку — від визначення вузького місця до конкретних кроків для твоєї ситуації (слабкий ПК, перегрітий ноутбук, повільне завантаження).

---

## Крок 1 — Знайти вузьке місце, перш ніж щось міняти

`Ctrl + Shift + Esc` → вкладка **Продуктивність** → дивись CPU, Memory, Disk, GPU.

| Показник | Норма | Проблема |
|---|---|---|
| CPU | < 70% | > 90% постійно |
| RAM | < 80% | > 90% або активна підкачка |
| Диск | < 50% | 100% постійно |

Через PowerShell — той самий знімок одним рядком:

```powershell
Get-Counter '\Processor(_Total)\% Processor Time',
    '\Memory\Available MBytes',
    '\PhysicalDisk(_Total)\% Disk Time' |
    Select-Object -ExpandProperty CounterSamples |
    Select-Object Path, CookedValue
```

Перейди на вкладку **Процеси**, посортуй за ресурсом що на 100% — побачиш конкретного винуватця, а не гадатимеш.

**Якщо жоден показник не зашкалює, а система все одно "відчувається" повільною** — причина, найімовірніше, в автозавантаженні й фонових службах (крок 2), а не в залізі.

## Крок 2 — Універсальні кроки, які дають 80% ефекту за 10 хвилин

Незалежно від причини, ці кроки безпечні й майже завжди помітні.

### Вимкнути зайве автозавантаження (найбільший ефект)

Кожна програма в автозавантаженні уповільнює старт і їсть ресурси у фоні весь час роботи.

`Ctrl + Shift + Esc` → **Автозавантаження** → сортуй за **Вплив на запуск** → вимкни все з **Високим** впливом що не потрібне одразу після входу.

```powershell
# Переглянути всі записи автозавантаження
Get-CimInstance Win32_StartupCommand | Select-Object Name, Command, Location | Format-Table -AutoSize
```

**Безпечно вимикати:** Spotify, Discord, Steam, Teams (особистий), OneDrive (якщо не синхронізуєш постійно), Adobe updaters, Skype, Dropbox/Google Drive.
**НЕ чіпати:** антивірус, аудіо-драйвери (Realtek), відео-драйвери, Windows Security.

### Переключитись на High Performance

```powershell
# High Performance
powercfg /setactive 8c5e7fda-e8bf-4a96-9a85-a6e23a8c635c

# Ultimate Performance (максимум для стаціонарного ПК)
powercfg /duplicatescheme e9a42b02-d5df-448d-aa00-03f14749eb61
powercfg /setactive e9a42b02-d5df-448d-aa00-03f14749eb61
```

На ноутбуці став тільки при роботі від мережі — на батареї суттєво скоротить час автономності.

### Вимкнути візуальні ефекти

`Win + R` → `sysdm.cpl` → **Додатково** → **Параметри** (Швидкодія) → **Забезпечити найкращу продуктивність**.

Або точково — залиш тільки згладжування шрифтів і мініатюри замість значків, решту (прозорість, анімації, тіні) вимкни:

```powershell
Set-ItemProperty "HKCU:\Software\Microsoft\Windows\CurrentVersion\Explorer\VisualEffects" -Name "VisualFXSetting" -Value 2
```

### Очистити диск

```powershell
cleanmgr /sageset:1
cleanmgr /sagerun:1

# Або швидко прибрати тимчасові файли напряму
Remove-Item "$env:TEMP\*" -Recurse -Force -EA 0
Remove-Item "C:\Windows\Temp\*" -Recurse -Force -EA 0
```

Знайти що саме займає місце:

```powershell
Get-ChildItem C:\ -Recurse -EA 0 | Sort-Object Length -Descending |
  Select-Object -First 15 FullName, @{N='MB';E={[math]::Round($_.Length/1MB,1)}}
```

Якщо вільного місця на C менше 10-15% — це саме по собі гальмує Windows: системі ніде тримати тимчасові файли й файл підкачки.

## Крок 3 — Служби, драйвери, цілісність системи

### Безпечні для вимкнення служби

```powershell
$services = @(
    'SysMain',          # Superfetch — корисний на HDD, зайвий на SSD
    'WSearch',          # індексування пошуку (вимкни якщо не шукаєш файли часто)
    'DiagTrack',        # телеметрія Microsoft
    'dmwappushservice', # телеметрія
    'Fax',
    'RemoteRegistry',
    'XblGameSave', 'XblAuthManager'  # Xbox-сервіси, якщо не граєш
)
foreach ($s in $services) {
    Stop-Service $s -Force -EA 0
    Set-Service $s -StartupType Disabled -EA 0
}
```

> ⚠️ **SysMain вимикай тільки на SSD.** На HDD він реально корисний — прибереш і тільки погіршиш ситуацію.

### Оновити драйвери, особливо відеокарти

Застарілі GPU-драйвери — одна з найчастіших причин гальмувань і зависань:

```powershell
# Поточна версія + драйвери з помилками
(Get-WmiObject Win32_VideoController).DriverVersion
Get-WmiObject Win32_PnPEntity | Where-Object {$_.ConfigManagerErrorCode -ne 0} | Select-Object Name, ConfigManagerErrorCode
```

Завантажуй тільки з офіційних сайтів — nvidia.com/drivers, amd.com/support — не через сторонні "driver updater" програми.

### Перевірити цілісність системних файлів

```cmd
DISM /Online /Cleanup-Image /RestoreHealth
sfc /scannow
```

Пошкоджені системні файли (після невдалого оновлення, збою живлення, вимкнення посеред запису) можуть непомітно, але суттєво уповільнювати систему.

### Перевірити стан диску

```powershell
Get-PhysicalDisk | Select-Object FriendlyName, HealthStatus, MediaType
Repair-Volume -DriveLetter C -Scan
```

Статус "Caution" або "Warning" — це вже не питання оптимізації, диск треба міняти.

## Сценарій: повільне завантаження системи

Якщо саме СТАРТ Windows довгий (а не робота після) — окремий чекліст.

**Спочатку виміряй реальний час**, щоб було з чим порівнювати після змін:

```powershell
Get-WinEvent -FilterHashtable @{LogName='System'; Id=100; ProviderName='Microsoft-Windows-Diagnostics-Performance'} -MaxEvents 3 |
  Select-Object TimeCreated, @{n='BootMs';e={$_.Properties[0].Value}}
```

Або простіше: `Ctrl+Shift+Esc` → **Автозапуск** → внизу показано час до останнього завантаження BIOS.

**Орієнтир норми:**

| Конфігурація | Норма |
|---|---|
| SSD + мінімум автозапуску | 8-15 сек |
| SSD + звичайний автозапуск | 15-35 сек |
| HDD | 45-90 сек |
| Більше 2 хв на SSD | є проблема |

**Увімкнути Fast Startup** (зберігає стан ядра на диск, скорочує старт на 30-50%):

`Панель керування` → **Параметри живлення** → **Дії кнопок живлення** → **Увімкнути швидкий запуск**

```powershell
Set-ItemProperty "HKLM:\SYSTEM\CurrentControlSet\Control\Session Manager\Power" -Name "HiberbootEnabled" -Value 1
```

> Якщо є подвійне завантаження (Windows + Linux) — Fast Startup краще вимкнути, може блокувати доступ до диску з іншої ОС.

**Перевір заплановані завдання, що спрацьовують при вході:**

```powershell
Get-ScheduledTask | Where-Object { $_.Triggers.CimClass -match "Boot|Logon" -and $_.State -eq "Ready" } |
  Select-Object TaskName, TaskPath | Format-Table -AutoSize
```

**Обмеж Windows Update у фоні одразу після старту:** Параметри → Windows Update → Додаткові параметри → Оптимізація доставки → обмеж до 20%.

**Додатково:** оновлення BIOS іноді пришвидшує POST; вимкнення непотрібних пристроїв у BIOS (зчитувач карт, зайві COM-порти, мережеве завантаження PXE) теж трохи скорочує час до старту Windows.

## Сценарій: ноутбук гальмує, особливо під навантаженням

Якщо ноутбук нормально працює в спокої, але гальмує під час гри чи важкої задачі — ймовірний винуватець **thermal throttling**: процесор перегрівається, і Windows автоматично знижує його частоту щоб уникнути пошкодження.

**Перевірити:** завантаж безкоштовний HWiNFO64 (`winget install REALiX.HWiNFO`) і подивись температуру CPU/GPU під навантаженням.

| | Норма | Небезпечно |
|---|---|---|
| CPU | до 85°C | вище 95°C |
| GPU | до 85°C | вище 90°C |

**Що робити при перегріві:**
- Почистити ноутбук від пилу (раз на рік — найпоширеніша причина)
- Перевірити що вентиляційні отвори не заблоковані
- Не класти ноутбук на ковдру/подушку — блокує забір повітря знизу
- Замінити термопасту (раз на 3-4 роки, 100-200 грн у сервісі)

Пил у кулері — найчастіша причина повільної роботи саме старих ноутбуків, і її часто пропускають, шукаючи проблему в софті.

## Сценарій: слабкий ПК або мало RAM (4-8 ГБ)

Windows 11 офіційно вимагає 4 ГБ RAM, але реально комфортно працює з 8+. На слабшому залізі стандартних кроків вище недостатньо — потрібні додаткові:

**Вимкнути Widgets** (панель новин тягне дані у фоні): `Параметри` → `Персоналізація` → `Панель завдань` → вимкни **Віджети**.

**Вимкнути Game Mode**, якщо не граєш — на слабких ПК він іноді навпаки гальмує звичайну роботу: `Параметри` → `Ігри` → вимкни **Режим гри**.

**Збільшити файл підкачки** — критично важливо при малому RAM:

`sysdm.cpl` → Додатково → Параметри → Додатково → Змінити → зніми "Автоматично" → **Нестандартний розмір**: початковий RAM×1.5, максимальний RAM×3.

**Орієнтовний ефект оптимізацій на слабкому залізі:**

| Дія | RAM | CPU |
|---|---|---|
| Вимкнути ефекти | ~100 МБ | ~5-10% |
| Вимкнути автозапуск | ~200-500 МБ | ~10-20% |
| Вимкнути служби | ~50-200 МБ | ~3-7% |
| Вимкнути Widgets | ~100 МБ | ~2-5% |

**Якщо все одно замало ресурсів** — розглянь легшу ОС: Windows 10 (менш вимоглива), Linux Mint (легка, добре підходить для браузера й документів), або Lubuntu (для ПК з 2 ГБ RAM).

**Перевір чи взагалі варто оптимізувати далі:**

```powershell
(Get-WmiObject Win32_Processor).Name
```

Якщо процесору 2010-2012 років і старший — подальша оптимізація софтом дає мало, CPU сам стає вузьким місцем незалежно від налаштувань.

## Апаратні апгрейди — коли софт-оптимізації вже недостатньо

Якщо після всіх кроків вище все одно повільно — далі працює тільки залізо.

### SSD замість HDD — найбільший ефект з усіх можливих змін

```powershell
Get-PhysicalDisk | Select-Object FriendlyName, MediaType
```

Якщо MediaType показує HDD — це саме по собі головна причина повільної роботи. Перехід на SSD:
- Завантаження: 60-120 сек → 10-15 сек
- Відкриття програм: у 3-5 разів швидше

**Бюджетний варіант:** SSD 240-256 ГБ коштує $25-40 (600-800 грн). Перенести Windows без перевстановлення можна безкоштовними Macrium Reflect Free або Clonezilla.

### RAM — другий за ефектом апгрейд

```powershell
Get-WmiObject Win32_PhysicalMemory | Select-Object @{n='GB';e={$_.Capacity/1GB}}, Speed, DeviceLocator
```

Менше 8 ГБ у 2026 — це вже реальне обмеження для звичайної роботи (браузер з десятком вкладок + офісні програми). Перевір максимум, який підтримує материнська плата, перш ніж купувати (`msinfo32` → модель плати → пошук специфікацій).

### Термопаста — дешево і часто недооцінено

Якщо ПК/ноутбук старший 3-4 років і показує високі температури в простої — заміна термопасти (100-200 грн у сервісі) часто повертає продуктивність без жодних інших витрат.

## Що НЕ допомагає (і навіть шкодить)

- **"Оптимізатори" типу CCleaner** — очищення реєстру не прискорює Windows. У кращому випадку марно, у гіршому — ламає щось потрібне.
- **Відключення Windows Update** — не дає приросту швидкості, зате відкриває критичні вразливості безпеки.
- **Дефрагментація SSD** — SSD не дефрагментують, це шкодить ресурсу диска. Дефрагментація має сенс тільки для HDD.

## Часті питання

### Скільки RAM потрібно для комфортної роботи Windows 11?

Мінімум 8 ГБ. 16 ГБ — якщо працюєш з браузером із багатьма вкладками одночасно з іншими програмами.

### Що дає найбільший ефект, якщо є лише 10 хвилин?

Вимкнути автозавантаження → переключитись на High Performance → очистити диск. Ці три кроки покривають більшість типових випадків гальмування без жодного ризику.

### Чи можна прискорити Windows без перевстановлення?

Так, усі кроки в цьому гайді не вимагають перевстановлення. Чиста установка з флешки — крайній варіант, якщо система накопичила роками сміття й нічого інше не допомогло.

### Skільки має тривати завантаження Windows?

SSD: 10-20 секунд норма. HDD: 45-90 секунд норма. Більше 2 хвилин на SSD — точно є проблема, дивись розділ про повільне завантаження вище.

## Підсумок — з чого почати

1. **Спочатку діагностика** (крок 1) — не вгадуй причину, подивись де реально вузьке місце
2. **Універсальні 10 хвилин** (крок 2) — автозавантаження, план живлення, ефекти, очищення диска
3. **Якщо ноутбук і гальмує під навантаженням** — перевір температури, це часто саме перегрів
4. **Якщо мало RAM або старе залізо** — окремий набір кроків вище, плюс подумай про SSD
5. **SSD — єдиний апгрейд, який варто робити майже завжди**, якщо досі стоїть HDD
