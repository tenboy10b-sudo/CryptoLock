Клацнув на PDF — відкрився браузер замість Acrobat. Зображення відкриваються в Paint замість переглядача. Ось як виправити.

---

## Змінити для одного типу файлів

**Найшвидший спосіб:**
Правий клік на файлі → **Відкрити за допомогою** → **Вибрати іншу програму** → вибери потрібну → постав галочку **Завжди використовувати цю програму** → OK.

---

## Через Параметри

`Win + I` → **Програми** → **Програми за замовчуванням**:

- **Вибрати програму за замовчуванням** — вибери програму і встанови всі її типи файлів
- **Вибрати значення за замовчуванням за типом файлу** — вибери розширення (.pdf, .mp4 тощо) і призначи програму

---

## Типові асоціації що варто змінити

| Тип файлу | Рекомендована програма |
|-----------|------------------------|
| .pdf | Adobe Acrobat Reader або Sumatra PDF |
| .mkv, .mp4 | VLC Media Player |
| .jpg, .png | Windows Photos або IrfanView |
| .docx, .xlsx | Microsoft Office або LibreOffice |
| .zip, .7z | 7-Zip або WinRAR |

---

## Через командний рядок

```powershell
# Переглянути поточні асоціації
cmd /c "assoc" | Select-String ".pdf", ".mp4", ".docx"

# Змінити асоціацію (cmd)
cmd /c 'assoc .pdf=AcroExch.Document.DC'

# Переглянути що відкриває тип
cmd /c 'ftype AcroExch.Document.DC'
```

---

## Відновити стандартні асоціації Windows

Якщо якась програма "захопила" всі типи файлів при встановленні:

`Win + I` → **Програми** → **Програми за замовчуванням** → знайди програму → **Скинути**.

Або:
```powershell
# Скинути всі асоціації до стандартних Windows
cmd /c 'dism /online /cleanup-image /restorehealth'
# Не дуже ефективно. Краще вручну через Параметри
```

Найнадійніший варіант — вручну через Параметри для кожного типу.

---

## Браузер за замовчуванням

`Win + I` → **Програми** → **Програми за замовчуванням** → знайди потрібний браузер (Chrome, Firefox) → **Встановити за замовчуванням**.

Windows 11 вимагає підтвердити для кожного протоколу (http, https) окремо — клікни на кожен і вибери браузер.

---

## Резюме

Правий клік на файлі → Відкрити за допомогою → Вибрати іншу програму → Завжди використовувати. Для масової зміни: Параметри → Програми → Програми за замовчуванням. Браузер за замовчуванням налаштовується там само.
