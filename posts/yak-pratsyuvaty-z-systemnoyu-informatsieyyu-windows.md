`msinfo32` — вбудований інструмент Windows що збирає всю системну інформацію в одному місці. Корисний для діагностики і для підготовки звітів для технічної підтримки.

---

## Відкрити msinfo32

`Win + R` → `msinfo32`

Або: `Win + S` → **Відомості про систему**

---

## Що можна знайти

**Відомості про систему** (головна сторінка):
- Версія і збірка Windows
- Виробник і модель ПК
- Процесор, RAM, тип BIOS (UEFI/Legacy)
- Режим завантаження, Secure Boot, стан TPM

**Ресурси обладнання:**
- Конфлікти і спільний доступ до ресурсів IRQ
- DMA, порти введення/виведення

**Компоненти:**
- Дисплей (GPU, VRAM, драйвер і його версія)
- Диски і розділи
- Мережеві адаптери і їх конфігурація
- Звукові пристрої

**Програмне середовище:**
- Змінні середовища
- Мережеві підключення
- Запущені завдання
- Завантажені модулі

---

## Швидкий пошук

`Ctrl + F` — пошук по всій базі. Наприклад введи "DirectX" щоб знайти версію, або "IPV4" щоб знайти IP адресу.

---

## Знайти конфліктні пристрої

**Ресурси обладнання** → **Конфлікти і спільний доступ** → список пристроїв що конфліктують або ділять ресурси.

Якщо є конфлікти — можлива причина нестабільної роботи обладнання.

---

## Через PowerShell

```powershell
# Аналог деяких полів msinfo32
Get-ComputerInfo | Select-Object `
  WindowsProductName,
  WindowsVersion,
  OsBuildNumber,
  CsManufacturer,
  CsModel,
  CsProcessors,
  CsTotalPhysicalMemory,
  BiosFirmwareType,
  BiosVersion

# BIOS тип (UEFI або Legacy)
(Get-ComputerInfo).BiosFirmwareType

# Secure Boot
Confirm-SecureBootUEFI

# TPM
Get-Tpm | Select-Object TpmPresent, TpmReady
```

## Зберегти звіт для підтримки

`Файл` → **Зберегти** → зберігає `.nfo` файл (відкривається тільки в msinfo32).

Або: `Файл` → **Експортувати** → зберігає у текстовий файл що можна відкрити будь-де і надіслати в підтримку.

```powershell
# Зберегти через командний рядок
msinfo32 /report "C:\system-info.txt"
```

---

## Що перевіряти при проблемах

**Система не завантажується після оновлення:**
Дивись **Програмне середовище** → **Служби** — перевір чи немає нових проблемних служб.

**Незрозумілі BSOD:**
Дивись **Компоненти** → **Відображення** — версія і дата драйвера відеокарти.

**Мережеві проблеми:**
Дивись **Компоненти** → **Мережа** → **Адаптер** — детальна конфігурація.

---

## Резюме

`msinfo32` — перший інструмент що відкривають при зверненні в технічну підтримку. `msinfo32 /report C:\info.txt` зберігає все в текстовий файл. Для швидкої перевірки конкретних полів — PowerShell `Get-ComputerInfo` з потрібними Select-Object.
