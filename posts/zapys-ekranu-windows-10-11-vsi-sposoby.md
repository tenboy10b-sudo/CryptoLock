Записати екран на Windows можна без встановлення додаткових програм — вбудовані інструменти вже є в системі. Але якщо потрібен більший контроль — є безкоштовні альтернативи.

---

## Спосіб 1 — Xbox Game Bar (вбудований, Windows 10/11)

Найшвидший спосіб. Працює для більшості додатків і ігор.

**Гарячі клавіші:**
```
Win + G          — відкрити Game Bar
Win + Alt + R    — почати/зупинити запис
Win + Alt + M    — увімкнути/вимкнути мікрофон
Win + Alt + PrtSc — скріншот
```

**Через інтерфейс:**
1. Натисни `Win + G`
2. У віджеті "Захоплення" натисни ● (почати запис)
3. Для зупинки — ■ або `Win + Alt + R`

Відео зберігається в: `C:\Users\[ім'я]\Videos\Captures`

**Налаштування якості:**
```
Win + I → Ігри → Захоплення
```
- Якість відео: Стандартна / Висока
- Частота кадрів: 30 або 60 FPS
- Максимальний час запису: до 4 годин

> ⚠️ Game Bar не записує Робочий стіл і Провідник — тільки додатки і ігри.

## Спосіб 2 — Snipping Tool (Windows 11)

У Windows 11 оновлений Snipping Tool вміє записувати екран.

```
Win + Shift + S → вибрати область → натисни іконку відео (🎬)
```

Або через пошук: `Snipping Tool` → вкладка **"Відео"**

1. Натисни **"Новий"** (відео режим)
2. Вибери область екрану
3. Натисни **"Почати"**
4. Для зупинки — **"Зупинити"**

Зберігає у форматі MP4.

---

## Спосіб 3 — PowerPoint (є в Office)

Якщо встановлений Microsoft Office:

1. Відкрий PowerPoint → **"Вставлення"** → **"Запис екрана"**
2. Вибери область
3. Натисни **"Запис"**
4. Зупини через панель або `Win + Shift + Q`
5. Відео вставиться в слайд → ПКМ → **"Зберегти медіафайл як"**

## Спосіб 4 — OBS Studio (безкоштовно, потужно)

Найпопулярніший безкоштовний інструмент для запису і стрімінгу.

**Завантаження:** [obsproject.com](https://obsproject.com)

**Базове налаштування:**
1. Встановити → запустити
2. Майстер автоналаштування вибере оптимальні параметри
3. В розділі "Джерела" натисни **+** → **"Захоплення дисплея"**
4. Натисни **"Почати запис"**

**Налаштування виводу:**
```
Файл → Параметри → Вивід → Запис
- Формат: MP4
- Шлях: будь-яка папка
- Якість: висока
```

**Запис зі звуком системи + мікрофон:**
В розділі "Мікшер звуку" налаштуй:
- Desktop Audio — звук з комп'ютера
- Mic/Aux — мікрофон

## Спосіб 5 — ShareX (безкоштовно, максимум функцій)

ShareX — безкоштовна програма з відкритим кодом. Більше функцій ніж OBS для простого запису.

**Завантаження:** [getsharex.com](https://getsharex.com) або Microsoft Store

**Запис екрану:**
1. **"Захоплення"** → **"Запис екрана"**
2. Вибери область
3. Натисни **"Почати"**

**Переваги ShareX:**
- Запис певної області або всього екрану
- Конвертація в GIF
- Вбудоване редагування
- Автозавантаження на хмару
- Повністю безкоштовно без реклами

## Запис екрану зі звуком

### Дозволити запис системного звуку

```
Win + I → Система → Звук → Мікшер гучності
```

В Game Bar:
```
Win + G → Налаштування (⚙️) → Звук → 
Увімкнути "Записувати звук при записі гри"
```

### Перевірити пристрій запису

```powershell
# Список мікрофонів
Get-WmiObject Win32_SoundDevice | Select-Object Name, Status
```

## Часті питання

### Чому Game Bar не відкривається?
```
Win + I → Ігри → Xbox Game Bar → Увімкнути
```
Або перевір чи не вимкнено через групову політику.

### Як записати тільки одне вікно?
В OBS: Джерела → **"Захоплення вікна"** → вибери потрібне вікно.

### Який формат відео найкращий?
MP4 (H.264) — найбільш сумісний. OBS і ShareX підтримують його за замовчуванням.

### Як зменшити розмір файлу?
В OBS: Параметри → Вивід → CRF (чим вище число — менший файл, нижча якість). Значення 23–28 — хороший баланс.
