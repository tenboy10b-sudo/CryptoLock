Редактор групових політик — найпотужніший інструмент налаштування Windows що дозволяє примусово застосовувати параметри які не можна змінити через звичайні Параметри.

---

## Відкрити редактор

```powershell
gpedit.msc
```

**Увага:** gpedit.msc недоступний на Windows Home.

---

## Структура GPO

```
Конфігурація комп'ютера (для машини незалежно від користувача)
└── Адміністративні шаблони

Конфігурація користувача (для поточного користувача)
└── Адміністративні шаблони
```

---

## Застосувати і оновити політики

```powershell
# Примусове оновлення
gpupdate /force

# Тільки комп'ютер
gpupdate /target:computer /force

# З перезавантаженням
gpupdate /force /boot
```

---

## Перевірити застосовані політики

```powershell
# Текстовий звіт
gpresult /r

# HTML звіт (найзручніший)
gpresult /h "C:\gpo-report.html"
Start-Process "C:\gpo-report.html"

# Графічний інструмент
rsop.msc
```

---

## Часті питання

### Політика GPO не застосовується — як діагностувати?

1. `gpupdate /force` і перезавантаж
2. `gpresult /r` — чи є в Applied або Denied GPOs?
3. Перегляд подій: `Get-WinEvent` з провайдером `Microsoft-Windows-GroupPolicy`

### Чи можуть користувачі скасувати GPO?

Ні — Конфігурація комп'ютера примусова. Користувачі не можуть змінити захищені реєстрові ключі через Параметри.

---

## Резюме

`gpedit.msc` для GUI. `gpupdate /force` для застосування. `gpresult /h` для HTML звіту. Конфігурація комп'ютера — загальносистемні. Конфігурація користувача — для конкретного юзера. `rsop.msc` коли щось не застосовується.
