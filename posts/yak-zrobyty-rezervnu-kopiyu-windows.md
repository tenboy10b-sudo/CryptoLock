Без резервної копії — немає відновлення. Windows має кілька вбудованих інструментів — ось як використовувати кожен.

---

## Метод 1: File History (безперервний)

Автоматично зберігає файли з бібліотек, Робочого столу і Документів на зовнішній диск.

`Win + I` → **Система** → **Параметри резервного копіювання** → вибери диск → **Увімкнути**

---

## Метод 2: Образ системи (повний знімок)

Повний образ Windows — відновлює все включаючи програми і налаштування.

`Панель керування` → **Архівація та відновлення (Windows 7)** → **Створити образ системи**

```powershell
# Створити образ через WBADMIN
wbadmin start backup -backupTarget:E: -include:C: -allCritical -quiet

# Список доступних резервних копій
wbadmin get versions
```

---

## Метод 3: Robocopy + Планувальник

```powershell
$action = New-ScheduledTaskAction -Execute "robocopy.exe" `
  -Argument '"C:\Users\Ім'я\Documents" "E:\Backup\Documents" /MIR /R:3 /W:5'

$trigger = New-ScheduledTaskTrigger -Daily -At "02:00AM"
Register-ScheduledTask -TaskName "DailyBackup" `
  -Action $action -Trigger $trigger -RunLevel Highest
```

---

## Метод 4: OneDrive

Іконка OneDrive в треї → Параметри → Резервна копія → Керувати резервним копіюванням

Вмикає синхронізацію Робочого столу, Документів і Зображень у хмару.

---

## Правило 3-2-1

- **3** копії даних
- **2** різних носії (внутрішній + зовнішній диск або хмара)
- **1** копія поза домом (OneDrive, Google Drive або фізичний диск деінде)

---

## Часті питання

### Скільки місця займає образ системи?

Зазвичай 20-50 ГБ для стандартної установки Windows. Зберігай на зовнішньому диску з мінімум 2× від зайнятого місця на C:.

### Як часто робити резервну копію?

Документи: щодня або безперервно через File History. Образ системи: щомісяця або перед великими змінами. Питання: скільки роботи ти можеш дозволити собі втратити?

---

## Резюме

File History — для безперервного копіювання файлів. Образ системи — для повного відновлення ОС. Robocopy + Планувальник — для власних автоматизованих бекапів. OneDrive — для хмарної синхронізації. Завжди тестуй відновлення.
