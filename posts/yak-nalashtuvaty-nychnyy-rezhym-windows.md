Night Light зменшує кількість синього світла на екрані у вечірній час — це знижує навантаження на очі і покращує засинання. Синє світло пригнічує вироблення мелатоніну і порушує циркадний ритм. Night Light замінює його на тепліший жовтуватий відтінок.

---

## Увімкнути Night Light

**Швидко через Центр сповіщень:**
Натисни на значок сповіщень у правому нижньому куті → клікни плитку **Night Light**.

**Через Параметри:**
```
Win + I → Система → Дисплей → Night Light → перемикач увімкнути
```

**Через пошук:**
```
Win → пошук "Night Light" → Параметри Night Light
```

---

## Налаштувати розклад і інтенсивність

```
Win + I → Система → Дисплей → Night Light → Параметри Night Light
```

### Інтенсивність
Повзунок від теплого (мінімум синього світла) до холодного. Рекомендовано: **30–50%** для вечірньої роботи. Для читання перед сном — 20–30%.

### Розклад
Два варіанти:
- **Від заходу до сходу сонця** — автоматично за геолокацією. Найзручніший варіант.
- **Встановити години** — вручну, наприклад з 21:00 до 7:00. Зручно якщо не хочеш ділитись геолокацією.

### Кольорова температура
Night Light змінює колірну температуру дисплея:
- Денний режим: ~6500K (холодне біле світло)
- Нічний режим: 2700–4000K (тепле жовтувате світло)

## Налаштування через реєстр

```powershell
# Перевірити поточні налаштування Night Light
$path = "HKCU:\Software\Microsoft\Windows\CurrentVersion\CloudStore\Store\DefaultAccount\Current\default`$windows.data.bluelightreduction.settings\windows.data.bluelightreduction.settings"
Get-ItemProperty $path -ErrorAction SilentlyContinue

# Перевірити статус (увімкнено/вимкнено)
$statePath = "HKCU:\Software\Microsoft\Windows\CurrentVersion\CloudStore\Store\DefaultAccount\Current\default`$windows.data.bluelightreduction.bluelightreductionstate\windows.data.bluelightreduction.bluelightreductionstate"
Get-ItemProperty $statePath -ErrorAction SilentlyContinue
```

> Рекомендується керувати Night Light через GUI — реєстровий шлях складний і змінюється між версіями Windows.

## Автоматичне перемикання не працює

### Проблема: опція "Від заходу до сходу" недоступна або сіра

**Рішення 1 — увімкнути служби розташування:**
```
Win + I → Конфіденційність і безпека → Розташування → 
Служби розташування → увімкнути
```

**Рішення 2 — перевірити налаштування дати і часу:**
```
Win + I → Час і мова → Дата і час → 
Встановлювати часовий пояс автоматично → увімкнути
```

**Рішення 3 — перезапустити службу:**
```powershell
# Перезапустити службу Location
Restart-Service -Name "lfsvc" -Force
```

### Night Light не вмикається взагалі
- Перевір чи підтримує твій монітор і відеокарта потрібні функції
- Оновіть драйвер відеокарти
- HDR дисплеї можуть мати обмеження з Night Light

## Порівняння Night Light і f.lux

| Функція | Night Light | f.lux |
|---------|------------|-------|
| Встановлення | Вбудований | Потрібно завантажити |

| Плавність переходу | Середня | Дуже плавна |
| Профілі освітлення | ❌ | ✅ (лампочка, флуоресцент) |
| Пауза для кольорів | ❌ | ✅ |

**f.lux** — якщо потрібен більший контроль. Завантаж з [justgetflux.com](https://justgetflux.com).

## Night Light на кількох моніторах

Night Light застосовується до **всіх моніторів одночасно** — немає можливості налаштувати окремо для кожного монітора в Windows. Якщо потрібен такий рівень контролю — використовуй f.lux.

## Часті питання

### Чи впливає Night Light на якість зображення для роботи з кольором?
Так — при ввімкненому Night Light кольори змінюються. Для дизайну і роботи з фото вимикай Night Light або налаштовуй паузу через f.lux.

### Чи є Night Light на Windows 10?
Так — Night Light доступний починаючи з Windows 10 версії 1703 (Creators Update).

### Night Light не зберігає налаштування після перезавантаження
Перевір чи увімкнений розклад. Без розкладу Night Light не вмикається автоматично після перезавантаження.
