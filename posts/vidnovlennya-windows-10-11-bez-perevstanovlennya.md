Windows почала гальмувати, з'явились помилки або система взагалі не завантажується? Перш ніж переінсталювати — спробуй ці способи. У 80% випадків вони вирішують проблему за 15–30 хвилин.

---

## Який спосіб вибрати

| Проблема | Рішення |
|---------|---------|
| Система гальмує, глючить | Точка відновлення або SFC/DISM |
| Після оновлення все зламалось | Відкочення оновлення або точка відновлення |
| Вірус або серйозна помилка | Скидання ПК (зберегти файли) |
| Windows не завантажується | Відновлення завантажувача |
| Синій екран (BSOD) | SFC + DISM + перевірка диску |

---

## Спосіб 1 — Точка відновлення системи

Найшвидший спосіб — повертає систему до стану коли все працювало. Не видаляє особисті файли, але скасовує встановлені програми і зміни реєстру після точки відновлення.

### Перевірити чи є точки відновлення

```powershell
# Переглянути доступні точки відновлення
Get-ComputerRestorePoint | Select-Object Description, CreationTime | Sort-Object CreationTime -Descending
```

### Відновити через GUI

1. `Win + R` → `rstrui` → Enter
2. Вибери точку відновлення зі списку
3. Натисни **"Далі"** → **"Готово"** → **"Так"**
4. ПК перезавантажиться і повернеться до вибраного стану (10–20 хв)

### Якщо Windows не завантажується

При старті натисни F8 → **"Додаткові параметри"** → **"Відновлення системи"**

Або з флешки: **"Відновлення системи"** → **"Усунення неполадок"** → **"Відновлення системи"**

### Увімкнути захист системи (якщо вимкнено)

```powershell
# Увімкнути для диску C:
Enable-ComputerRestore -Drive "C:\"

# Створити точку відновлення вручну
Checkpoint-Computer -Description "Перед змінами" -RestorePointType "MODIFY_SETTINGS"
```

## Спосіб 2 — SFC і DISM (відновлення системних файлів)

Якщо Windows глючить через пошкоджені системні файли — ці команди знайдуть і виправлять їх.

### Крок 1 — SFC (System File Checker)

Відкрий командний рядок від адміністратора:

```cmd
sfc /scannow
```

Чекай 10–20 хвилин. Можливі результати:

- `Windows Resource Protection did not find any integrity violations` — файли в порядку
- `Windows Resource Protection found corrupt files and successfully repaired them` — **виправлено**
- `Windows Resource Protection found corrupt files but was unable to fix some of them` — потрібен DISM

### Крок 2 — DISM (якщо SFC не допоміг)

```cmd
# Перевірка стану образу
DISM /Online /Cleanup-Image /CheckHealth

# Сканування
DISM /Online /Cleanup-Image /ScanHealth

# Відновлення (завантажує файли з Windows Update)
DISM /Online /Cleanup-Image /RestoreHealth
```

DISM може тривати 20–40 хвилин і завантажувати файли з інтернету.

### Після DISM запусти SFC ще раз

```cmd
sfc /scannow
```

## Спосіб 3 — Скидання ПК (Reset This PC)

Перевстановлює Windows але **зберігає особисті файли**. Видаляє програми та налаштування.

```
Win + I → Система → Відновлення → Скинути цей ПК
```

Або через пошук: `Скинути цей ПК`

**Два варіанти:**
- **"Зберегти мої файли"** — видаляє програми, зберігає документи/фото
- **"Видалити все"** — повне очищення (як чиста установка)

> Вибирай "Зберегти мої файли" якщо хочеш зберегти дані. Процес займає 30–60 хвилин.

**Якщо Windows не завантажується:**
При старті F8 → **"Усунення неполадок"** → **"Скинути цей ПК"**

## Спосіб 4 — Відкочення оновлення Windows

Якщо проблеми почались після оновлення:

```
Win + I → Windows Update → Журнал оновлень → Видалити оновлення
```

Або через PowerShell:
```powershell
# Переглянути встановлені оновлення
Get-HotFix | Sort-Object InstalledOn -Descending | Select-Object -First 10

# Видалити конкретне оновлення
wusa /uninstall /kb:XXXXXXX /quiet /norestart
```

**Для великих оновлень (Feature Update):**
```
Win + I → Система → Відновлення → Повернутись до попередньої версії Windows
```
Доступно тільки 10 днів після оновлення.

## Спосіб 5 — Відновлення завантажувача

Якщо Windows не завантажується і показує помилку `BOOTMGR is missing` або `No bootable device`:

Завантажся з флешки Windows → **"Відновлення системи"** → **"Усунення неполадок"** → **"Командний рядок"**:

```cmd
# Відновлення завантажувача
bootrec /fixmbr
bootrec /fixboot
bootrec /scanos
bootrec /rebuildbcd

# Якщо не допомогло — повне відновлення BCD
bcdedit /export C:\BCD_backup
attrib C:\boot\bcd -r -s -h
ren C:\boot\bcd bcd.old
bootrec /rebuildbcd
```

Після кожної команди перезавантаж і перевір.

## Спосіб 6 — Середовище відновлення (WinRE)

WinRE — вбудований інструмент відновлення Windows. Доступний навіть якщо система не завантажується.

**Як потрапити в WinRE:**
- При завантаженні 3 рази перерви живлення → автоматично відкриється
- `Win + I → Система → Відновлення → Розширений запуск → Перезавантажити зараз`
- З флешки Windows → **"Відновлення системи"**

**Що можна зробити в WinRE:**
- Відновлення системи (точка відновлення)
- Відновлення образу системи
- Відновлення при запуску
- Командний рядок
- Скидання ПК

## Часті питання

### Чи видалить відновлення мої файли?
- **Точка відновлення** — ні, особисті файли залишаються
- **SFC/DISM** — ні, тільки системні файли
- **Скидання "Зберегти файли"** — зберігає документи і фото
- **Скидання "Видалити все"** — видаляє все

### Скільки часу займає відновлення?
- Точка відновлення — 15–20 хвилин
- SFC + DISM — 30–60 хвилин
- Скидання ПК — 30–90 хвилин

### Що робити якщо жоден спосіб не допоміг?
Чиста установка Windows з флешки — радикальний але надійний варіант.

## Резюме — порядок дій

```
1. Спробуй точку відновлення (rstrui)
2. Запусти SFC → DISM → SFC
3. Відкоти останнє оновлення
4. Скидання ПК (зберегти файли)
5. Чиста установка (крайній варіант)
```
