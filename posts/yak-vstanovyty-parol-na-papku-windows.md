Windows не має вбудованої функції «поставити пароль на папку» як в смартфоні. Але є кілька способів обмежити доступ — залежно від того чого саме ти хочеш.

---

## Спосіб 1: Архів з паролем (найпростіше)

Якщо потрібно захистити файли для зберігання або передачі — упакуй в зашифрований архів.

**7-Zip** (безкоштовний):
1. Встанови [7-zip.org](https://7-zip.org)
2. Правий клік на папці → **7-Zip** → **Додати до архіву**
3. Формат: **zip** або **7z**
4. В полі **Шифрування** введи пароль
5. Метод шифрування: **AES-256**

Мінус: для роботи з файлами треба кожен раз розпаковувати.

---

## Спосіб 2: BitLocker (для цілого диска або флешки)

Якщо потрібно захистити великий обсяг даних — зашифруй окремий розділ або USB флешку через BitLocker.

`Win + S` → **Керування BitLocker** → вибери диск → **Увімкнути BitLocker**

Або для флешки: правий клік на диску в Провіднику → **Увімкнути BitLocker**

Плюс: прозоро, файли доступні після введення пароля без розпакування.

---

## Спосіб 3: Обмеження прав NTFS (для окремих користувачів)

Якщо на ПК кілька користувачів і треба щоб інші не бачили папку:

1. Правий клік на папці → **Властивості** → **Безпека** → **Змінити**
2. Вибери користувача якому хочеш заборонити доступ
3. Постав галочку **Заборонити** навпроти **Повний доступ**

Або через PowerShell:
```powershell
$acl = Get-Acl "C:\SecretFolder"
$rule = New-Object System.Security.AccessControl.FileSystemAccessRule(
  "Username", "FullControl", "Deny"
)
$acl.SetAccessRule($rule)
Set-Acl "C:\SecretFolder" $acl
```

Мінус: адміністратор завжди може отримати доступ.

---

## Спосіб 4: VeraCrypt (найнадійніше)

VeraCrypt створює зашифрований контейнер — файл що монтується як диск після введення пароля.

1. Завантаж з [veracrypt.fr](https://www.veracrypt.fr) — безкоштовно
2. **Create Volume** → **Create an encrypted file container**
3. Вибери розмір і пароль
4. Монтуй контейнер через VeraCrypt → працюй з файлами → розмонтуй

Плюс: найсильніше шифрування, кросплатформне, відкритий код.

---

## Що НЕ працює

**Атрибут "Прихований"** — правий клік → Властивості → "Прихований" — це не захист. Файли видно якщо увімкнути "Показати приховані файли".

**"Заблокувати папку" через bat-скрипти** — популярні в інтернеті скрипти що нібито ховають папку. Це просто зміна атрибутів, легко обходиться.

## Резюме

Для швидкого захисту файлів → архів 7-Zip з AES-256. Для великого обсягу даних → BitLocker. Для найсерйознішого захисту → VeraCrypt. Обмеження NTFS підходить тільки для захисту від інших користувачів того самого ПК.
