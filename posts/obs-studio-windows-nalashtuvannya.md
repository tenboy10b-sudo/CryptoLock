OBS Studio — стандарт індустрії для запису екрану і стрімінгу. Безкоштовний, відкритий код, використовується мільйонами стрімерів і контент-мейкерів. Ось як налаштувати з нуля.

---

## Встановлення

1. Завантаж з [obsproject.com](https://obsproject.com)
2. Запусти інсталятор
3. При першому запуску — **майстер автоналаштування**:
   - Вибери "Оптимізувати для запису" або "Оптимізувати для стрімінгу"
   - OBS автоматично підбере налаштування для твого ПК

```powershell
winget install OBSProject.OBSStudio
```

---

## Основні концепції OBS

**Сцена (Scene)** — набір джерел для одного виду трансляції. Наприклад: "Ігровий", "Вебкамера", "Перерва".

**Джерело (Source)** — що саме показується в сцені:
- Захоплення дисплея — весь екран
- Захоплення вікна — одне вікно
- Відеозахоплення — веб-камера
- Зображення — фон або оверлей
- Текст — підписи
- Мікрофон/аудіо

---

## Налаштування сцен і джерел

### Додати джерело "Захоплення дисплея"

1. Внизу в розділі "Джерела" → **"+"** → **"Захоплення дисплея"**
2. Вибери монітор
3. Джерело з'явиться в попередньому перегляді

### Додати веб-камеру

1. **"+"** → **"Відеозахоплення"**
2. Вибери камеру зі списку
3. Перетягни і змінш розмір в попередньому перегляді

### Додати мікрофон

В розділі **"Мікшер звуку"** мікрофон додається автоматично. Якщо ні:
1. **"+"** → **"Захоплення аудіовходу"**
2. Вибери свій мікрофон

## Налаштування виводу

```
Файл → Налаштування → Вивід
```

### Для запису

| Параметр | Рекомендація |
|---------|-------------|
| Шлях запису | D:\Recordings (не системний диск) |
| Формат | MKV (надійніше) або MP4 |
| Кодер | NVENC (NVIDIA) / AMF (AMD) / x264 (CPU) |
| Бітрейт | 15000–25000 кбіт/с для 1080p |
| CRF/CQP | 18–23 (нижче = краща якість) |

### Для стрімінгу на Twitch

```
Файл → Налаштування → Трансляція
Сервіс: Twitch
Ключ потоку: скопіюй з dashboard.twitch.tv
```

| Параметр | Twitch 1080p60 |
|---------|---------------|
| Бітрейт відео | 6000 кбіт/с (макс для більшості) |
| Кодер | NVENC або x264 |
| Пресет | Quality або Balanced |

### Для YouTube

```
Сервіс: YouTube / YouTube - RTMPS
```

| Параметр | YouTube 1080p |
|---------|--------------|
| Бітрейт відео | 8000–12000 кбіт/с |
| Бітрейт аудіо | 160 кбіт/с |

## Налаштування відео

```
Файл → Налаштування → Відео
```

| Параметр | Значення |
|---------|---------|
| Базова роздільна здатність | 1920x1080 (роздільна здатність монітора) |
| Вихідна роздільна здатність | 1920x1080 або 1280x720 для стрімінгу |
| FPS | 60 для ігор, 30 для вебінарів |
| Фільтр масштабування | Lanczos (якість) або Bilinear (швидкість) |

## Фільтри і ефекти

### Шумозаглушення мікрофона

1. ПКМ на мікрофоні в мікшері → **"Фільтри"**
2. **"+"** → **"Придушення шуму"**
3. Вибери:
   - **RNNoise** — AI шумозаглушення (рекомендую)
   - **Speex** — легше для CPU

### Компресор голосу

**"+"** → **"Компресор"**:
- Поріг: -18 дБ
- Співвідношення: 4:1
- Атака: 6 мс

## Гарячі клавіші

```
Файл → Налаштування → Гарячі клавіші
```

Рекомендовані:
| Дія | Клавіша |
|-----|---------|
| Почати/зупинити запис | F9 |
| Почати/зупинити трансляцію | F10 |
| Заглушити мікрофон | F1 |
| Пауза запису | F8 |

## Плагіни OBS

**obs-move-transition** — плавні анімації між сценами
**StreamFX** — розширені ефекти і фільтри
**obs-websocket** — керування OBS через API

Встановлення: розпакуй в `C:\Program Files\obs-studio\obs-plugins\`

## Вирішення проблем

### Низький FPS при записі

```
Файл → Налаштування → Вивід → Запис
```
- Змінь кодер з x264 на NVENC (якщо є NVIDIA GPU)
- Знизь бітрейт
- Зменш роздільну здатність виходу

```powershell
# Перевірити яка відеокарта
Get-WmiObject Win32_VideoController | Select-Object Name
```

### Чорний екран при захопленні гри

```
Файл → Налаштування → Загальне → Прискорення
```
- Вимкни "Прискорення GPU"
- Або: ПКМ на ярлику OBS → Властивості → Сумісність → Відключити оптимізації

### Аудіо не синхронізується з відео

Для кожного аудіо джерела можна додати затримку:
```
ПКМ на джерелі в мікшері → Властивості → Синхронізація зміщення
```
