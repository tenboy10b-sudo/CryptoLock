iTunes — необхідна програма якщо у тебе iPhone або iPad і Windows ПК. Синхронізація, резервне копіювання, перенесення музики — все через iTunes.

---

## Два способи встановлення iTunes

### Спосіб 1 — Microsoft Store (рекомендую)

```
Пуск → Microsoft Store → пошук "iTunes" → Встановити
```

Або пряме посилання: [apps.microsoft.com — iTunes](https://apps.microsoft.com/store/detail/itunes/9PB2MZ1ZMB1S)

**Переваги Store версії:**
- Автоматичні оновлення
- Менше проблем з драйверами
- Простіше видалення

### Спосіб 2 — Офіційний сайт Apple

1. Відкрий [apple.com/itunes/download](https://www.apple.com/itunes/download/win64)
2. Завантаж 64-bit версію
3. Встанови — автоматично встановить Apple Mobile Device Support і Bonjour

---

## Перше підключення iPhone

1. Підключи iPhone кабелем Lightning або USB-C
2. На iPhone з'явиться запит **"Довіряти цьому комп'ютеру?"** → натисни **"Довіряти"** і введи пасскод
3. iTunes відкриє сторінку пристрою

**Якщо iPhone не відображається:**
- Перевір кабель (оригінальний надійніший)
- Спробуй інший USB порт
- Переконайся що iPhone не заблокований під час підключення

## Резервне копіювання iPhone

```
iTunes → вибери пристрій → "Резервні копії" → "Зробити резервну копію зараз"
```

| Тип | Де зберігається | Що містить |
|-----|----------------|-----------|
| Локально (Windows) | `C:\Users\[user]\AppData\Roaming\Apple Computer\MobileSync\Backup` | Все крім куплених медіафайлів |
| iCloud | Хмара Apple | Все (платно якщо > 5 ГБ) |

**Рекомендую:** зроби локальну резервну копію перед будь-якими великими змінами.

**Шифрована резервна копія:**
```
"Зашифрувати локальну резервну копію" → встанови пароль
```
Зберігає також паролі і дані здоров'я.

---

## Синхронізація музики

```
iTunes → пристрій → Музика → "Синхронізувати музику"
```

Вибери:
- **"Вся медіатека"** — вся музика з iTunes
- **"Вибрані плейлисти/виконавці"** — тільки вибране

> Якщо на iPhone є музика куплена в App Store — вона залишиться. Синхронізація замінює тільки "звичайну" музику.

## Перенесення фото і відео

### Фото з iPhone на Windows (без iTunes)

Більш простий спосіб — **без iTunes**:
```
Підключи iPhone → Провідник Windows → iPhone → Internal Storage → DCIM
```
Або: Налаштування Windows → Bluetooth і пристрої → Автовідтворення → вибери дію

### Через iTunes

```
iTunes → пристрій → Фото → "Синхронізувати фото"
```
Вибери папку на Windows звідки переносити фото на iPhone.

---

## Оновлення iOS через iTunes

Якщо не хочеш оновлюватись "по повітрю":

```
iTunes → пристрій → "Оновити"
```

Або для чистого відновлення: **"Відновити iPhone"** (видаляє всі дані).

## Вирішення помилок

### iTunes не бачить iPhone

```powershell
# Перезапустити службу Apple Mobile Device
Restart-Service -Name "Apple Mobile Device Service"
```

Або вручну:
```
Win + R → services.msc → Apple Mobile Device Service → Перезапустити
```

### Помилка "Довіра до цього комп'ютера скинута"
На iPhone: Налаштування → Загальні → Перенесення або скидання iPhone → Скинути → Скинути геолокацію і конфіденційність → потім знову підключи

### iTunes не встановлюється (помилка 2503/2502)
```powershell
# Встанови через Store замість сайту
Start-Process "ms-windows-store://pdp/?ProductId=9PB2MZ1ZMB1S"
```

### Повільна синхронізація
- Використовуй USB 3.0 порт (синій)
- Вимкни синхронізацію фото якщо потрібна тільки музика
