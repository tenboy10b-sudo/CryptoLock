Rufus — найпопулярніша утиліта для створення завантажувальних флешок. Безкоштовна, без реклами, розміром 1 МБ. Ось як правильно нею користуватись щоб флешка точно запустилась.

---

## Що потрібно

- Флешка **мінімум 8 ГБ** (краще 16 ГБ) — всі дані з неї будуть видалені
- ISO образ Windows 10 або Windows 11 (завантажений з офіційного сайту Microsoft)
- Rufus — завантажити з [rufus.ie](https://rufus.ie)
- 15–20 хвилин часу

---

## Крок 1 — Завантаження ISO образу Windows

Офіційний ISO завантажується з сайту Microsoft безкоштовно.

**Windows 11:**
1. Відкрий [microsoft.com/uk-ua/software-download/windows11](https://www.microsoft.com/uk-ua/software-download/windows11)
2. Вибери **"Завантажити образ диска ISO для Windows 11"**
3. Вибери мову → **"64-bit Download"**

**Windows 10:**
1. Відкрий [microsoft.com/uk-ua/software-download/windows10](https://www.microsoft.com/uk-ua/software-download/windows10)
2. Вибери **"Завантажити інструмент зараз"** → запусти
3. У майстрі вибери **"Створити інсталяційний носій"** → ISO файл

> Розмір ISO: Windows 10 — ~5,5 ГБ, Windows 11 — ~5,2 ГБ

---

## Крок 2 — Завантаження та запуск Rufus

1. Відкрий [rufus.ie](https://rufus.ie) → завантаж останню версію (наприклад `rufus-4.6.exe`)
2. Запусти від імені адміністратора (правою кнопкою → **"Запуск від імені адміністратора"**)
3. Вставте флешку в USB порт

---

## Крок 3 — Налаштування Rufus

Після запуску Rufus автоматично визначить флешку. Ось що потрібно налаштувати:

### Пристрій
Вибери свою флешку в першому рядку. **Переконайся що вибрана саме флешка**, а не жорсткий диск.

### Вибір завантаження
Натисни **"ВИБРАТИ"** і вкажи завантажений ISO файл Windows.

### Схема розділів — найважливіший параметр

| Твій комп'ютер | Схема розділів | Цільова система |
|---------------|----------------|-----------------|
| Сучасний (після 2012) | **GPT** | **UEFI (не CSM)** |
| Старий BIOS | **MBR** | **BIOS або UEFI-CSM** |
| Не знаю | GPT | UEFI |

**Як дізнатись яка система у тебе:**
```
Win + R → msinfo32 → BIOS Mode
```
- `UEFI` → вибирай **GPT + UEFI**
- `Legacy` → вибирай **MBR + BIOS**

### Файлова система
- **NTFS** — для більшості випадків
- **FAT32** — тільки якщо є проблеми з UEFI на старих материнських платах

### Мітка тому
Можна залишити автоматично — Rufus заповнить сам.

---

## Крок 4 — Запис

1. Натисни **"СТАРТ"**
2. З'явиться попередження про видалення даних з флешки — натисни **"ОК"**
3. Для Windows 11 Rufus запропонує додаткові опції:

### Опції Windows 11 в Rufus

| Опція | Що робить | Рекомендація |
|-------|-----------|--------------|
| Вимкнути вимоги TPM 2.0 | Дозволяє встановити на старі ПК | ✅ Якщо немає TPM |
| Вимкнути вимоги Secure Boot | Для старих BIOS | За потребою |
| Вимкнути вимогу RAM 8 ГБ | Для ПК з 4 ГБ | За потребою |
| Вимкнути вимогу облікового запису Microsoft | Локальний акаунт при встановленні | ✅ Рекомендую |

4. Дочекайся завершення — статусбар має показати **"ГОТОВО"**

Час запису: 5–15 хвилин залежно від швидкості флешки.

---

## Крок 5 — Налаштування завантаження з флешки

Після запису потрібно вказати комп'ютеру завантажуватись з флешки.

**Варіант 1 — Boot Menu (швидко):**
При старті ПК натисни клавішу Boot Menu:

| Виробник | Клавіша |
|----------|---------|
| ASUS | F8 або Esc |
| Gigabyte | F12 |
| MSI | F11 |
| HP | F9 або Esc |
| Dell | F12 |
| Lenovo | F12 або Fn+F12 |
| Acer | F12 |

**Варіант 2 — через BIOS/UEFI:**
1. Увійди в BIOS (зазвичай Del або F2 при старті)
2. Знайди розділ **Boot** або **Boot Priority**
3. Постав флешку на перше місце
4. Зберегти і перезавантажити: **F10 → Yes**

---

## Крок 6 — Встановлення Windows

Після завантаження з флешки:
1. Вибери мову і клавіатуру → **"Далі"**
2. **"Встановити зараз"**
3. Введи ключ продукту або натисни **"У мене немає ключа"** (можна активувати пізніше)
4. Вибери редакцію Windows
5. Прийми ліцензію → **"Далі"**
6. Вибери **"Вибіркове: встановити тільки Windows"** (для чистої установки)
7. Вибери розділ для встановлення

> ⚠️ **Увага:** якщо вибираєш чисту установку — всі дані з обраного розділу будуть видалені. Зроби резервну копію заздалегідь.

## Часті питання

### Флешка не відображається в Rufus
- Спробуй інший USB порт (бажано USB 2.0)
- Переконайся що флешка видима в Провіднику
- Перевір у Rufus: **Показати додаткові пристрої** (внизу)

### Помилка "This PC can't run Windows 11"
- Встановлюй Rufus версії 3.19 або новіше
- При записі ISO постав галочку **"Вимкнути перевірку TPM 2.0 і Secure Boot"**

### Комп'ютер не бачить флешку при завантаженні
- Перевір що в BIOS увімкнено **USB Boot** або **Legacy USB Support**
- Спробуй інший USB порт
- Переконайся що вибрав правильну схему розділів (GPT/MBR)

### "Диск має стиль розділів MBR" при встановленні
Диск не підходить для UEFI. Два варіанти:
```powershell
# Конвертувати диск в GPT (видаляє всі дані!)
# При встановленні: Shift+F10 → diskpart
list disk
select disk 0
clean
convert gpt
```
Або перестворити флешку з параметром MBR.
