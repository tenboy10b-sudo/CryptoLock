Ventoy вирішує головну проблему завантажувальних флешок — не потрібно щоразу форматувати і перезаписувати. Просто скопіюй ISO файли на флешку і вибирай що завантажити.

---

## Що таке Ventoy і чим відрізняється від Rufus

| | Rufus | Ventoy |
|-|-------|--------|
| ISO на флешці | Одночасно 1 | Скільки влізе |
| Додати новий образ | Перезаписати флешку | Скопіювати файл |
| Формат флешки | FAT32 або NTFS | ExFAT або NTFS |
| Збереження файлів | Видаляються | Залишаються |
| Підтримка UEFI | ✅ | ✅ |
| Підтримка Secure Boot | ✅ | ✅ (з модулем) |

**Ventoy ідеальний якщо:**
- Часто встановлюєш Windows на різні ПК
- Хочеш мати Windows 10 + Windows 11 + Linux на одній флешці
- Потрібні утиліти для відновлення системи (Hiren's Boot CD, SystemRescue)

---

## Крок 1 — Завантаження Ventoy

1. Відкрий [ventoy.net](https://www.ventoy.net/en/download.html)
2. Завантаж `ventoy-X.X.XX-windows.zip`
3. Розпакуй архів

---

## Крок 2 — Встановлення на флешку

1. Вставь флешку (мінімум 8 ГБ — краще 32 ГБ+)
2. Запусти `Ventoy2Disk.exe` від імені адміністратора
3. В списку **"Device"** вибери свою флешку

**Налаштування перед встановленням:**

```
Option → Partition Style
```

| Твій ПК | Вибери |
|---------|--------|
| Сучасний UEFI | GPT |
| Старий BIOS | MBR |
| Не знаєш | GPT |

4. Натисни **"Install"** → підтвердь двічі → чекай "Install Successfully"

> ⚠️ Всі дані з флешки будуть видалені. Зроби резервну копію якщо потрібно.

---

## Крок 3 — Копіювання ISO файлів

Після встановлення флешка розділиться на два розділи. Відкрий **перший великий розділ** (Ventoy) і просто скопіюй туди ISO файли:

```
Флешка (Ventoy)\
├── windows11.iso
├── windows10.iso
├── ubuntu-24.04.iso
└── hirens-boot-cd.iso
```

Ніяких додаткових налаштувань — Ventoy автоматично знайде всі ISO.

**Звідки брати ISO:**
- Windows 11: [microsoft.com/software-download/windows11](https://www.microsoft.com/software-download/windows11)
- Windows 10: [microsoft.com/software-download/windows10](https://www.microsoft.com/software-download/windows10)
- Ubuntu: [ubuntu.com/download](https://ubuntu.com/download)
- Hiren's Boot CD: [hirensbootcd.org](https://www.hirensbootcd.org)

---

## Крок 4 — Завантаження з Ventoy

1. Вставь флешку → завантажся з неї (F11/F12 для Boot Menu)
2. З'явиться меню Ventoy зі списком всіх ISO
3. Вибери потрібний образ → Enter
4. Вибери режим завантаження (зазвичай Normal mode)

---

## Оновлення Ventoy

Коли виходить нова версія — не потрібно переформатовувати флешку і копіювати ISO знову:

1. Завантаж нову версію з ventoy.net
2. Запусти `Ventoy2Disk.exe`
3. Натисни **"Update"** замість "Install"
4. ISO файли залишаться на місці

---

## Secure Boot

Якщо ПК з Secure Boot не завантажує Ventoy:

```
Option → Secure Boot Support → увімкнути
```

Або в BIOS вимкни Secure Boot тимчасово для встановлення.

---

## Ventoy на флешці разом зі звичайними файлами

Перший розділ Ventoy — звичайний диск. Можна зберігати будь-які файли поруч з ISO. Ventoy завантажує тільки `.iso`, `.img`, `.vhd`, `.wim` файли.

---

## Часті питання

### Ventoy не бачить мою флешку
Перевір що флешка відображається в Провіднику. Спробуй інший USB порт.

### ISO не з'являється в меню Ventoy
- Файл повинен мати розширення `.iso`
- Перевір що скопіював в перший розділ (Ventoy), а не в другий маленький
- Спробуй перезавантажитись

### Чи можна встановити Ventoy на SSD або HDD?
Так — Ventoy працює на будь-якому USB носії. Але флешка зручніша.
