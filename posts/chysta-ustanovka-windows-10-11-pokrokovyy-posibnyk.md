Чиста установка — найкращий спосіб отримати швидку і стабільну систему. На відміну від оновлення, вона видаляє весь накопичений сміттям і встановлює Windows з нуля.

**Коли потрібна чиста установка:**
- Система стала дуже повільною
- Вірус або зловмисне ПЗ
- Зміна SSD або жорсткого диску
- Windows не завантажується
- Хочеш почати з чистого аркуша

---

## Підготовка — зроби це перед тим як почати

### 1. Резервна копія даних

Чиста установка **видаляє все** з системного розділу. Скопіюй:
- Документи, фото, відео — на зовнішній диск або хмару
- Закладки браузера — експорт або синхронізація через акаунт
- Паролі — менеджер паролів або запиши
- Ключі і серійні номери встановлених програм
- Важливі листи з поштових клієнтів

```powershell
# Швидко знайти важливі файли
Get-ChildItem C:\Users -Recurse -Include *.docx,*.xlsx,*.pdf | 
  Where-Object {$_.LastWriteTime -gt (Get-Date).AddDays(-30)}
```

### 2. Запам'ятай ключ Windows

```powershell
# Переглянути ключ продукту
wmic path SoftwareLicensingService get OA3xOriginalProductKey
```

Або через PowerShell:
```powershell
(Get-WmiObject -query 'select * from SoftwareLicensingService').OA3xOriginalProductKey
```

### 3. Список встановлених програм

```powershell
Get-ItemProperty HKLM:\Software\Microsoft\Windows\CurrentVersion\Uninstall\* |
  Select-Object DisplayName, DisplayVersion |
  Sort-Object DisplayName |
  Export-Csv "$env:USERPROFILE\Desktop\programs.csv" -Encoding UTF8
```

### 4. Перевір чи є ліцензія

```powershell
slmgr /xpr
```
Якщо Windows активована — після чистої установки активується автоматично (цифрова ліцензія прив'язана до материнської плати).

## Крок 1 — Створення завантажувальної флешки

Потрібна флешка мінімум 8 ГБ і ISO образ Windows.

**Через Rufus (рекомендую):**
1. Завантаж [rufus.ie](https://rufus.ie)
2. Завантаж ISO з [microsoft.com/software-download/windows11](https://www.microsoft.com/software-download/windows11)
3. В Rufus вибери: флешку, ISO, схему GPT (для UEFI) або MBR (для Legacy BIOS)
4. Натисни СТАРТ → чекай ГОТОВО

**Схема розділів:**
```
Win + R → msinfo32 → BIOS Mode
UEFI → GPT | Legacy → MBR
```

---

## Крок 2 — Завантаження з флешки

1. Вставити флешку
2. При старті ПК натиснути клавішу Boot Menu:

| Виробник | Клавіша Boot Menu |
|---------|------------------|
| ASUS | F8 або Esc |
| Gigabyte | F12 |
| MSI | F11 |
| Dell | F12 |
| HP | F9 |
| Lenovo | F12 |

3. Вибрати USB Drive зі списку

---

## Крок 3 — Майстер встановлення

### Мова і регіон
Вибери мову, формат часу і розкладку клавіатури → **"Далі"** → **"Встановити зараз"**

### Ключ продукту
- Якщо є ключ — введи
- Якщо Windows була активована — натисни **"У мене немає ключа"** (активується автоматично)

### Редакція
Вибери ту ж редакцію що була (Home або Pro). Якщо переходиш на Pro — потрібен ключ Pro.

### Тип установки
**Обов'язково вибери "Вибіркове: встановити тільки Windows"** — це і є чиста установка. Варіант "Оновлення" залишає старі файли.

---

## Крок 4 — Розмітка диску

Це найвідповідальніший крок.

### Варіант А — повне очищення (рекомендую)

Якщо хочеш повністю очистити диск:
1. Вибери кожен розділ → натисни **"Видалити"**
2. Залишиться "Незайнятий простір на диску"
3. Вибери його → **"Далі"** — Windows сама створить потрібні розділи

### Варіант Б — зберегти другий розділ

Якщо є розділ D: з даними:
1. Видаляй тільки системні розділи (зазвичай С: і службові)
2. Розділ D: не чіпай
3. Вибери незайнятий простір → **"Далі"**

### Що означають системні розділи

| Розділ | Розмір | Призначення |
|--------|--------|-------------|
| Відновлення | ~500 МБ | WinRE — відновлення системи |
| EFI System | 100 МБ | Завантажувач UEFI |
| MSR | 16 МБ | Microsoft Reserved |
| Основний | Решта | Власне Windows (C:) |

## Крок 5 — Процес встановлення

Після вибору розділу Windows починає копіювати файли. ПК перезавантажиться 2–3 рази.

**Не вимикай комп'ютер** під час встановлення. Процес займає 15–30 хвилин залежно від швидкості диску.

При першому завантаженні пройди початкове налаштування (OOBE):
- Вибір регіону і мови
- Підключення до мережі
- Акаунт Microsoft або локальний акаунт

> 💡 Щоб створити локальний акаунт без Microsoft: при запиті мережі натисни **"У мене немає інтернету"** → **"Продовжити з обмеженим налаштуванням"**

---

## Крок 6 — Після встановлення

### Активація
Якщо Windows не активувалась автоматично:
`Параметри → Система → Активація → Усунення неполадок`

### Драйвери
Windows 11 встановить більшість драйверів автоматично через Windows Update. Перевір:
```powershell
# Пристрої без драйверів
Get-PnpDevice | Where-Object {$_.Status -eq 'Error'}
```

### Оновлення
`Win + I → Windows Update → Перевірити наявність оновлень`

### Відновлення програм
Встанови програми зі списку який зберіг перед інсталяцією.

## Часті питання

### Скільки займає чиста установка?
Загалом 45–90 хвилин: створення флешки (10–15 хв) + встановлення (20–30 хв) + початкове налаштування (15–30 хв).

### Чи потрібно форматувати диск перед встановленням?
Ні — просто видали розділи в майстрі і вибери незайнятий простір. Windows відформатує сама.

### Де взяти ключ Windows після чистої установки?
Якщо Windows була активована — вона активується автоматично (цифрова ліцензія). Якщо ні — ключ на наклейці під ноутбуком або в коробці.

### Чи можна встановити Windows без ключа?
Так — вона буде працювати, але без активації деякі функції персоналізації недоступні.
