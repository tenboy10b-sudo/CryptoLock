Windows має гнучке управління звуком але налаштування розкидані по різних місцях. Ось де що знаходиться.

---

## Пристрій виводу звуку

Правий клік на іконці звуку в треї → **Відкрити мікшер гучності** або **Параметри звуку**.

`Win + I` → **Система** → **Звук** → **Вивід** → вибери потрібний пристрій (динаміки, навушники, HDMI).

**Швидке перемикання:** клікни на іконці звуку → стрілка поруч з повзунком гучності → вибери пристрій.

---

## Мікшер гучності (різна гучність для програм)

Правий клік на іконці звуку → **Відкрити мікшер гучності**

Показує окрему гучність для кожної програми що відтворює звук. Зменши гучність браузера не впливаючи на плеєр.

---

## Налаштування мікрофона

`Win + I` → **Система** → **Звук** → **Вхід** → вибери мікрофон → **Властивості пристрою**:

- **Гучність** — посилення мікрофона
- **Вимкнути покращення** — якщо мікрофон звучить з артефактами

Перевірити рівень мікрофона: в тих самих налаштуваннях → говори → дивись на індикатор.

---

## Формат і частота дискретизації

Якщо звук хрустить або заїкається — перевір формат:

Правий клік на іконці звуку → **Параметри звуку** → **Додаткові параметри звуку** → **Відтворення** → правий клік на пристрої → **Властивості** → **Додатково**:

- Спробуй **16 біт, 44100 Гц** або **24 біт, 48000 Гц**
- Натисни **Перевірити** після кожної зміни

---

## Покращення звуку

В тих самих **Властивостях** → вкладка **Покращення**:

- **Еквалайзер** — налаштуй частоти
- **Посилення басів** — для акустики без сабвуфера
- **Просторовий звук** — для навушників

Якщо звук погіршився — **Вимкнути всі покращення** і перевір.

---

## Просторовий звук (Windows Sonic / Dolby)

`Win + I` → **Система** → **Звук** → **Властивості пристрою** → **Просторовий звук**:

- **Windows Sonic для навушників** — безкоштовно, хороший для ігор і кіно
- **Dolby Atmos** — платний, найкраща якість

---

## Через PowerShell

```powershell
# Переглянути аудіо пристрої
Get-WmiObject Win32_SoundDevice | Select-Object Name, Status, DeviceID

# Перевірити службу аудіо
Get-Service AudioSrv, AudioEndpointBuilder | Select-Object Name, Status

# Перезапустити аудіо службу
Restart-Service AudioSrv, AudioEndpointBuilder -Force
```

---

## Якщо немає звуку після оновлення

```powershell
# Перевірити драйвер
Get-WmiObject Win32_SoundDevice | Select-Object Name, DriverVersion
```

Якщо пристрій показує застарілий драйвер — завантаж новий з сайту виробника материнської плати або ноутбука.

---

## Резюме

Мікшер гучності — правий клік на іконці звуку → відкрий і регулюй гучність окремих програм. Хрускіт або проблеми з якістю → Властивості пристрою → Додатково → змінити формат. Немає звуку → перезапусти AudioSrv і перевстанови драйвер.
