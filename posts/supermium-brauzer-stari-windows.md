Supermium — некомерційний браузер на основі Chromium що підтримує Windows XP, Vista, 7, 8.1 і старіші версії де сучасні Chrome і Edge вже не запускаються.

---

## Для кого Supermium

**Головна аудиторія:**
- Власники старих ПК з Windows XP/Vista/7 що не можна оновити
- Адміністратори промислових або медичних систем на застарілих ОС
- Ентузіасти ретро-комп'ютингу

**Якщо у тебе Windows 10 або 11** — Supermium тобі не потрібен. Використовуй звичайний Chrome або Edge.

## Де завантажити

Офіційний репозиторій: [github.com/win32ss/supermium](https://github.com/win32ss/supermium)

1. Відкрий розділ **Releases**
2. Завантаж останню версію для своєї ОС
3. Доступні варіанти:
   - **Installer** — повна установка
   - **Portable** — без встановлення

---

## Встановлення на Windows 7

1. Переконайся що встановлено **SP1** і всі критичні оновлення
2. Завантаж Supermium Installer
3. Запусти — встановлення стандартне
4. Перший запуск може бути повільнішим — ініціалізація профілю

**Якщо виникла помилка при запуску на Windows 7:**
```
Встанови Visual C++ Redistributable 2022:
https://aka.ms/vs/17/release/vc_redist.x64.exe
```

## Основні можливості

Supermium базується на актуальній гілці Chromium тому підтримує:
- **Manifest V3** розширення (сучасний стандарт)
- **WebGL і WebAssembly**
- **HTTP/3 і QUIC**
- **Сучасні стандарти CSS і JS**

**Сумісність з розширеннями Chrome:**
Більшість розширень з Chrome Web Store встановлюються і працюють.

---

## Налаштування після встановлення

### Встановити розширення
```
Меню → Розширення → Відвідати Chrome Web Store
```
Встановлюй uBlock Origin, Password Manager тощо як у звичайному Chrome.

### Синхронізація з Google акаунтом
Supermium підтримує вхід в Google акаунт і синхронізацію закладок, паролів і налаштувань.

### Пошукова система
```
Налаштування → Пошукова система → Google/Bing/DuckDuckGo
```

## Supermium vs Basilisk vs Mypal (альтернативи для старих Windows)

| Браузер | Основа | XP | Vista | 7 | Актуальні сайти |
|---------|--------|-----|-------|---|----------------|
| Supermium | Chromium | ✅ | ✅ | ✅ | ✅ (сучасний движок) |
| Basilisk | Firefox (старий) | ✅ | ✅ | ✅ | ⚠️ (деякі проблеми) |
| Mypal | Firefox (старий) | ❌ | ❌ | ✅ | ⚠️ |
| Thorium | Chromium | ❌ | ❌ | ❌ | ✅ (тільки Win 10/11) |

**Supermium** — найкращий вибір якщо потрібна максимальна сумісність з сучасними сайтами на старій ОС.

---

## Обмеження Supermium

- **Відеодзвінки** (Google Meet, Zoom) можуть не працювати на XP/Vista
- **DRM контент** (Netflix, Disney+) — не підтримується на старих ОС
- **Розширена синхронізація** Google може мати обмеження
- **Оновлення** менш часті ніж у Chrome

---

## Безпека на старих Windows

Важливо розуміти: навіть із сучасним браузером Windows XP і Vista **не отримують патчів безпеки**. Не використовуй старі ОС для:
- Онлайн-банкінгу
- Введення паролів на важливих сайтах
- Зберігання чутливих даних

Supermium підходить для перегляду інформаційних сайтів і базового серфінгу на ізольованих системах.
