Правильно налаштована клавіатура економить час і зменшує роздратування від постійного перемикання розкладок.

---

## Додати мовну розкладку

`Win + I` → **Час і мова** → **Мова і регіон** → клікни на поточній мові (наприклад Англійська) → **Параметри** → **Додати клавіатуру** → вибери потрібну розкладку.

Або додай нову мову:
`Win + I` → **Мова і регіон** → **Додати мову** → знайди потрібну (наприклад Українська) → **Далі** → **Встановити**.

---

## Налаштувати гарячі клавіші перемикання

`Win + I` → **Час і мова** → **Введення** → **Розширені параметри клавіатури** → **Клавіші швидкого перемикання мов введення**

Або через старий інтерфейс:
`Win + R` → `intl.cpl` → **Клавіатури та мови** → **Змінити клавіатури** → **Перемикання клавіатури** → **Змінити** → вибери комбінацію.

Популярні варіанти:
- `Alt + Shift` (за замовчуванням)
- `Win + Space` — перемикання в Windows 11
- `Ctrl + Shift` — класичний варіант

---

## Введення спеціальних символів

**Символи через Alt-код (NumLock увімкнений):**
- `Alt + 0169` → © (копірайт)
- `Alt + 0174` → ® (зареєстровано)
- `Alt + 0176` → ° (градус)
- `Alt + 0215` → × (множення)

**Таблиця символів:**
`Win + R` → `charmap` — графічний вибір символів.

**Emoji і символи:**
`Win + .` (крапка) → відкриє панель емодзі з пошуком.

---

## Налаштування затримки і швидкості повторення

`Win + R` → `control keyboard` → повзунки **Затримка повторення** і **Швидкість повторення**.

Або:
```powershell
# Переглянути поточні значення
Get-ItemProperty "HKCU:\Control Panel\Keyboard" |
  Select-Object KeyboardDelay, KeyboardSpeed
```

---

## Перепризначити клавіші (PowerToys)

```powershell
winget install Microsoft.PowerToys
```

PowerToys → **Keyboard Manager** → **Remap a key** або **Remap a shortcut**:
- Можна перепризначити будь-яку клавішу
- Створити власні комбінації для конкретних програм

---

## Вимкнути Caps Lock

Більшість людей вмикають Caps Lock випадково. Переназнач його на Ctrl або вимкни:

```powershell
# Вимкнути Caps Lock через реєстр (потрібно перезавантаження)
$hex = [byte[]](0x00,0x00,0x00,0x00,0x00,0x00,0x00,0x00,
                 0x02,0x00,0x00,0x00,0x00,0x00,0x3A,0x00,
                 0x00,0x00,0x00,0x00)
Set-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Control\Keyboard Layout" `
  -Name "Scancode Map" -Value $hex -Type Binary
```

Або через PowerToys Keyboard Manager: Remap Caps Lock → Ctrl.

---

## Екранна клавіатура

`Win + Ctrl + O` — відкрити екранну клавіатуру.

Корисно якщо фізична клавіатура не працює або для введення паролю на публічному ПК.

---

## Резюме

Додай українську розкладку через Мова і регіон. Налаштуй `Win + Space` або `Ctrl + Shift` для швидкого перемикання. Для перепризначення клавіш — PowerToys Keyboard Manager. Caps Lock що заважає — відключи через реєстр або PowerToys.
