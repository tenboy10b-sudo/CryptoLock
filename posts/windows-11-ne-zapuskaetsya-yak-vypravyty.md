Windows 11 не запускається — одна з найстрашніших ситуацій для користувача. Але в більшості випадків це виправляється без перевстановлення. Ось покрокова діагностика від простого до складного.

---

## Спочатку: визнач симптом

| Що бачиш | Причина | Куди йти |
|----------|---------|----------|
| Чорний екран, курсор є | Драйвер відеокарти або Explorer | Крок 2 |
| Зависає на логотипі Windows | Пошкоджені системні файли | Крок 3 |
| Синій екран з кодом | Критична помилка | Крок 4 |
| "Автоматичне відновлення" в петлі | Пошкоджений завантажувач | Крок 5 |
| BIOS є але Windows не стартує | Проблема з диском або MBR | Крок 6 |

---

## Крок 1: Найпростіші перевірки

Перед діагностикою:
- Витягни всі USB флешки і зовнішні диски
- Від'єднай зовнішні монітори (залиш тільки один)
- Спробуй `Ctrl + Alt + Del` — якщо реагує, система жива
- Зажми `Win + Ctrl + Shift + B` — скидає відеодрайвер

---

## Крок 2: Увійти в Recovery Mode

**Спосіб 1:** Якщо Windows частково завантажується — `Win + I` → **Система** → **Відновлення** → **Розширений запуск** → **Перезавантажити зараз**

**Спосіб 2:** Перебий завантаження 3 рази кнопкою живлення → автоматично відкриється Recovery

**Спосіб 3:** USB з Windows 11 → вибери **Відновлення комп'ютера** (не встановлення)

---

## Крок 3: Безпечний режим

З Recovery Mode:
**Усунення несправностей** → **Розширені параметри** → **Параметри запуску** → **Перезавантажити** → **F4** (Безпечний режим)

У безпечному режимі Windows вантажиться з мінімальними драйверами. Якщо тут все працює — проблема в драйвері або програмі автозавантаження.

```powershell
# У безпечному режимі — перевірити автозавантаження
Get-ItemProperty "HKCU:\Software\Microsoft\Windows\CurrentVersion\Run"
Get-ItemProperty "HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Run"

# Вимкнути всі сторонні програми автозавантаження
msconfig  # → вкладка Автозагрузка → відключи все стороннє
```

---

## Крок 4: Відновити системні файли (з Recovery CMD)

З Recovery: **Усунення несправностей** → **Розширені параметри** → **Командний рядок**

```cmd
rem Перевірити і відновити системні файли
sfc /scannow

rem Відновити образ Windows
DISM /Online /Cleanup-Image /RestoreHealth

rem Якщо DISM не працює без інтернету — з USB
DISM /Online /Cleanup-Image /RestoreHealth /Source:WIM:D:\sources\install.wim:1 /LimitAccess
```

---

## Крок 5: Відновити завантажувач

Якщо бачиш "Автоматичне відновлення" в нескінченній петлі — пошкоджений BCD (Boot Configuration Data):

```cmd
rem З Recovery CMD:
bootrec /fixmbr
bootrec /fixboot
bootrec /scanos
bootrec /rebuildbcd

rem Або через bcdboot (замінити C: на диск з Windows)
bcdboot C:\Windows /s C: /f UEFI
```

---

## Крок 6: Перевірити диск

Проблеми з диском — часта причина що Windows не завантажується:

```cmd
rem З Recovery CMD — перевірити диск C:
chkdsk C: /f /r /x

rem Перевірити SMART статус
wmic diskdrive get status,model
```

Якщо chkdsk знаходить і виправляє помилки — перезавантаж і перевір.

---

## Крок 7: Відновлення системи

Якщо є точка відновлення до появи проблеми:

Recovery → **Усунення несправностей** → **Розширені параметри** → **Відновлення системи** → вибери дату до проблеми

---

## Крок 8: Видалити проблемне оновлення

Якщо проблема почалась після конкретного оновлення:

Recovery → **Усунення несправностей** → **Розширені параметри** → **Видалити оновлення** → вибери останнє оновлення якості або функцій

---

## Крок 9: Скидання Windows (збереження файлів)

Recovery → **Усунення несправностей** → **Скинути ПК** → **Зберегти мої файли** → **Хмарне завантаження**

Хмарне завантаження отримує свіжий образ від Microsoft. Особисті файли зберігаються, програми видаляються.

---

## Крок 10: Чисте встановлення (якщо нічого не допомогло)

1. Завантаж Media Creation Tool з microsoft.com/software-download/windows11
2. Запиши на USB (мін. 8 ГБ)
3. Завантажся з USB і обери **Встановлення**
4. При виборі типу — вибери **Вибіркове** і відформатуй системний розділ
