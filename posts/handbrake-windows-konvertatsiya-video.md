HandBrake — найкращий безкоштовний конвертер відео для Windows. Відкритий код, підтримує всі популярні формати, дає повний контроль над якістю і розміром файлу.

---

## Встановлення

```powershell
winget install HandBrake.HandBrake
```
Або з [handbrake.fr](https://handbrake.fr/downloads.php) → Windows → 64 bit.

---

## Базова конвертація відео

1. **"Open Source"** → вибери відеофайл
2. Вибери пресет у правій панелі (наприклад **"Fast 1080p30"**)
3. В полі **"Save As"** вкажи куди зберегти
4. Натисни **"Start Encode"**

---

## Найкращі пресети

| Пресет | Коли використовувати |
|--------|---------------------|
| **Fast 1080p30** | Швидка конвертація, гарна якість |
| **HQ 1080p30 Surround** | Висока якість, більший файл |
| **Super HQ 1080p30 Surround** | Максимальна якість |
| **Fast 720p30** | Для мобільних пристроїв |
| **Discord Small** | Для відправки в Discord (<8 МБ) |

---

## Налаштування якості і розміру

### Constant Quality (RF/CRF)

Головний параметр — **"Quality"** (RF або CRF):

| RF значення | Результат |
|------------|-----------|
| 18–20 | Майже без втрат, великий файл |
| 20–23 | Висока якість (рекомендовано) |
| 23–26 | Помітне стиснення, менший файл |
| 26+ | Помітна втрата якості |

**Video → Quality → RF:** менше число = краща якість.

### Відео кодек

| Кодек | Призначення |
|-------|------------|
| **H.264 (x264)** | Найсумісніший, для будь-яких пристроїв |
| **H.265 (x265)** | Вдвічі менший файл при тій же якості |
| **AV1** | Найменший розмір, повільна кодифікація |

## Стиснення відео для конкретних цілей

### Зменшити розмір файлу вдвічі (зберігши якість)

1. Video → Codec: **H.265 (x265)**
2. Quality: **RF 22–24**
3. Preset: **Fast**

### Відео для YouTube

1. Video → Codec: **H.264**
2. Quality: **RF 18**
3. Audio → Bitrate: **192 kbps AAC**
4. Framerate: Same as source

### Відео для Discord (<8 МБ)

Вибери пресет **"Discord Small"** або:
1. Video → Average Bitrate: **800 kbps**
2. Audio → Bitrate: **128 kbps**
3. Розрахуй тривалість: 8000 кБ / бітрейт = максимальна довжина

### Відео для телефону

Пресет: **"Android 720p30"** або **"Apple 720p60 Surround"**

---

## Пакетна конвертація (кілька файлів одночасно)

1. **"Open Source"** → вибери папку з відео
2. HandBrake покаже список файлів
3. Вибери пресет
4. **"Add to Queue"** для кожного або **"Add All"**
5. **"Start Queue"** → всі конвертуються по черзі

---

## Субтитри

```
Subtitles → Add Track
```

- Вибери доріжку субтитрів із файлу
- Або додай зовнішній .srt файл: **"Import SRT"**
- **"Burn In"** — вбудувати субтитри в відео (не можна вимкнути)
- Без Burn In — субтитри як окрема доріжка

---

## Аудіо

```
Audio → Add Track
```

| Кодек | Коли |
|-------|------|
| **AAC** | Максимальна сумісність |
| **AC3** | Surround sound, великий файл |
| **MP3** | Для старих пристроїв |
| **FLAC** | Без втрат (тільки MKV) |

**Passthru** — зберегти оригінальну аудіодоріжку без перекодування.

## HandBrake CLI (командний рядок)

```powershell
# Базова конвертація
HandBrakeCLI.exe -i input.mp4 -o output.mp4 --preset "Fast 1080p30"

# З налаштуванням якості
HandBrakeCLI.exe -i input.mp4 -o output.mp4 -e x265 -q 22

# Пакетна конвертація всіх mp4 в папці
Get-ChildItem *.mp4 | ForEach-Object {
    HandBrakeCLI.exe -i $_.FullName -o "$($_.BaseName)_converted.mp4" --preset "Fast 1080p30"
}
```

## Вирішення проблем

### Конвертація дуже повільна
- Video → Encoder Preset: **"Veryfast"** або **"Ultrafast"**
- Або використовуй апаратне прискорення: Video → Encoder → **"H.264 (Nvidia NVEnc)"**

### Чорний екран у вихідному відео
Спробуй Video → Encoder: **H.264** замість H.265.

### Немає звуку після конвертації
Audio → перевір що обрана правильна доріжка і не вибрано "None".
