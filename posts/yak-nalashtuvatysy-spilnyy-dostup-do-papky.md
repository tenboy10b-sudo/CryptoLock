Спільний доступ до папки дозволяє іншим ПК в мережі читати або записувати файли без фізичного носія. Ось як налаштувати це правильно.

---

## Крок 1: Увімкнути виявлення мережі

`Win + I` → **Мережа і Інтернет** → **Розширені параметри мережі** → **Розширені параметри спільного доступу**:

- **Виявлення мережі**: Увімкнути
- **Спільний доступ до файлів і принтерів**: Увімкнути

Переконайся що ПК в **Приватній** мережі, не в Публічній.

---

## Крок 2: Відкрити спільний доступ до папки

Правий клік на папці → **Властивості** → вкладка **Спільний доступ** → **Спільний доступ...**

Додай користувачів:
- **Everyone** — для всіх в мережі (без пароля)
- Конкретне ім'я користувача — тільки для нього

Рівень дозволів:
- **Читання** — тільки перегляд файлів
- **Читання/Запис** — можна також змінювати і видаляти

Натисни **Поділитись** → запам'ятай мережевий шлях (наприклад `\\ПК-ІМ'Я\Папка`).

---

## Крок 3: Підключитись з іншого ПК

**Через Провідник:**
В адресному рядку введи: `\\192.168.1.100\НазваПапки` або `\\ІМ'Я-ПК\НазваПапки`

**Підключити як мережевий диск:**
Провідник → **Цей ПК** → **Підключити мережевий диск** → вибери букву → введи шлях → **Відновлювати при вході**.

```powershell
# Підключити через PowerShell
New-PSDrive -Name "Z" -PSProvider FileSystem `
  -Root "\\192.168.1.100\SharedFolder" -Persist
```

---

## Крок 4: Налаштувати NTFS дозволи (додатково)

Для точного контролю доступу — налаштуй NTFS дозволи окремо:

Правий клік на папці → **Властивості** → **Безпека** → **Змінити** → додай або видали користувачів і дозволи.

**SMB дозволи** (налаштовані в Кроці 2) і **NTFS дозволи** діють разом — застосовується найбільш обмежений варіант.

---

## Керування через PowerShell

```powershell
# Створити спільну папку
New-SmbShare -Name "SharedDocs" -Path "C:\SharedDocuments" `
  -FullAccess "Everyone"

# З обмеженим доступом
New-SmbShare -Name "WorkFiles" -Path "C:\Work" `
  -ReadAccess "Domain Users" `
  -FullAccess "Administrators"

# Переглянути всі спільні папки
Get-SmbShare

# Видалити спільну папку
Remove-SmbShare -Name "SharedDocs"
```

---

## Типові проблеми

**"Немає доступу до мережевої папки":**
- Перевір що брандмауер дозволяє SMB (порт 445)
- Перевір дозволи папки
- Спробуй підключитись по IP замість імені ПК

```powershell
# Дозволити SMB через брандмауер
Enable-NetFirewallRule -DisplayGroup "File and Printer Sharing"
```

**Запитує пароль:**
Якщо на ПК де папка немає відповідного облікового запису, Windows запитує пароль. Створи однакового користувача з однаковим паролем на обох ПК, або вимкни парольний захист:

`Розширені параметри спільного доступу` → **Усі мережі** → **Спільний доступ із захистом паролем** → Вимкнути.

**Папка не видна в мережевому оточенні:**
Підключайся напряму по шляху `\\IP\НазваПапки` — автовиявлення часто не працює.

---

## Резюме

Правий клік на папці → Властивості → Спільний доступ → додай Everyone або конкретного користувача. З іншого ПК підключайся по `\\IP\НазваПапки`. Для постійного підключення — підключи як мережевий диск з буквою.
