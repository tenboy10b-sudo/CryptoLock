MSI Afterburner — стандартний інструмент для моніторингу і налаштування відеокарти. Показує температуру, навантаження і частоти GPU прямо в грі, дозволяє розігнати відеокарту і налаштувати профілі вентиляторів.

---

## Встановлення

1. Завантаж з [msi.com/Landing/afterburner](https://www.msi.com/Landing/afterburner/graphics-cards)
2. Встанови разом з **RivaTuner Statistics Server (RTSS)** — потрібен для оверлею в іграх

```powershell
winget install MSI.Afterburner
```

---

## Моніторинг в реальному часі

Головне вікно показує:
- **GPU Usage** — навантаження відеокарти %
- **GPU Temp** — температура GPU
- **VRAM Usage** — використання відеопам'яті
- **GPU Clock** — поточна частота ядра
- **Fan Speed** — швидкість вентиляторів

---

## Налаштування оверлею в іграх (OSD)

Найкорисніша функція — показ метрик поверх гри:

1. Відкрий **MSI Afterburner** → **Settings (шестерня)**
2. Вкладка **Monitoring**
3. Для кожного датчика (GPU Temp, FPS, VRAM...) постав галочку **"Show in On-Screen Display"**
4. Натисни **OK**
5. Запусти гру — в куті побачиш метрики

**RTSS налаштування** (Rivatuner):
```
Position: Top-left / Top-right
Zoom: 75-100%
```

### Які датчики додати в OSD

Рекомендований мінімум:
- **Framerate** (FPS)
- **GPU Temperature**
- **GPU Usage %**
- **VRAM Usage**
- **CPU Temperature** (якщо є)

---

## Розгін GPU (Overclocking)

> ⚠️ Розгін може пошкодити відеокарту. Роби покроково і моніторь температуру. Не перевищуй 85°C.

### Базовий розгін

1. Натисни **замок** (lock) щоб синхронізувати Core і Memory ліміти
2. **Core Clock** — збільшуй по +50 MHz
3. **Memory Clock** — збільшуй по +100 MHz
4. Натисни **Apply (галочка)**
5. Тестуй стабільність — запусти гру або стрес-тест (FurMark)
6. Якщо стабільно — збільш ще

**Power Limit і Temp Limit:**
Підніми до максимуму (+20%) — дозволяє GPU boost вище.

### Збереження профілю

Натисни **Save** → вибери слот (1-5) → присвой гарячу клавішу.

---

## Власний профіль вентиляторів

За замовчуванням вентилятори керуються автоматично. Можна налаштувати свою криву:

1. Settings → **Fan** → увімкни **"Enable user defined software automatic fan control"**
2. Клікай на графік щоб додати точки кривої:
   ```
   50°C → 30% швидкість
   65°C → 50%
   75°C → 70%
   85°C → 100%
   ```
3. **Apply**

**Тихий профіль** (для роботи):
```
<60°C → 0% (пасивне охолодження)
70°C  → 40%
80°C  → 70%
```

## Запис відео і скріншоти

MSI Afterburner вміє записувати відео прямо під час гри:

```
Settings → Video Capture:
Video format: MP4
Video quality: High
Hotkey: F12 (або своя)
```

**Гарячі клавіші за замовчуванням:**
- `F12` — скріншот
- `F9` — почати/зупинити запис

---

## Benchmark — вимір FPS

```
Settings → Benchmark:
Start logging: F11
Stop/Save: F12
```

Зберігає лог FPS для порівняння до і після розгону.

## Профілі для різних ситуацій

Налаштуй 3 профілі:

| Профіль | Налаштування | Коли |
|---------|-------------|------|
| **Stock** | Стандартні значення | Нормальна робота |
| **OC Gaming** | +100 Core, +200 Mem | Ігри |
| **Silent** | -50 Core, тихий вентилятор | Тиха робота |

## MSI Afterburner vs HWiNFO vs GPU-Z

| | Afterburner | HWiNFO | GPU-Z |
|-|-------------|--------|-------|
| OSD в іграх | ✅ | ✅ (через RTSS) | ❌ |
| Розгін | ✅ | ❌ | ❌ |
| Профіль вентиляторів | ✅ | ❌ | ❌ |
| Запис відео | ✅ | ❌ | ❌ |
| Детальні датчики | Середньо | ✅ | GPU only |

## Резюме

| Задача | Де в Afterburner |
|--------|-----------------|
| OSD в іграх | Settings → Monitoring → Show in OSD |
| Розгін Core | Core Clock слайдер + Apply |
| Профіль вентилятора | Settings → Fan → Custom curve |
| Запис відео | Settings → Video Capture → F9 |
| Зберегти профіль | Save → слот 1-5 |
