Гарячі клавіші економлять хвилини щодня. Ось найкорисніші — від базових до тих що мало хто знає.

---

## Основні системні

| Клавіші | Дія |
|---------|-----|
| `Win + D` | Показати/сховати робочий стіл |
| `Win + E` | Відкрити Провідник |
| `Win + L` | Заблокувати екран |
| `Win + R` | Відкрити "Виконати" |
| `Win + S` | Пошук |
| `Win + X` | Меню швидких дій (адмін) |
| `Win + I` | Параметри Windows |
| `Win + V` | Буфер обміну з історією |
| `Win + .` | Емодзі і символи |
| `Win + H` | Диктовка |
| `Win + Shift + S` | Скріншот вибраної області |
| `Win + PrtScn` | Скріншот і зберегти в Зображення |

---

## Керування вікнами

| Клавіші | Дія |
|---------|-----|
| `Win + ←/→` | Прив'язати вікно ліворуч/праворуч |
| `Win + ↑` | Розгорнути вікно |
| `Win + ↓` | Згорнути вікно |
| `Win + Z` | Snap Layouts (вибір розкладки) |
| `Alt + Tab` | Перемикання між вікнами |
| `Win + Tab` | Огляд завдань (Task View) |
| `Alt + F4` | Закрити активне вікно |
| `Win + M` | Згорнути всі вікна |

---

## Віртуальні столи

| Клавіші | Дія |
|---------|-----|
| `Win + Ctrl + D` | Новий віртуальний стіл |
| `Win + Ctrl + →/←` | Перемикати столи |
| `Win + Ctrl + F4` | Закрити поточний стіл |
| `Win + Ctrl + Shift + →/←` | Перемістити вікно між столами |

---

## Провідник файлів

| Клавіші | Дія |
|---------|-----|
| `Ctrl + N` | Нове вікно Провідника |
| `Ctrl + T` | Нова вкладка (Windows 11) |
| `Ctrl + W` | Закрити вкладку |
| `Alt + ↑` | На папку вище |
| `F2` | Перейменувати файл |
| `F5` | Оновити |
| `Ctrl + Shift + N` | Нова папка |
| `Delete` | Видалити в кошик |
| `Shift + Delete` | Видалити назавжди |

---

## Текст і буфер обміну

| Клавіші | Дія |
|---------|-----|
| `Ctrl + C/X/V` | Копіювати/вирізати/вставити |
| `Ctrl + Z` | Скасувати |
| `Ctrl + Y` | Повторити |
| `Ctrl + A` | Виділити все |
| `Ctrl + F` | Знайти |
| `Win + V` | Буфер обміну з історією |
| `Ctrl + Shift + V` | Вставити без форматування (Chrome/Edge) |

---

## Системні інструменти

| Клавіші | Дія |
|---------|-----|
| `Ctrl + Shift + Esc` | Диспетчер завдань |
| `Win + Pause` | Властивості системи |
| `Win + P` | Режим дисплея |
| `Win + K` | Підключення пристроїв (Cast) |
| `Win + A` | Центр дій |
| `Win + N` | Центр сповіщень (Windows 11) |
| `Ctrl + Alt + Del` | Меню безпеки |

---

## Менш відомі але корисні

| Клавіші | Дія |
|---------|-----|
| `Win + Ctrl + Shift + B` | Скинути відеодрайвер |
| `Win + +/-` | Лупа (збільшення екрана) |
| `Win + Esc` | Закрити лупу |
| `Ctrl + Shift + T` | Відновити закриту вкладку в браузері |
| `F6` | Перейти до адресного рядка |

## Резюме

Вивчи по 3-5 нових комбінацій на тиждень — через місяць більшість стануть автоматичними. Найцінніші для продуктивності: `Win + V` (буфер), `Win + Z` (snap), `Win + Shift + S` (скріншот), `Win + Ctrl + D/→/←` (віртуальні столи).
