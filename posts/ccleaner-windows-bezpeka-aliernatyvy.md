CCleaner — найпопулярніша утиліта для очищення Windows. Але за останні роки виникли питання до безпеки і доцільності використання. Ось що потрібно знати перед встановленням.

---

## Чи безпечний CCleaner у 2026 році

**Коротка відповідь:** безкоштовна версія — прийнятно безпечна, але є нюанси.

**Що сталось:**
- 2017 рік — CCleaner був зламаний і містив шкідливий код (зараз виправлено)
- З 2017 року Avast придбав CCleaner і додав агресивну рекламу
- Встановлення намагається додати Avast антивірус без явної згоди

**Висновок:** якщо встановлюєш — уважно читай кожен крок інсталятора і відмовляйся від додаткового ПЗ. Альтернативи без цих проблем є вбудовані в Windows.

---

## Встановлення CCleaner

1. Завантаж з [ccleaner.com](https://www.ccleaner.com/ccleaner/download) — вибери **"Free"**
2. При встановленні **зніми галочки** з будь-яких пропозицій встановити Avast або інше ПЗ
3. Запусти від імені адміністратора

---

## Очищення тимчасових файлів

```
Запусти CCleaner → "Custom Clean" → "Analyze" → "Run Cleaner"
```

**Що видаляє:**
- Тимчасові файли Windows (`%temp%`)
- Кеш браузерів (Chrome, Firefox, Edge)
- Cookies (будь обережний — вийдеш з усіх сайтів)
- Кошик
- Логи Windows Update
- Мініатюри

> Порада: знімай галочку з **"Cookies"** якщо не хочеш виходити з усіх сайтів.

## Очищення реєстру — чи варто?

CCleaner пропонує очистити реєстр від "непотрібних" записів. **Офіційна позиція Microsoft — не треба.**

**Чому:**
- Сучасний реєстр Windows оптимізований і "сміття" в ньому майже не впливає на швидкість
- Неправильне видалення запису реєстру може зламати програму або систему
- Підвищення швидкості від очищення реєстру — міф

**Якщо все ж хочеш:**
`Registry → Scan for Issues → Fix selected issues → Зроби резервну копію`

## Управління автозапуском

Одна з найкорисніших функцій CCleaner:

```
Tools → Startup → Windows
```

Показує всі програми що запускаються з Windows. Можна вимкнути або видалити непотрібні.

**Те саме безкоштовно і безпечніше:**
```
Ctrl + Shift + Esc → Автозапуск
```
Або:
```powershell
# Через PowerShell
Get-CimInstance Win32_StartupCommand | Select-Object Name, Command
```

## Деінсталятор програм

```
Tools → Uninstall
```

Показує всі встановлені програми — зручніше ніж стандартний список Windows.

## Безкоштовні альтернативи CCleaner

Все що робить CCleaner можна зробити вбудованими засобами Windows:

### Очищення диску (вбудоване)
```
Win + R → cleanmgr → вибери диск C: → OK
Натисни "Очистити системні файли" для глибокого очищення
```

Або через PowerShell:
```powershell
# Автоматичне очищення всіх категорій
cleanmgr /sagerun:1
```

### Storage Sense (автоматичне очищення)
```
Win + I → Система → Пам'ять → Налаштувати Storage Sense
```
Автоматично видаляє тимчасові файли за розкладом.

### BleachBit (відкритий код, без реклами)
Завантаж з [bleachbit.org](https://www.bleachbit.org) — безкоштовна альтернатива без агресивної реклами.

## Скільки місця реально звільняє CCleaner

Реалістичні очікування:
- Перший запуск на запущеній системі: 1–10 ГБ
- Регулярне використання: 100–500 МБ
- Очищення реєстру: 0 ефективного ефекту на швидкість

Найбільше місця займають:
- Кеш браузерів (особливо Chrome — до кількох ГБ)
- Логи Windows Update після великих оновлень
- Папка `WinSxS` (не рекомендую чіпати)

## Часті питання

### CCleaner прискорює Windows?
Незначно — при першому запуску може трохи прискорити завантаження браузера. На загальну швидкість системи майже не впливає.

### Чи видаляє CCleaner віруси?
Ні — це не антивірус. Для захисту використовуй Windows Defender.

### Чи потрібно платити за Pro версію?
Ні — безкоштовна версія має всі основні функції.
