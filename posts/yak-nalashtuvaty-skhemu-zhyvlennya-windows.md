Схема живлення визначає як Windows балансує між продуктивністю і споживанням енергії. Правильна схема може значно збільшити FPS в іграх або час роботи ноутбука.

---

## Доступні схеми живлення

`Win + R` → `powercfg.cpl`

| Схема | Для кого | CPU поведінка |
|-------|----------|---------------|
| **Збалансована** | Більшість користувачів | Масштабується по потребі |
| **Висока продуктивність** | Ігри, важкі задачі | CPU завжди на максимумі |
| **Економія енергії** | Ноутбук від батареї | CPU знижений, екран темніший |
| **Максимальна продуктивність** | Прихована, для серверів | Без обмежень взагалі |

---

## Увімкнути приховані схеми

```powershell
# Показати всі доступні схеми
powercfg /list

# Увімкнути Максимальну продуктивність
powercfg /setactive e9a42b02-d5df-448d-aa00-03f14749eb61

# Якщо не знайдено — відновити
powercfg /duplicatescheme e9a42b02-d5df-448d-aa00-03f14749eb61
```

---

## Змінити схему швидко

```powershell
# Збалансована
powercfg /setactive SCHEME_BALANCED

# Висока продуктивність
powercfg /setactive SCHEME_MIN

# Економія енергії
powercfg /setactive SCHEME_MAX
```

---

## Налаштувати конкретні параметри

`powercfg.cpl` → вибери схему → **Змінити параметри схеми** → **Змінити додаткові параметри живлення**

Найважливіші параметри:

**Жорсткий диск → Вимикати жорсткий диск через:**
- Від мережі: Ніколи (запобігає затримкам при першому зверненні)
- Від батареї: 10-20 хвилин

**Сон → Перейти в режим сну через:**
- Від мережі: Ніколи або 30+ хвилин
- Від батареї: 10-15 хвилин

**Процесор → Мінімальний стан процесора:**
- Збалансована: 5%
- Висока продуктивність: 100% (CPU ніколи не знижується)

**Процесор → Максимальний стан процесора:**
- Якщо CPU перегрівається — знизь до 90-95%

## Через PowerShell (детально)

```powershell
# Поточна активна схема
powercfg /getactivescheme

# Детальні налаштування активної схеми
powercfg /query SCHEME_CURRENT

# Встановити мінімальний стан CPU (5% від батареї)
powercfg /setdcvalueindex SCHEME_CURRENT SUB_PROCESSOR PROCTHROTTLEMIN 5

# Встановити час до сну (1800 секунд = 30 хвилин)
powercfg /setacvalueindex SCHEME_CURRENT SUB_SLEEP STANDBYIDLE 1800
powercfg /setactive SCHEME_CURRENT
```

## Для ноутбука: Power Mode в Windows 11

`Win + I` → **Система** → **Живлення і акумулятор** → **Режим живлення**:
- **Найкраща економія енергії** — максимальний час від батареї
- **Збалансований** — за замовчуванням
- **Найкраща продуктивність** — максимальна швидкість

Простіший спосіб ніж схеми живлення для більшості користувачів.

---

## Резюме

Для ігор і важких задач: **Висока продуктивність** або **Максимальна продуктивність**. Для ноутбука від батареї: **Збалансована** або **Економія енергії**. `powercfg /setactive SCHEME_MIN` — найшвидший спосіб перемкнути з командного рядка.
