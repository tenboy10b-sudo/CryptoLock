Process Explorer — потужна заміна Диспетчеру завдань. Показує що кожен процес насправді робить, які файли відкриті і позначає підозрілі процеси.

---

## Встановити

```powershell
winget install Microsoft.Sysinternals.ProcessExplorer
```

---

## Замінити Диспетчер завдань

Process Explorer → **Options** → **Replace Task Manager**

Тепер `Ctrl + Alt + Delete` відкриває Process Explorer.

---

## Ключові переваги

| Можливість | Диспетчер завдань | Process Explorer |
|-----------|-----------------|-----------------|
| Дерево процесів (батько/дитина) | ❌ | ✅ |
| DLL завантажені процесом | ❌ | ✅ |
| Handles (відкриті файли, реєстр) | ❌ | ✅ |
| Інтеграція VirusTotal | ❌ | ✅ |
| Підказки з описом | ❌ | ✅ |

---

## Знайти який процес тримає файл

```
Ctrl + F → введи ім'я файлу → покаже який процес його тримає
```

Корисно при помилці "файл використовується".

---

## Перевірка через VirusTotal

ПКМ на процесі → **Check VirusTotal** → результати у браузері

**Червоні записи** = VirusTotal позначив → досліджуй негайно.

---

## Підозрілі ознаки процесів

- **Фіолетовий колір** = запакований/стиснутий виконуваний (поширено в малваре)
- Два процеси з однаковим ім'ям з різними шляхами
- `svchost.exe` НЕ в `C:\Windows\System32\`
- Непідписані exe без назви компанії

---

## Вбити процес разом з дочірніми

ПКМ → **Kill Process Tree** — вбиває процес і всі що він запустив.

---

## Часті питання

### Process Explorer показує фіолетовий процес — це малваре?

Фіолетовий означає запакований виконуваний файл. Деяке легітимне ПЗ теж пакується. Перевір VirusTotal і переконайся в правильності шляху.

### svchost.exe споживає багато CPU — як знайти яку службу?

Наведи курсор на процес → підказка показує які служби в ньому запущені. Або: Properties → Services.

---

## Резюме

Встанови і заміни Диспетчер завдань. VirusTotal для підозрілих. Шукай непідписані, фіолетові або дубльовані процеси. `Ctrl+F` для пошуку по файлах. Перегляд DLL для виявлення ін'єкцій.
