7-Zip — найкращий безкоштовний архіватор для Windows. Відкритий код, без реклами, без обмежень. Стискає краще за WinRAR у більшості випадків і повністю безкоштовний — назавжди.

---

## Чому 7-Zip а не WinRAR або WinZip

| | 7-Zip | WinRAR | WinZip |
|-|-------|--------|--------|
| Ціна | Безкоштовно | Умовно-безкоштовно | Платно |
| Відкритий код | ✅ | ❌ | ❌ |
| Ступінь стиснення | Відмінний | Хороший | Середній |
| Формат 7z | ✅ (рідний) | ✅ | ✅ |
| Шифрування AES-256 | ✅ | ✅ | ✅ |
| Реклама | ❌ | ❌ | ❌ |
| Розмір | ~1.5 МБ | ~4 МБ | ~40 МБ |

## Встановлення

1. Завантаж з [7-zip.org](https://www.7-zip.org)
2. Вибери версію:
   - **64-bit x64** — для сучасних Windows (майже завжди цей)
   - **32-bit x86** — для старих систем
3. Запусти інсталятор → **"Install"**

**Або через winget:**
```powershell
winget install 7zip.7zip
```

## Основні операції

### Розпакувати архів

**Через контекстне меню** (правою кнопкою на архів):
- **"7-Zip → Розпакувати тут"** — розпакує в поточну папку
- **"7-Zip → Розпакувати в [назва папки]\"** — створить підпапку
- **"7-Zip → Відкрити архів"** — переглянути вміст без розпакування

**Через інтерфейс:**
1. Відкрий 7-Zip File Manager (в меню Пуск)
2. Знайди архів → натисни **"Розпакувати"**
3. Вкажи куди → **"OK"**

### Створити архів

1. Вибери файли або папку
2. Правою кнопкою → **"7-Zip → Додати до архіву..."**
3. Налаштуй параметри:

| Параметр | Рекомендація |
|---------|-------------|
| Формат | 7z (краще стиснення) або zip (сумісність) |
| Рівень стиснення | Нормальний (баланс) або Максимальний |
| Метод стиснення | LZMA2 для 7z |
| Розмір словника | 32 МБ або більше для великих файлів |

4. **"OK"** → архів створено

## Шифрування архіву паролем

Щоб захистити архів паролем:

1. При створенні архіву → розділ **"Шифрування"**
2. Введи пароль двічі
3. Метод шифрування: **AES-256** (найнадійніший)
4. Увімкни **"Шифрувати назви файлів"** — приховає навіть імена файлів

```
⚠️ Якщо забудеш пароль — відновити неможливо.
Зберігай паролі в менеджері паролів.
```

## Розбивка на частини (Split archive)

Для великих файлів або якщо потрібно розіслати частинами:

1. Додати до архіву → поле **"Розбити на томи розміром"**
2. Вкажи розмір частини:
   - `700m` — для CD
   - `4092m` — для FAT32 флешки
   - `25000m` — для Google Drive

Частини будуть: `архів.7z.001`, `архів.7z.002` тощо.
Для розпакування — просто розпакуй першу частину.

## Командний рядок 7-Zip

7-Zip має потужний CLI для автоматизації:

```cmd
:: Розпакувати архів
7z x архів.7z -o"C:\Destination"

:: Створити архів
7z a архів.7z "C:\Folder\*"

:: Створити з паролем
7z a -p"МійПароль" -mhe архів.7z "C:\Folder"

:: Переглянути вміст архіву
7z l архів.zip

:: Перевірити цілісність
7z t архів.7z

:: Розпакувати конкретний файл
7z e архів.zip файл.txt
```

**PowerShell автоматизація — резервна копія з архівацією:**
```powershell
$date = Get-Date -Format "yyyy-MM-dd"
$src  = "C:\ImportantData"
$dest = "D:\Backups\backup-$date.7z"
& "C:\Program Files\7-Zip\7z.exe" a -t7z -mx=5 -p"BackupPassword" $dest $src
Write-Host "Резервна копія: $dest"
```

## Асоціація форматів

Щоб 7-Zip відкривав всі архіви за замовчуванням:

```
7-Zip File Manager → Сервіс → Параметри → Система
```

Встав галочки навпроти всіх форматів або натисни **"+"** щоб вибрати всі.

## Часті питання

### Чи можна відкрити RAR архів в 7-Zip?
Так — 7-Zip читає RAR але не створює. Для створення RAR потрібен WinRAR.

### Архів пошкоджений — що робити?
```cmd
:: Спроба відновлення
7z t архів.7z
7z e -y архів.7z
```

### Як відкрити ISO в 7-Zip?
7-Zip вміє відкривати ISO як звичайний архів — правою кнопкою → **"Відкрити архів"**.
