VirtualBox дозволяє запускати Windows, Linux або будь-яку іншу ОС всередині твого Windows — в окремому вікні. Безкоштовно, без обмежень, від Oracle.

**Коли потрібен VirtualBox:**
- Протестувати програму не забруднюючи основну систему
- Запустити Linux не виходячи з Windows
- Розробляти і тестувати в ізольованому середовищі
- Навчатись адмініструванню без ризику для основного ПК

---

## Вимоги до системи

| Компонент | Мінімум | Рекомендовано |
|-----------|---------|---------------|
| RAM | 4 ГБ | 8 ГБ+ |
| Диск | 20 ГБ вільно | 50 ГБ+ |
| CPU | з підтримкою VT-x/AMD-V | будь-який сучасний |
| Windows | 10 64-bit | 10/11 64-bit |

**Перевірити чи увімкнена віртуалізація:**
```powershell
# В PowerShell
(Get-WmiObject Win32_Processor).VirtualizationFirmwareEnabled

# Або через диспетчер завдань
Ctrl+Shift+Esc → Продуктивність → CPU → Віртуалізація: Enabled
```

Якщо вимкнена — увімкни в BIOS: Intel VT-x або AMD-V.

## Крок 1 — Встановлення VirtualBox

1. Завантаж з [virtualbox.org/wiki/Downloads](https://www.virtualbox.org/wiki/Downloads)
   - **"Windows hosts"** — для Windows
2. Запусти інсталятор від адміністратора
3. Всі налаштування залиш за замовчуванням → **"Install"**
4. Дозволь встановлення мережевих адаптерів і драйверів

**Також завантаж Extension Pack:**
На тій же сторінці → **"VirtualBox Extension Pack"** → встанови через VirtualBox:
`Файл → Налаштування → Розширення → +`

Extension Pack додає: USB 2.0/3.0, RDP сервер, шифрування дисків.

---

## Крок 2 — Створення віртуальної машини

1. Натисни **"Створити"** (Ctrl+N)
2. Заповни параметри:

### Основні параметри

| Поле | Що вводити |
|------|-----------|
| Ім'я | Windows 11 Test або Ubuntu 24.04 |
| Тип | Microsoft Windows або Linux |
| Версія | Windows 11 (64-bit) або Ubuntu (64-bit) |

### Обсяг RAM
- Windows 11: мінімум **4096 МБ** (рекомендую 6144)
- Ubuntu Desktop: мінімум **2048 МБ**
- Ubuntu Server: **1024 МБ** достатньо

### Жорсткий диск
- Вибери **"Створити новий віртуальний жорсткий диск"**
- Тип: **VDI** (рекомендую)
- Розмір: Windows 11 — мінімум 64 ГБ, Ubuntu — 20 ГБ
- Формат: **Динамічний** (займає менше місця реально)

---

## Крок 3 — Встановлення ОС у віртуальну машину

1. Вибери VM → **"Налаштування"** → **"Носії"**
2. Клікни на порожній привід → іконка диску → **"Вибрати файл диску"**
3. Вкажи ISO файл (Windows або Linux)
4. **"OK"** → **"Запустити"**

Далі — звичайний процес встановлення ОС як на реальному ПК.

---

## Крок 4 — Встановлення Guest Additions

Guest Additions значно покращують роботу VM: повноекранний режим, спільний буфер обміну, перетягування файлів, краще відео.

**Після встановлення ОС в VM:**
```
Пристрої → Вставити образ компакт-диска Guest Additions...
```

У Windows гості — запустить автоматично.
У Linux гості:
```bash
sudo apt install build-essential dkms linux-headers-$(uname -r)
sudo mount /dev/cdrom /mnt
sudo sh /mnt/VBoxLinuxAdditions.run
sudo reboot
```

## Налаштування мережі

VirtualBox пропонує кілька режимів мережі:

| Режим | VM бачить інтернет | Хост бачить VM | Коли використовувати |
|-------|-------------------|----------------|---------------------|
| NAT | ✅ | ❌ | Простий доступ до інтернету |
| Bridged | ✅ | ✅ | VM як окремий ПК в мережі |
| Host-only | ❌ | ✅ | Ізольована мережа між VM і хостом |
| Internal | ❌ | ❌ | Тільки між VM |

**Налаштування:** VM → Налаштування → Мережа → Адаптер 1 → Тип підключення

## Спільні папки

Для обміну файлами між Windows і VM:

1. VM → **"Налаштування"** → **"Спільні папки"** → **"+"**
2. Вкажи папку на хості
3. Ім'я: `share`
4. Постав галочку **"Автопідключення"**

У Windows гості папка з'явиться як мережевий диск.
У Linux гості:
```bash
sudo mount -t vboxsf share /mnt/share
# Або автоматично через /etc/fstab:
share /mnt/share vboxsf defaults,uid=1000,gid=1000 0 0
```

## Корисні можливості

### Знімки стану (Snapshots)
Зберігають стан VM в будь-який момент — можна відкотитись:
```
Машина → Зробити знімок стану
```

### Клонування VM
Права кнопка на VM → **"Клонувати"** — корисно для тестових середовищ.

### Безголовий режим (Headless)
Запуск VM без вікна — як сервер:
```powershell
& "C:\Program Files\Oracle\VirtualBox\VBoxHeadless.exe" --startvm "Ubuntu Server"
```

## Вирішення помилок

### "VT-x is disabled in the BIOS"
Увімкни Intel VT-x або AMD-V в BIOS. Зазвичай у розділі Advanced → CPU Configuration.

### "Not in a hypervisor partition (HVP=0)"
Конфлікт з Hyper-V (Windows Sandbox або WSL 2). Вимкни в PowerShell:
```powershell
bcdedit /set hypervisorlaunchtype off
# Перезавантаж
```

Або встанови VirtualBox 7.0+ — він підтримує роботу поруч з Hyper-V.

### VM дуже повільна
- Збільш RAM і CPU ядра в налаштуваннях
- Встанови Guest Additions
- Увімкни 3D прискорення: Налаштування → Дисплей → Увімкнути 3D прискорення
- Використовуй SSD для файлів VM
