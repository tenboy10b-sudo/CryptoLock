Два монітори підвищують продуктивність на 20–40% — це підтверджено дослідженнями. Браузер на одному екрані, редактор на іншому — не потрібно постійно перемикатися. Ось як це налаштувати правильно.

---

## Що потрібно перед підключенням

**Перевір порти на відеокарті або ноутбуці:**
- **DisplayPort** — найкраще: підтримує 144 Гц, 4K, HDR
- **HDMI 2.0/2.1** — добре для 4K 60 Гц або 1080p 144 Гц
- **HDMI 1.4** — обмежений: максимум 1080p 60 Гц або 4K 30 Гц
- **USB-C з DisplayPort Alt Mode** — на сучасних ноутбуках
- **VGA/DVI** — застарілі, без звуку, уникай якщо є вибір

**Перевір порти на моніторах** — і підбери відповідний кабель.

> **Порада:** якщо є вибір між HDMI і DisplayPort — бери DisplayPort. Він надійніший при вищих частотах.

---

## Крок 1: Фізичне підключення

1. Вимкни ПК (необов'язково, але безпечніше)
2. Підключи кабель від відеокарти до другого монітора
3. Увімкни монітор
4. Увімкни ПК

Windows автоматично визначить новий монітор при завантаженні. Якщо другий екран залишається чорним — читай розділ про усунення проблем нижче.

---

## Крок 2: Відкрити налаштування дисплея

Правий клік на робочому столі → **Параметри дисплея**

Або: `Win + I` → **Система** → **Дисплей**

Вгорі ти побачиш прямокутники що позначають твої монітори — **1** і **2**.

---

## Крок 3: Вибрати режим відображення

Натисни `Win + P` щоб швидко перемикати режими:

| Режим | Що робить | Коли використовувати |
|-------|-----------|----------------------|
| **Тільки екран ПК** | Другий вимкнений | Один монітор |
| **Дублювати** | Однакове на обох | Презентації |
| **Розширити** | Різний вміст | Щоденна робота |
| **Тільки другий екран** | Перший вимкнений | Ноутбук закритий |

Для роботи обирай **Розширити** — це дозволяє тягнути вікна між екранами.

---

## Крок 4: Розставити монітори правильно

У **Параметрах дисплея** перетягни прямокутники 1 і 2 так, щоб вони відповідали фізичному розташуванню твоїх моніторів.

**Приклад:** якщо другий монітор стоїть праворуч — прямокутник **2** має бути праворуч від **1**. Якщо ліворуч — ліворуч. Якщо монітори на різній висоті — підніми або опусти прямокутник відповідно.

Це важливо: якщо розташування неправильне, курсор буде "застрягати" при переході між екранами.

Натисни **Застосувати** після зміни.

---

## Крок 5: Налаштувати роздільну здатність

Клікни на монітор у верхній частині екрана → прокрути до **Роздільна здатність дисплея** → вибери **Рекомендовану** (нативну для твого монітора).

Ніколи не використовуй нижчу за нативну без причини — зображення буде розмитим.

**Типові нативні роздільні здатності:**
- Full HD монітор: 1920×1080
- QHD/2K монітор: 2560×1440
- 4K монітор: 3840×2160

---

## Крок 6: Налаштувати частоту оновлення

Клікни на монітор → **Розширені параметри дисплея** → **Частота оновлення дисплея**

Встанови максимальну підтримувану частоту:
- 144 Гц або 165 Гц для ігрових моніторів
- 75 Гц для офісних
- 60 Гц мінімум

```powershell
# Переглянути підтримувані режими через PowerShell
Get-WmiObject -Namespace "root\wmi" -Class "WmiMonitorListedSupportedSourceModes" |
  Select-Object -ExpandProperty MonitorSourceModes |
  ForEach-Object { "$($_.HorizontalActivePixels)x$($_.VerticalActivePixels) @ $([math]::Round(10000000/$_.VSyncFrequencyDivider)) Hz" } |
  Sort-Object -Unique
```

---

## Крок 7: Налаштувати масштаб (DPI)

Якщо монітори різні (наприклад 1080p і 4K), текст на них виглядатиме по-різному. Налаштуй масштаб окремо для кожного:

Клікни на монітор → **Масштаб** → вибери значення:
- 1080p монітор: **100%**
- 1440p монітор: **125%**
- 4K монітор: **150–200%**

**Якщо після масштабування програми виглядають розмито:**
`Win + I` → **Система** → **Дисплей** → **Розширені параметри масштабування** → увімкни **Дозволити Windows виправляти розмитість програм**.

---

## Крок 8: Вибрати основний монітор

Основний монітор — де з'являється меню Пуск, сповіщення і нові вікна за замовчуванням.

Клікни на потрібний монітор → постав галочку **Зробити цим головним дисплеєм**.

---

## Налаштування панелі завдань на обох моніторах

`Win + I` → **Персоналізація** → **Панель завдань** → **Поведінка панелі завдань** → увімкни:
- **Показувати панель завдань на всіх дисплеях**
- Вибери що показувати: всі вікна або тільки вікна поточного монітора

---

## Різні шпалери на кожному моніторі

Правий клік на будь-якому зображенні в Провіднику → **Встановити як фон робочого столу** — і потім правий клік на шпалерах у Персоналізації → **Встановити для монітора 1** / **Монітора 2**.

Або: `Win + I` → **Персоналізація** → **Фон** → вибери **Слайдшоу** і вкажи дві різні папки.

---

## Типові проблеми та рішення

### Другий монітор не визначається

`Win + I` → **Дисплей** → **Виявити** → натисни кнопку.

```powershell
# Примусова перевизначення дисплеїв
$CSharpCode = @"
using System.Runtime.InteropServices;
public class Display {
  [DllImport("user32.dll")] public static extern bool EnumDisplayDevices(string lpDevice, uint iDevNum, ref DISPLAY_DEVICE lpDisplayDevice, uint dwFlags);
  [StructLayout(LayoutKind.Sequential, CharSet = CharSet.Auto)] public struct DISPLAY_DEVICE { public int cb; [MarshalAs(UnmanagedType.ByValTStr, SizeConst = 32)] public string DeviceName; [MarshalAs(UnmanagedType.ByValTStr, SizeConst = 128)] public string DeviceString; public int StateFlags; [MarshalAs(UnmanagedType.ByValTStr, SizeConst = 128)] public string DeviceID; [MarshalAs(UnmanagedType.ByValTStr, SizeConst = 128)] public string DeviceKey; }
}
"@
# Спробуй інший кабель або порт — найпростіше рішення
```

Якщо кнопка "Виявити" не допомагає:
1. Спробуй інший HDMI/DisplayPort кабель
2. Підключи до іншого порту на відеокарті
3. Перезавантаж ПК з підключеним монітором
4. Оновити драйвер відеокарти (nvidia.com, amd.com)

### Другий монітор є але чорний

- Натисни `Win + P` → вибери **Розширити**
- Перевір що монітор увімкнений і вибрано правильний вхід (HDMI 1, HDMI 2, DP тощо)

### Неправильна роздільна здатність або немає потрібної

Причина — старий або невірний драйвер. Завантаж драйвер відеокарти:
- NVIDIA: [nvidia.com/drivers](https://www.nvidia.com/drivers)
- AMD: [amd.com/support](https://www.amd.com/support)
- Intel: [intel.com/download-center](https://www.intel.com/content/www/us/en/download-center/home.html)

### Розмитий текст на одному з моніторів

Правий клік на програмі → **Властивості** → **Сумісність** → **Змінити параметри DPI** → **Замінити** → **Застосунок**.

### Курсор не переходить між екранами

Перетягни прямокутники моніторів у Параметрах дисплея щоб їх краї співпадали. Курсор проходить тільки в місці де монітори "торкаються".

### Монітор показує не ту частоту

DisplayPort підтримує більш високі частоти ніж HDMI 1.4. Якщо у тебе 144 Гц монітор підключений через HDMI 1.4 — отримаєш максимум 60 Гц. Використовуй DisplayPort або HDMI 2.0.

---

## Корисні гарячі клавіші для роботи з двома моніторами

| Клавіші | Дія |
|---------|-----|
| `Win + P` | Режим відображення |
| `Win + Shift + ←/→` | Перенести вікно на інший монітор |
| `Win + ←/→` | Прив'язати вікно до лівої/правої половини |
| `Win + Z` | Snap Layouts (вибір розкладки) |
| `Win + D` | Показати робочий стіл |

### Переміщення вікна на інший монітор

`Win + Shift + →` — кинути активне вікно на правий монітор.
`Win + Shift + ←` — на лівий.

---

## Ноутбук з зовнішнім монітором: корисні налаштування

**Закрити кришку і продовжити роботу на зовнішньому моніторі:**
`Win + R` → `powercfg.cpl` → **Вибрати дії при закритті кришки** → **Закриття кришки** → **Нічого не робити** (при підключенні до мережі).

**Використовувати тільки зовнішній монітор:**
`Win + P` → **Тільки другий екран**

---

## Резюме

1. Підключи кабель (DisplayPort — найкраще)
2. `Win + P` → **Розширити**
3. Розтягни прямокутники моніторів відповідно до фізичного розташування
4. Встанови нативну роздільну здатність і максимальну частоту для кожного
5. Налаштуй масштаб якщо монітори різні
6. `Win + Shift + ←/→` для швидкого переміщення вікон між екранами

Два монітори налаштовуються за 5 хвилин. Якщо щось не працює — найчастіша причина: невірний кабель або застарілий драйвер відеокарти.
