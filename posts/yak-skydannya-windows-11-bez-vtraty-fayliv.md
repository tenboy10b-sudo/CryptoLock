Скидання Windows — крайній захід, але не обов'язково означає втрату файлів.

---

## Варіант 1: Скинути цей ПК (рекомендовано)

`Win + I` → **Система** → **Відновлення** → **Скинути цей ПК**

Вибір:
- **Зберегти мої файли** — видаляє застосунки і налаштування, зберігає особисті файли
- **Видалити все** — повна чиста установка

Потім:
- **Хмарне завантаження** — свіжа Windows від Microsoft (краще якщо файли пошкоджені)
- **Локальне перевстановлення** — швидше, без інтернету

---

## Варіант 2: Через WinRE (якщо Windows не запускається)

3 невдалі завантаження → WinRE → **Усунення несправностей** → **Скинути цей ПК**

---

## Перед скиданням — резервна копія

```powershell
# Список встановлених програм
Get-ItemProperty HKLM:\Software\Wow6432Node\Microsoft\Windows\CurrentVersion\Uninstall\* |
  Select-Object DisplayName, DisplayVersion |
  Export-Csv "C:\Users\Public\Desktop\apps.csv" -NoTypeInformation

# Список через winget
winget export -o "C:\Users\Public\Desktop\apps.json"
```

---

## Що видаляє "Зберегти мої файли"

| Видаляє | Зберігає |
|---------|---------|
| Всі встановлені застосунки | Документи, Фото, Відео |
| Налаштування системи | Файли Робочого столу |
| Зміни реєстру | Папка Завантаження |

---

## Після скидання — відновити застосунки

```powershell
winget import -i "C:\apps.json" --accept-package-agreements
```

---

## Спочатку спробуй без скидання

```powershell
DISM /Online /Cleanup-Image /RestoreHealth
sfc /scannow
```

---

## Часті питання

### Скидання видаляє віруси?

Так — скидання з "Видалити все" + хмарне завантаження видаляє весь малваре. "Зберегти мої файли" може не видалити малваре що ховається в папках користувача.

### Скільки часу займає скидання?

30-60 хвилин для "Зберегти мої файли". 45-90 хвилин для "Видалити все". Хмарне завантаження додає 10-30 хвилин.

---

## Резюме

**Скинути → Зберегти файли → Хмарне завантаження** — найбезпечніший варіант. Збережи список застосунків через winget до початку. DISM + SFC перед скиданням. Fresh Start видаляє bloatware виробника.
