Lightshot — найшвидший спосіб зробити скріншот виділеної області і одразу відредагувати або поділитись. Один клік — і скріншот готовий.

---

## Встановлення

1. Завантаж з [app.prntscr.com](https://app.prntscr.com/en/download.html)
2. Встанови — заміняє стандартну клавішу PrtScr

---

## Як користуватись

### Зробити скріншот

1. Натисни `PrtScr`
2. Екран затемниться — виділи мишею потрібну область
3. З'явиться панель інструментів

### Інструменти редагування

| Інструмент | Призначення |
|-----------|------------|
| Олівець | Вільне малювання |
| Лінія | Пряма лінія |
| Стрілка | Вказівна стрілка |
| Прямокутник | Рамка навколо елемента |
| Маркер | Виділення кольором |
| Текст | Підпис |
| Blur | Розмити область (для конфіденційних даних) |

### Зберегти або поділитись

| Кнопка | Дія |
|--------|-----|
| 💾 | Зберегти на комп'ютер |
| 📋 | Скопіювати в буфер обміну |
| 🖨️ | Роздрукувати |
| ↑ | Завантажити на сервер і отримати посилання |
| 🔍 | Пошук схожих зображень в Google |

---

## Гарячі клавіші

| Клавіша | Дія |
|---------|-----|
| `PrtScr` | Зробити скріншот |
| `Ctrl+Z` | Відмінити |
| `Ctrl+C` | Копіювати |
| `Ctrl+S` | Зберегти |
| `Ctrl+A` | Виділити весь екран |
| `Esc` | Скасувати |

---

## Альтернативи Lightshot (вбудовані в Windows)

| Інструмент | Гарячі клавіші | Переваги |
|-----------|--------------|---------|
| Snipping Tool | `Win+Shift+S` | Вбудований, не потрібно встановлювати |
| Xbox Game Bar | `Win+Alt+PrtScr` | Запис відео і скріншоти ігор |
| PrtScr | `PrtScr` | Копіює весь екран в буфер |
| Win+PrtScr | `Win+PrtScr` | Зберігає весь екран в Pictures |
