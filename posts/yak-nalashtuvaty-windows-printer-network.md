Один принтер в домі або офісі можна зробити доступним для всіх ПК в мережі без додаткового обладнання.

---

## Налаштувати спільний доступ до принтера

На ПК де підключений принтер:

`Win + I` → **Bluetooth і пристрої** → **Принтери та сканери** → вибери принтер → **Властивості принтера** → вкладка **Спільний доступ** → постав галочку **Надати спільний доступ до цього принтера** → задай ім'я → OK.

Переконайся що мережевий виявлення увімкнений:
`Win + I` → **Мережа і Інтернет** → **Розширені налаштування мережі** → **Розширені параметри спільного доступу** → увімкни **Виявлення мережі** і **Спільний доступ до файлів і принтерів**.

---

## Підключити принтер з іншого ПК

**Спосіб 1: Через мережеве оточення**
`Win + E` → **Мережа** → знайди ПК з принтером → двічі клікни → знайди принтер → правий клік → **Підключити**.

**Спосіб 2: Через адресний рядок**
`Win + R` → введи `\\ІМ'Я-ПК\НазваПринтера` → Enter → принтер встановиться автоматично.

**Спосіб 3: Додати принтер вручну**
`Win + I` → **Принтери та сканери** → **Додати пристрій** → пристрій не знайдено → **Потрібного принтера немає у списку** → **Вибрати спільний принтер за іменем** → введи `\\ІМ'Я-ПК\НазваПринтера`.

## Через PowerShell

```powershell
# На ПК з принтером — налаштувати спільний доступ
$printer = Get-Printer -Name "HP LaserJet"
Set-Printer -Name $printer.Name -Shared $true -ShareName "HPLaserJet"

# На іншому ПК — підключити мережевий принтер
Add-Printer -ConnectionName "\\SERVER-PC\HPLaserJet"

# Переглянути принтери
Get-Printer | Select-Object Name, Shared, ShareName, PortName
```

## Типові проблеми

**"Немає доступу до принтера":**
- Перевір що на обох ПК є однаковий обліковий запис і пароль, або вимкни **Захист паролем** для спільного доступу:
`Розширені параметри спільного доступу` → **Усі мережі** → **Спільний доступ із захистом паролем** → Вимкнути.

**Принтер є в мережі але не друкує:**
```powershell
# Перезапустити Print Spooler
Restart-Service Spooler -Force
```

**Драйвер не встановлюється на клієнтському ПК:**
Завантаж драйвер з сайту виробника і встанови вручну, потім підключайся до спільного принтера.

**ПК з принтером у сні — принтер недоступний:**
`Win + I` → **Система** → **Живлення** → вимкни режим сну для ПК де принтер. Або налаштуй Wake-on-LAN.

## Мережевий принтер напряму (без комп'ютера-сервера)

Якщо принтер має вбудований Wi-Fi або Ethernet:

1. Підключи принтер до мережі через його меню
2. На кожному ПК: `Win + I` → **Принтери та сканери** → **Додати пристрій** — принтер з'явиться автоматично
3. Якщо ні — додай по IP: **Потрібного принтера немає у списку** → **Додати принтер за IP-адресою**

---

## Резюме

На ПК з принтером: Властивості принтера → Спільний доступ → увімкни. На іншому ПК: `\\ІМ'Я-ПК\НазваПринтера` в адресному рядку Провідника. Якщо вимагає пароль — вимкни захист паролем у розширених параметрах спільного доступу.
