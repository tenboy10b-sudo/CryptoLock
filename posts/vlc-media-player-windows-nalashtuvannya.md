VLC — найпопулярніший медіаплеєр у світі. Відкриває будь-який відеоформат без додаткових кодеків, безкоштовний і без реклами. Але мало хто знає про його приховані можливості.

---

## Встановлення

1. Завантаж з [videolan.org/vlc](https://www.videolan.org/vlc/download-windows.html)
2. Вибери 64-bit для сучасних Windows
3. Встанови — все за замовчуванням

```powershell
# Або через winget
winget install VideoLAN.VLC
```

---

## Які формати відкриває VLC

VLC відкриває практично все без додаткових кодеків:

| Категорія | Формати |
|---------|---------|
| Відео | MP4, MKV, AVI, MOV, WMV, FLV, WebM, TS, M2TS |
| Аудіо | MP3, FLAC, AAC, OGG, WAV, AIFF, AC3 |
| Диски | DVD, Blu-ray (з ключем), Audio CD |
| Потокове | HTTP, RTSP, HLS, YouTube (через URL) |
| Архіви | RAR (відео з архіву) |

## Корисні гарячі клавіші

| Клавіша | Дія |
|---------|-----|
| `Пробіл` | Пауза/відтворення |
| `F` | Повноекранний режим |
| `←` / `→` | Перемотка -10/+10 сек |
| `Alt+←` / `Alt+→` | Перемотка -1/+1 хв |
| `[` / `]` | Зменшити/збільшити швидкість |
| `=` | Нормальна швидкість |
| `J` / `K` | Зсув субтитрів -/+ 50мс |
| `G` / `H` | Зсув аудіо -/+ 50мс |
| `Ctrl+D` | Відкрити диск |
| `Ctrl+N` | Відкрити потік (URL) |
| `T` | Показати поточний час |

## Зміна швидкості відтворення

Дивись лекції і туторіали швидше:

```
Відтворення → Швидкість → Швидше/Повільніше
```

Або `[` і `]` для покрокової зміни.
Або праве меню → "Швидкість відтворення" → вибери 1.25x, 1.5x, 2x.

---

## Субтитри

### Автоматично завантажити субтитри

```
Вид → VLsub (завантажити субтитри)
```

VLsub шукає субтитри на OpenSubtitles.org за назвою фільму.

### Зміна шрифту субтитрів

```
Інструменти → Параметри → Субтитри/OSD
```

- Розмір шрифту: 24–36 для комфортного перегляду
- Кодування: UTF-8 для кирилиці

### Синхронізація субтитрів
- `J` — затримати субтитри (якщо йдуть раніше за відео)
- `K` — прискорити субтитри (якщо запізнюються)

## Конвертація відео

VLC вміє конвертувати відео в інші формати:

```
Медіа → Конвертувати/Зберегти (Ctrl+R)
```

1. Додай файл → **"Конвертувати/Зберегти"**
2. Вибери профіль (MP4, MP3, WebM тощо)
3. Вкажи файл виводу
4. **"Почати"**

Це не найшвидший конвертер — для великих об'ємів краще HandBrake або FFmpeg.

---

## Відео з YouTube і потокових сервісів

VLC відкриває відео напряму за URL:

```
Ctrl+N → вставити URL відео
```

Підтримує: YouTube, Twitch, Dailymotion, прямі HTTP посилання на відео.

---

## Скріншот з відео

```
Відео → Знімок екрана (Ctrl+Alt+S)
```

Збереження: `C:\Users\[user]\Pictures\vlc`

## Приховані можливості

### Запис відео
```
Вид → Додаткові елементи керування
```
З'являється кнопка запису — записує те що зараз відтворюється.

### Ефекти і фільтри
```
Інструменти → Ефекти і фільтри (Ctrl+E)
```
- Еквалайзер
- Корекція кольору
- Просторовий звук
- Стабілізація відео

### Медіасервер (DLNA)
```
Вид → Медіасервер
```
VLC може стримити відео на інші пристрої в мережі.

### Трансляція відео (streaming)
```
Медіа → Stream (Ctrl+S)
```
Транслює відео на інший ПК або в інтернет через HTTP/RTSP.

---

## Налаштування для найкращої якості

```
Інструменти → Параметри → Відео
```

- **Виведення відео:** Direct3D11 Video output (найкраще для Windows)
- **Апаратне прискорення:** Direct3D11 (GPU декодування)

```
Інструменти → Параметри → Аудіо
```
- **Аудіо вивід:** DirectSound або WASAPI
