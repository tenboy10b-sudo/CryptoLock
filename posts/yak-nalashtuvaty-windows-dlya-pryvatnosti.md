Windows збирає різні дані за замовчуванням. Більшість із цього можна вимкнути за кілька хвилин.

---

## Загальні налаштування приватності

`Win + I` → **Конфіденційність і безпека** → **Загальні**:

- **Рекламний ідентифікатор** → вимкни (персоналізована реклама в програмах)
- **Відстеження запусків програм** → вимкни
- **Показувати рекомендований вміст в Параметрах** → вимкни
- **Мова веб-сайтів** → вимкни

---

## Телеметрія і діагностика

`Win + I` → **Конфіденційність і безпека** → **Діагностика і відгуки**:

- **Діагностичні дані** → **Необхідні дані** (мінімум)
- **Покращення рукопису і введення тексту** → вимкни
- **Індивідуальний інтерфейс** → вимкни
- **Журнал зворотного зв'язку** → вимкни

```powershell
# Встановити мінімальний рівень телеметрії через реєстр
Set-ItemProperty -Path "HKLM:\SOFTWARE\Policies\Microsoft\Windows\DataCollection" `
  -Name "AllowTelemetry" -Value 1 -Type DWord
```

---

## Журнал активності

`Win + I` → **Конфіденційність і безпека** → **Журнал активності**:

- Вимкни **Зберігати журнал активності на цьому пристрої**
- Натисни **Очистити журнал активності**

---

## Дозволи програм

`Win + I` → **Конфіденційність і безпека** → перевір кожен розділ:

**Розташування** → вимкни для програм що не потребують
**Камера** → залиш тільки Teams, Zoom або що використовуєш для відео
**Мікрофон** → аналогічно
**Сповіщення** → вимкни доступ для програм що його не потребують
**Відомості про акаунт** → вимкни для незнайомих програм

---

## Пошук Windows і Cortana

`Win + I` → **Конфіденційність і безпека** → **Дозволи для пошуку**:

- **Безпечний пошук** → вибери рівень
- **Хмарний вміст** → вимкни якщо не хочеш персоналізованих результатів
- **Журнал пошуку** → **Очистити журнал**

---

## Вимкнути служби телеметрії

```powershell
# DiagTrack — основна служба телеметрії
Stop-Service DiagTrack -Force
Set-Service DiagTrack -StartupType Disabled

# dmwappushservice — допоміжна служба
Stop-Service dmwappushservice -Force
Set-Service dmwappushservice -StartupType Disabled
```

---

## Заблокувати телеметрію через hosts файл

Відкрий `C:\Windows\System32\drivers\etc\hosts` від адміністратора і додай:

```
0.0.0.0 vortex.data.microsoft.com
0.0.0.0 vortex-win.data.microsoft.com
0.0.0.0 telecommand.telemetry.microsoft.com
0.0.0.0 settings-win.data.microsoft.com
```

Збережи. Це блокує підключення до серверів телеметрії.

---

## Автоматизація через PowerShell скрипт

```powershell
# Вимкнути рекламний ідентифікатор
Set-ItemProperty "HKCU:\Software\Microsoft\Windows\CurrentVersion\AdvertisingInfo" `
  -Name "Enabled" -Value 0 -Type DWord

# Вимкнути відстеження запусків
Set-ItemProperty "HKCU:\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced" `
  -Name "Start_TrackProgs" -Value 0 -Type DWord

# Вимкнути Cortana
Set-ItemProperty "HKLM:\SOFTWARE\Policies\Microsoft\Windows\Windows Search" `
  -Name "AllowCortana" -Value 0 -Type DWord -Force
```

## Резюме

Мінімум: **Параметри → Конфіденційність → Загальні** → вимкни рекламний ідентифікатор і відстеження. **Діагностика** → встанови мінімальний рівень. Перевір дозволи для камери, мікрофона і розташування. Це займає 5 хвилин і значно зменшує обсяг зібраних даних.
