Telegram Desktop — повноцінна версія Telegram для Windows. Більше можливостей ніж мобільна: робота з кількома акаунтами, гарячі клавіші, кращий перегляд медіа і синхронізація файлів.

---

## Встановлення

1. Завантаж з [desktop.telegram.org](https://desktop.telegram.org)
2. Або з Microsoft Store
3. Запусти → увійди через номер телефону

```powershell
winget install Telegram.TelegramDesktop
```

---

## Налаштування після встановлення

### Тема оформлення

```
Налаштування → Налаштування чату → Вибрати тему
```

Вбудовані теми: Day, Night, Tinted. Або завантаж власну з [t.me/themes](https://t.me/themes).

### Сповіщення

```
Налаштування → Сповіщення та звуки
```

- Вимкнути всі сповіщення: зніми всі галочки
- Окремо для груп і каналів — різні налаштування
- **"Не турбувати"** — вимкнути на певний час

### Папки чатів (Folders)

Одна з найкорисніших функцій:

```
Налаштування → Папки → Створити папку
```

Приклади папок:
- Робота (всі робочі групи)
- Новини (новинні канали)
- Особисте (друзі і сім'я)

Ліва панель перетворюється на вкладки.

## Гарячі клавіші

| Клавіша | Дія |
|---------|-----|
| `Ctrl+N` | Новий чат |
| `Ctrl+F` | Пошук |
| `Ctrl+Tab` | Наступний чат |
| `Ctrl+Shift+Tab` | Попередній чат |
| `Ctrl+↑/↓` | Прокрутка списку чатів |
| `Ctrl+Enter` | Відправити (якщо Enter = новий рядок) |
| `Alt+←` | Назад |
| `F1` | Допомога |

**Змінити Enter на відправку:**
```
Налаштування → Загальне → Відправляти Enter
```

---

## Кілька акаунтів

Telegram Desktop підтримує до 3 акаунтів одночасно:

```
Натисни на своє ім'я зверху → Додати акаунт
```

Перемикання між акаунтами — `Ctrl+1`, `Ctrl+2`, `Ctrl+3`.

---

## Автозавантаження медіафайлів

```
Налаштування → Дані та сховище → Автоматичне завантаження медіа
```

Вимкни автозавантаження відео і файлів якщо не хочеш витрачати місце на диску.

**Папка збереження:**
```
Налаштування → Дані та сховище → Шлях до завантажень → Змінити
```

## Приховані функції

### Telegram як файлове сховище
Відправляй файли собі — "Збережені повідомлення" (Saved Messages) доступні з будь-якого пристрою. Ліміт файлу 2 ГБ.

### Теги в Saved Messages
```
Saved Messages → ПКМ на повідомлення → Pin
```
Закріплені повідомлення завжди зверху.

### Планувальник повідомлень
Утримуй кнопку відправки → "Запланувати повідомлення" → вибери час.

### Тихі повідомлення
`Ctrl+Enter` з пунктом "Без звуку" — відправляє без сповіщення для отримувача.

### Спойлер в тексті
```
Виділи текст → ПКМ → Форматування → Спойлер
```
Або обгорни в `||текст||`.

## Telegram і VPN

Якщо Telegram заблокований в твоїй мережі:

```
Налаштування → Конфіденційність та безпека → Проксі → Додати проксі
```

Типи проксі: SOCKS5, MTProto (рідний протокол Telegram).

Безкоштовні MTProto проксі: [t.me/socks](https://t.me/socks)

## Вирішення проблем

### Telegram не запускається
Видали папку даних і встанови заново:
```powershell
Remove-Item "$env:APPDATA\Telegram Desktop" -Recurse -Force
```

### Файли не відкриваються після завантаження
Перевір налаштування антивіруса — Windows Defender іноді блокує файли з Telegram.
