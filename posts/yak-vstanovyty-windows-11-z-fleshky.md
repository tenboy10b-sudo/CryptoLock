Чиста установка Windows 11 з флешки — найнадійніший спосіб отримати свіжу систему без сміття від попередньої. Ось як зробити все правильно.

---

## Що потрібно

- USB флешка від 8 ГБ (дані будуть видалені)
- Підключення до інтернету
- ПК з UEFI BIOS і TPM 2.0 (або Rufus для обходу)

---

## Спосіб 1: Rufus (рекомендовано)

Rufus — безкоштовна утиліта що завантажує ISO і записує на флешку. Також дозволяє обійти вимоги TPM 2.0.

```powershell
# Встановити Rufus через winget
winget install Rufus.Rufus
```

**Кроки:**
1. Підключи флешку і запусти Rufus від адміністратора
2. **Boot selection** → клікни **Download** → вибери **Windows 11**
3. Вибери мову і версію (Home або Pro)
4. Натисни **Start** — з'явиться вікно з опціями:
   - ✅ **Remove requirement for TPM 2.0** (якщо старий ПК)
   - ✅ **Remove requirement for Secure Boot**
   - ✅ **Create a local account** (без Microsoft акаунту)
5. OK → чекай завершення запису (~10-15 хвилин)

---

## Спосіб 2: Media Creation Tool (офіційний)

1. Завантаж з `microsoft.com/software-download/windows11`
2. Запусти → **Create installation media**
3. Вибери мову і версію
4. **USB flash drive** → вибери флешку
5. Чекай завершення (~20-30 хвилин)

---

## Налаштування BIOS для завантаження з флешки

1. Перезавантаж ПК і натискай **Del**, **F2** або **F12** (залежно від виробника)
2. Знайди **Boot Order** або **Boot Priority**
3. Постав USB на перше місце
4. **Secure Boot** — залиш увімкненим (або вимкни якщо є проблеми)
5. Збережи: **F10** → Yes

**Швидке завантаження з USB** (без BIOS):
- Windows 10/11: `Shift + Перезавантаження` → Усунення несправностей → Розширені параметри → Налаштування мікропрограми UEFI

---

## Процес встановлення

1. Завантажся з флешки — з'явиться синій екран інсталятора
2. Мова, час, клавіатура → **Далі** → **Встановити зараз**
3. Ліцензійний ключ → **У мене немає ключа** (якщо активація пізніше)
4. Вибери версію: **Home** або **Pro**
5. **Вибіркове встановлення** (не оновлення!)
6. Вибери диск → якщо потрібно — **Форматувати** → **Далі**
7. Чекай ~20-40 хвилин

## Проблема: "Цей ПК не може запустити Windows 11"

```cmd
rem Під час встановлення натисни Shift+F10 і введи:
regedit
rem HKEY_LOCAL_MACHINE\SYSTEM\Setup\MoSetup
rem Створи DWORD: AllowUpgradesWithUnsupportedTPMOrCPU = 1
```

Або використовуй Rufus з галочкою **Remove requirement for TPM 2.0** — простіший варіант.

## Часті питання

### Яка мінімальна флешка для Windows 11?

Мінімум 8 ГБ, але рекомендується 16 ГБ щоб ISO вмістився з запасом. USB 3.0 значно прискорить запис і встановлення.

### Чи видаляться файли на флешці?

Так. Rufus і Media Creation Tool форматують флешку перед записом. Збережи важливі файли перед початком.

### Після встановлення Windows не активована — що робити?

Якщо раніше був ліцензійний Windows — активація відбудеться автоматично після підключення до інтернету (через прив'язку до Microsoft акаунту або BIOS). Якщо ні — потрібен ліцензійний ключ.

### Чи можна встановити без інтернету?

Так, але при першому налаштуванні Windows 11 Home вимагає Microsoft акаунт. Rufus дозволяє оминути це: увімкни **Create a local account**.

---

## Резюме

Найшвидший шлях: Rufus → завантажити ISO → записати → завантажитись з USB → чиста установка. Для старих ПК без TPM 2.0 — Rufus з опцією обходу вимог. Після встановлення оновлення завантажуються автоматично.
