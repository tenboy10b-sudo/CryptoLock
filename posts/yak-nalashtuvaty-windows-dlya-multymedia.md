Вбудований медіаплеєр Windows обмежений. Ось що встановити для комфортного перегляду відео і роботи з медіафайлами.

---

## VLC — найкращий безкоштовний плеєр

VLC відтворює практично будь-який формат без додаткових кодеків:

```powershell
winget install VideoLAN.VLC
```

Підтримує: MP4, MKV, AVI, MOV, WebM, FLV, HEVC/H.265, VP9, Blu-ray і сотні інших форматів.

**Корисні функції VLC:**
- `A-Z` — пришвидшити/сповільнити відео
- `E` — наступний кадр (пауза)
- `G/H` — субтитри раніше/пізніше
- Медіа → Конвертувати/Зберегти — безкоштовна конвертація

---

## MPC-HC — легкий і швидкий

Для слабких ПК або якщо VLC здається важким:

```powershell
winget install MPC-HC.MPC-HC
```

Мінімальний інтерфейс, менше ресурсів, підтримка апаратного декодування.

---

## Встановити кодеки (K-Lite Codec Pack)

Якщо хочеш використовувати Windows Media Player але з повною підтримкою форматів:

Завантаж **K-Lite Codec Pack Basic** з codecguide.com — встановлює тільки необхідні кодеки без зайвого.

---

## Переглядач зображень

Вбудований Photos підходить для більшості. Альтернативи:

```powershell
# IrfanView — швидкий, підтримує 100+ форматів
winget install IrfanView.IrfanView

# ImageGlass — сучасний, підтримує WebP, HEIC
winget install DuyHai.ImageGlass
```

## Конвертація відео без доп. програм (VLC)

VLC вміє конвертувати відео:
**Медіа** → **Конвертувати/Зберегти** → вибери файл → формат виводу → зберегти.

Для пакетної конвертації або більш складних завдань:

```powershell
winget install Gyan.FFmpeg
```

FFmpeg — потужний консольний інструмент:
```cmd
rem Конвертувати MKV в MP4
ffmpeg -i input.mkv -codec copy output.mp4

rem Конвертувати з перекодуванням
ffmpeg -i input.avi -c:v libx264 -c:a aac output.mp4

rem Витягти аудіо
ffmpeg -i video.mp4 -vn -codec:a mp3 audio.mp3
```

## Субтитри

**Для VLC:** перетягни файл субтитрів (.srt, .ass) прямо у вікно плеєра або:
Відео → Субтитри → Додати файл субтитрів.

**Автоматичне завантаження субтитрів в VLC:**
Встанови розширення VLSub:
VLC → Вигляд → Диспетчер розширень → VLSub → Завантажити.

---

## Асоціації файлів

Якщо відеофайли відкриваються не в тому плеєрі:

```powershell
# Встановити асоціацію для .mkv
Set-ItemProperty -Path "HKCU:\Software\Classes\.mkv" -Name "(Default)" -Value "VLC.mkv"
```

Або: правий клік на файлі → **Відкрити за допомогою** → **Завжди використовувати цю програму**.

---

## Відтворення HEVC (H.265)

Windows 10/11 не підтримує HEVC без кодека. Два варіанти:

1. **VLC або MPC-HC** — відтворюють без кодека
2. **HEVC Video Extensions** — безкоштовно в Microsoft Store

---

## Резюме

Встанови VLC (`winget install VideoLAN.VLC`) — вирішує 95% питань з відтворенням. Для конвертації — FFmpeg. Для перегляду зображень — IrfanView якщо вбудований Photos не влаштовує.
