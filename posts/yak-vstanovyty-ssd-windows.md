Заміна HDD на SSD — найефективніше покращення для старого ПК. Windows завантажується за 10 секунд замість хвилини. Перевстановлювати систему не обов'язково — можна перенести клонуванням.

---

## Що знадобиться

- Новий SSD (бажано такого ж або більшого розміру ніж зайнятий простір на HDD)
- USB-перехідник SATA/NVMe → USB або другий слот в ноутбуці/ПК
- Macrium Reflect Free — безкоштовна програма для клонування

---

## Крок 1: Завантажити Macrium Reflect Free

Перейди на [macrium.com](https://www.macrium.com/reflectfree) → завантаж безкоштовну версію → встанови.

---

## Крок 2: Підключити SSD

- **ПК:** встанови SSD в другий слот або підключи через SATA кабель
- **Ноутбук:** підключи через USB-перехідник або встав замість DVD-приводу через caddy

Перевір що SSD видно в системі: `Win + X` → **Керування дисками**

---

## Крок 3: Клонувати диск

1. Відкрий **Macrium Reflect**
2. Вибери свій HDD зі списку дисків
3. Натисни **Clone this disk**
4. Вибери SSD як диск призначення
5. Натисни **Next** → перевір що всі розділи відображаються правильно

**Важливо:** якщо SSD менший за HDD — зменши розділ Windows перетягнувши межу. Розділ має поміщатись на SSD.

6. Натисни **Finish** → **OK** → клонування почнеться

Займає 30–90 хвилин залежно від обсягу даних.

---

## Крок 4: Замінити диск

Після клонування:

1. Вимкни ПК
2. Витягни HDD
3. Встав SSD на місце HDD
4. Увімкни ПК

Windows має завантажитись з SSD автоматично.

---

## Крок 5: Перевірити після заміни

```powershell
# Перевірити з якого диска завантажилась система
Get-PhysicalDisk | Select-Object FriendlyName, MediaType, Size

# Перевірити чи увімкнено TRIM для SSD
fsutil behavior query DisableDeleteNotify
```

`DisableDeleteNotify = 0` — TRIM увімкнено (добре).

---

## Крок 6: Розширити розділ якщо SSD більший

Якщо SSD більший за HDD — після клонування залишиться нерозподілений простір. Розшир розділ:

`Win + X` → **Керування дисками** → правий клік на розділі C → **Розширити том** → вибери весь доступний простір.

---

## Що робити зі старим HDD

Не викидай — він стає сховищем:
- Відформатуй через **Керування дисками**
- Використовуй для зберігання файлів, відео, ігор
- Або встав в зовнішній корпус як портативний диск

---

## Якщо ПК не завантажується після заміни

1. Увійди в BIOS і перевір порядок завантаження — SSD має бути першим
2. Або: завантажся з Windows USB → **Відновлення** → **Відновлення при завантаженні**

---

## Резюме

Macrium Reflect Free → Clone this disk → вибери SSD → чекай → заміни диск. Весь процес займає ~2 години. Результат — Windows з усіма програмами і налаштуваннями на SSD, завантаження за 10–15 секунд.
