Lightshot is the fastest way to screenshot a selected area and immediately edit or share it.

---

## Install

Download from [app.prntscr.com](https://app.prntscr.com/en/download.html) — replaces PrtScr key.

---

## How to Use

1. Press `PrtScr`
2. Screen dims — drag to select area
3. Toolbar appears for editing

### Editing Tools

| Tool | Purpose |
|------|---------|
| Pencil | Freehand drawing |
| Arrow | Pointer arrow |
| Rectangle | Highlight area |
| Text | Add caption |
| Blur | Hide sensitive data |

### Save or Share

| Button | Action |
|--------|--------|
| 💾 | Save to computer |
| 📋 | Copy to clipboard |
| ↑ | Upload and get shareable link |

---

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `PrtScr` | Take screenshot |
| `Ctrl+Z` | Undo |
| `Ctrl+C` | Copy |
| `Ctrl+S` | Save |

---

## Built-in Windows Alternatives

| Tool | Shortcut | Advantage |
|------|---------|-----------|
| Snipping Tool | `Win+Shift+S` | Built-in, no install |
| Xbox Game Bar | `Win+Alt+PrtScr` | Video recording too |

---

## Summary

```
PrtScr → select area → annotate → ↑ upload or 📋 copy
```

For advanced features and video recording: use ShareX instead.
