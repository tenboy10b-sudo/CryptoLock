You can record your screen on Windows without installing extra software — built-in tools are already there. But if you need more control, free alternatives are available.

---

## Method 1 — Xbox Game Bar (built-in, Windows 10/11)

The fastest method. Works for most apps and games.

**Keyboard shortcuts:**
```
Win + G           — open Game Bar
Win + Alt + R     — start/stop recording
Win + Alt + M     — toggle microphone
Win + Alt + PrtSc — screenshot
```

Videos saved to: `C:\Users\[name]\Videos\Captures`

**Quality settings:**
```
Win + I → Gaming → Captures
- Video quality: Standard / High
- Frame rate: 30 or 60 FPS
```

> ⚠️ Game Bar doesn't record the Desktop or File Explorer — only apps and games.

---

## Method 2 — Snipping Tool (Windows 11)

Updated Snipping Tool in Windows 11 can record video.

```
Win + Shift + S → select area → click video icon (🎬)
```

Or search: `Snipping Tool` → **"Video"** tab → **"New"** → select area → **"Start"**

---

## Method 3 — PowerPoint (requires Office)

1. PowerPoint → **"Insert"** → **"Screen Recording"**
2. Select area → **"Record"**
3. Stop with `Win + Shift + Q`
4. Video inserts into slide → right-click → **"Save Media As"**

---

## Method 4 — OBS Studio (free, powerful)

Most popular free tool for recording and streaming.

**Download:** [obsproject.com](https://obsproject.com)

**Basic setup:**
1. Install → run auto-configuration wizard
2. Sources → **+** → **"Display Capture"**
3. Click **"Start Recording"**

**Output settings:** File → Settings → Output → Recording
- Format: MP4
- Quality: High

---

## Method 5 — ShareX (free, maximum features)

Free open-source tool. More features than OBS for simple recording.

**Download:** [getsharex.com](https://getsharex.com) or Microsoft Store

1. **Capture** → **"Screen recording"**
2. Select area → **"Start"**

**ShareX advantages:** region recording, GIF conversion, built-in editor, auto-upload, completely free.
