Telegram Desktop has more features than mobile: multiple accounts, keyboard shortcuts, better media viewing and file sync.

---

## Install

```powershell
winget install Telegram.TelegramDesktop
```
Or from [desktop.telegram.org](https://desktop.telegram.org)

---

## Key Settings

### Theme
```
Settings → Chat Settings → Choose Theme
```
Built-in: Day, Night, Tinted. Or download from [t.me/themes](https://t.me/themes).

### Chat Folders
```
Settings → Folders → Create folder
```
Organize chats into tabs: Work, News, Personal.

### Notifications
```
Settings → Notifications and Sounds
```

---

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `Ctrl+N` | New chat |
| `Ctrl+F` | Search |
| `Ctrl+Tab` | Next chat |
| `Ctrl+Enter` | Send message |
| `Ctrl+1/2/3` | Switch accounts |

---

## Multiple Accounts

Up to 3 accounts simultaneously:
```
Click your name at top → Add Account
```
Switch with `Ctrl+1`, `Ctrl+2`, `Ctrl+3`.

---

## Hidden Features

**Telegram as file storage:** Send files to "Saved Messages" — accessible from any device. 2 GB file limit.

**Schedule messages:** Hold send button → "Schedule message"

**Silent message:** Send without notification to recipient.

**Spoiler text:** Wrap in `||text||`

## Proxy (if Telegram is blocked)
```
Settings → Privacy and Security → Proxy → Add proxy
```
MTProto proxies: [t.me/socks](https://t.me/socks)
